# 检查真实 GFSK IQ

先读取采集元数据，按实际 I/Q 顺序、字节序及有效位宽解包。
保留整段原始 IQ 和关联静默对照，不按已知载荷或同步位置预先裁切。
调用 `nearlink_sdr.phy.gfsk.analyze_gfsk_capture` 时显式提供实际采样率、
请求符号率和同增益的静默对照；当前前端支持整数 SPS ≥4，不固定为8。

前端以每符号平均功率的静默99.9%分位数乘4作为检测门限。
采用65抽头Hamming低通，截止频率为请求符号率，因果群延迟32样本。
每个能量段都输出：过短段、记录边界截断段、无法区分双频状态的段不会伪装成完整包。
CFO取双簇鉴频中心的中点；定时取每符号积分鉴频眼图的最大平均绝对值，
不使用期待载荷、CRC或同步相关结果选择定时。实际比特判决复用原有GFSK解调器。

`bit0_filtered_index` 为滤波后第一个判决区间的开始；
`bit0_raw_reference` 减去32样本群延迟，后续判决区间相隔SPS样本。
该坐标是原始文件偏移和一个样本的定时网格，不是空口硬件时间。
符号时钟还提供请求附近±10%的过渡能量谱峰、谱峰对比和观测时长；
FFT零填充后的网格间隔不是绝对时钟精度或独立SRO校准。

`prbs9` 定义数学约定为x⁹+x⁵+1、全一初态、stage8优先输出。
厂测固件是否使用相同种子、位序、扰码和帧封装，必须另外确认。
GFSK波形比较、能量段、同步候选或PRBS相似性都不能替代控制头、CRC和逐字节验收。
采集前端只返回未解析比特及诊断。若上下文已确认，可另调用
`phy.frame.decode_ft1_a3_candidates`：显式提供同步字、CRC24A种子与加扰种子
（`None`明确表示无加扰），扫描全部同步候选，复用已有A3解包和CRC算法。
头CRC12通过才使用长度，数据CRC24A通过才返回载荷；坏候选和截断候选保留，
继续搜索后续同步。不使用期待长度或载荷选择同步位置，也不为通过而枚举种子。
这是指定FT1/A3/CRC24A配置的解析器，不代表全部厂测模式或业务配置都相同。
不要直接把假定对齐的 `rx_chain` 或FT1 `decode_head` 的简化成功标志作为真实头CRC证据。
