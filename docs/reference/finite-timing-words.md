# 有限功率、Gardner误差、PI与NCO反馈

SYS-C2E2E-TIMING在[实际字交接](selected-symbol-handoff.md)之后，增加显式实验定时节点。
依据已登记标准§6.2.1.2的PSK波形，Gardner/PI及其增益是接收实现选择，不是标准强制算法。
只验证普通FT2/3/4、4Msym/s、SPS4；不由此推广FT1/GFSK、新WS63字路径或其他采样配置。
默认浮点接收保持不变，四项整体验收分别未通过。

## 接口与边界

`WordTimingState(power,start_tick,hold_symbols,fmt)`接收实际52bit插值字，
保存包内功率、上一个原字、PI速率、当前/上一个NCO坐标和有限统计计数。
已知同步期间每个功率更新都执行，误差为0、速率保持；之后必须提供实际中点字。
不接收期待载荷、CRC、判决比特或真值。包间重新创建状态，不能复用上包功率/积分器。

`WordTimingPSKReceiver`沿用原载波归一化、严格头/数据CRC、长度/MCS及MAC门。
`SelectedFrameReplay(...,word_timing_format=...)`选择实验节点；省略该参数保持原路径。
查询使用整数NCO描述符，浮点位置仅用于诊断/兼容数组。现有已选端口的4Msym/SPS4和
1Mi采样窗口限制继续有效；组件的64bit整数坐标测试不等于整链已支持任意长全局索引。

载波旋转、增益归一化、头部、LLR/译码仍为浮点服务。功能回放显式求解它们后，
完整周期证据永久失效，完整延迟为`None`。独立`TimingWordService`只证明该有限节点
的真实字计算与宏级周期，不把剩余工作填零，也不代表该服务已接回完整ADC调度器。

## 数据通路与格式

保持原功率IIR、误差限幅±2、PI增益、±500ppm速率限幅及包内NDA跟踪规则：

```text
P[k] = max((63P[k−1]+|current[k]|²)/64,1e−30)
e[k] = clip(Re[(previous−current)conj(midpoint)]/P[k],−2,+2)
omega[k] = clip(omega[k−1]+Ki e[k],lower,upper)
next[k] = current_coordinate+omega[k]+Kp e[k]
```

浮点执行顺序不逐次照抄；增益由独立80位Decimal方程核对后编译为Q48常量。
非法字、格式、指数、中间增长和计数耗尽显式报错；不以饱和掩盖算术溢出。
只在已规定的功率下限、误差和速率边界钳位。RNE均为最近偶数，负数对称处理。

| 节点 | 格式和规则 |
|---|---|
| 输入/上一个字 | signed22+signed22+signed8，共52bit |
| 功率 | unsigned30或38+signed10；初始unsigned54输入归一化 |
| 原能量 | 两个22位平方之和，unsigned44 |
| 功率对齐 | 63P和能量先各自归一化44bit，忽略零值指数，再对齐/45bit相加 |
| TED对齐 | 两个有效22位峰值确定共同指数，4个24位分量，2个signed25差 |
| TED分子 | 两个25×22实乘之和，signed48+signed10指数 |
| 归一化误差 | 正式比较固定signed35（小数32）；另保留Q24节点对照 |
| 临时尺度 | 有效位峰/指数差signed11，规范化移位signed7；存储指数signed10 |
| 比值/除法 | 先按平方尺度和位峰比较限幅/下溢，64或72位分子、49位分母、50位余数 |
| PI | Kp=7476035428952、Ki=29904141716，均除2^48；增量signed29/21 |
| 速率 | unsigned35，Q32；界17171279249/17188459119 |
| NCO | unsigned64整数+32小数；中点用97bit和，直接舍入到原phase16查询 |
| 计数 | 64bit，溢出报错；状态提交前统一检查 |

没有引入数据导频假设；实际导频位置及交替旋转仍由原帧解析处理。
SPS/带宽或速率界不符合本编译配置时明确拒绝，而不只解除检查宣称支持。

### 共同指数的开发反例

首版用输入原指数直接对齐，普通新开发仍5/6、旧13完整保留，但独立小尾数/零字反例失败：
功率相对误差可到0.003533，TED差可到1.015621，超过原冻结1e−6/2e−5预算。
原因是有效尾数未归一化、零字的指数也参与尺度选择。
原始52bit字序列、首版源码、独立分数/浮点答案和失败日志均保存。

修复按有效峰值选择尺度，并先规范化能量；没有扩大功率状态或更改误差门。
TED差增至25位仍恰好适配同一DSP的25位输入。增加2个44位能量规范化、2个22位峰值
优先编码及有界移位逻辑；完整LUT/时序未知。周期多3，不把这些逻辑当作免费收益。
这修复节点表示缺陷，不是压力包的实际接收恢复证明。

节点状态要求由单个服务独占；功能接收器与周期服务的状态交接/并发生产者尚未接入，
不能把事后逐字周期重放当作完整ADC接收。

## 冻结、数值与能力

正式功率精度比较固定误差Q32、NCO Q32及增益，只改变功率30/38位。
最早30/Q24仅为节点对照，原政策/源码保留；在任何新波形生成前已记录单因素政策修订。
新开发变化载荷、PID、FT/MCS、包长、导频、干扰、CFO/SRO和分数起点。
开发选择较小且过门的功率30后冻结源码/参数/预算/采用规则，再生成独立新保留。
已有及已查看集合仅固定回归，没有据保留结果重选格式。

冻结的新增误差门为功率相对差≤1e−6、TED绝对差≤2e−5、闭环中心增量≤0.001采样。
0.001约为64个phase16 LSB、原0.25轨迹预算的0.4%，不是新标准定时限值，
也不替换原插值RMS0.0001或RRC2%门。另要求原成功零丢失、零新增误交付。

| 集合 | 原字/浮点定时 | 有限定时 | 说明 |
|---|---:|---:|---|
| 新开发6合法包 | 5完整 | 5完整 | 1数据CRC失败，非恢复 |
| 冻结后新保留6合法包 | 5完整 | 5完整 | 1数据CRC失败，不换格式重试 |
| 原30固定请求 | 13完整 | 13完整 | 15可交接，其他几何/相干拒绝保留 |

新负例开发51200、保留54272采样（16MS/s下3.2/3.392ms），测试中零新增误交付。
观察量很短，上游仍是整份记录的一次差分最大峰夹具，不推导有界未知起点捕获率。
正式61/96未重算，本阶段接收率增益0。CRC、长度、MCS、完整载荷及BER分别保存。
真值仅用于事后误差；失锁/周期滑移及收敛时间未独立分类，不能由残差或正确包数推为零。

原RRC2.34835%＞2%、插值RMS0.000150245＞0.0001、原16KiB及三槽尾部拒绝均保留。
本节点的数值门通过不覆盖这些失败，更不等于全链定点通过。

## 硬件成本与周期拒绝

`TimingWordService`一个输入信用、一个保持输出；忙或输出未取时背压，中止后不能恢复。
每个DSP输入25×18，原生乘积43位；输入到乘积有效延迟3、II1。
低17位无符号块可放入signed18，高块按有符号拆分；不能把22×22或43×35算成一个DSP。

| 工作 | 原生25×18乘积 |
|---|---:|
| 每同步保持符号功率 | 4 |
| 每正常跟踪符号功率＋TED＋Ki＋Kp | 至多16 |
| 恢复除法 | 每周期1个实际余数/商位，64或72步 |

同一4DSP银行依次服务上述工作，未计与RRC、插值、初始拟合、TX或译码共享收益。

除原生乘积/除法步数是可执行模型计数外，下列为结构操作估算，不能转写为综合LUT数：

| 每正常跟踪符号最坏工作 | 数量/宽度 |
|---|---|
| 实数原生乘积 | ≤16次25×18，平均到SPS4为≤4次/输入采样；不含前端 |
| 核心加减（不含RNE/计数） | 约19次：乘积树12、63P减1、功率加1、TED差2、PI/步长/NCO各1 |
| 恢复除法 | 64次50bit比较及至多64次49bit减法，另有商/余数移位及索引计数 |
| 峰值/规范化 | 2×44bit功率优先编码、2×22bit TED峰编码、比值48bit峰编码/尺度比较 |
| 有界移位/RNE | 功率规范化/对齐、4个TED分量、比值分子、误差舍入及2个固定PI缩放；按宏流水计费 |
| 限幅比较 | 功率下限、误差±2、速率上下界；零与巨大指数差提前判别 |
| 除法/开方/其他 | 正常比值1次，限幅/下溢/同步保持可旁路；开方/三角函数0 |
| 独立查询生成 | 另1次97bit中点加及phase16舍入，控制器周期尚未知 |
| 状态访问 | 最多2×52bit输入寄存写，上一字/功率/速率/误差/两坐标更新；系数广播至4DSP |

服务时钟及诊断计数器的64bit递增、使能/仲裁/选通也存在，已计寄存位，逻辑/时序未综合；
每个除法位有索引及诊断递增。不能用平均零信号旁路代替持续有噪声输入的最坏工作。
状态只用寄存器，无新RAM端口；前端RRC/检测/相关/缓存银行仍分别计费。

新原始RAM及源读口为0；两输入字经额外104bit寄存接收，不免费借用原双回复寄存。
所选格式逻辑寄存上界2510bit，大格式2518bit，常数逻辑212bit；不是实际综合FF/LUT数。
其中持久状态、输入104、保留结果/标志160、DSP有效位流水516、互斥工作区320、
控制/时标224和7个64位统计分别计费。互斥工作区按功率、TED、乘积树、除法的最大值计，
没有同时保留全部历史；DSP原语内部固定资源已按4个计，不能当作可重分配的通用FF。

宽加法/比较/RNE暂假定1周期，功率6、TED峰值/移位/差3、比值预处理3周期；
规范化/优先编码宏只提供宏级排程与值，不是200MHz综合/布局布线保证。

| 精度 | 同步保持服务 | 非零且未限幅的跟踪服务 | 加原45边沿运输后的当前串行子图下界 |
|---|---:|---:|---:|
| 功率30/误差32 | 18 | 104 | ≥149 |
| 功率38/误差32 | 18 | 112 | ≥157 |

100/160/200MHz每4Msym/s符号可用25/40/50周期。
当前45边沿运输后仅余−20/−5/5周期，有限节点显然不满足；尚未计载波归一化、头及译码。
104/112只到NCO状态更新；下一查询的97bit中点加法、phase16舍入及端口交接仍需控制器
周期服务，不填零。因此表中求和是本串行结构的下界，不是完整反馈延迟。
立即取结果后还有一个输入信用冷却边沿；独立节点最小II分别105/113，输出阻塞另加等待。
因此数值实验节点保留，**当前串行实时结构拒绝采用**，不增加无限FIFO或放宽期限。
这些是已公开宏假设下的可执行节点结果与串行子图求和，非整链ADC调度，更非综合结果。

原512银行FT4初始化200MHz后约1039周期余量，也不足容纳126次串行18周期功率服务
及缓存读取。这是待接入实际生产者进一步复核的必要条件，不伪造资源丢弃包计数。
后续应优先评估有界同步功率统计复用、有限误差归一化及插值/反馈重排；先保留精确除法
作为数值对照，不通过降低SPS/盲减抽头或增加无界候选节省工作。

## 复现与证据

冻结根`timing-word-loop/`保存全部首版缺陷、输入/源码SHA、每符号实际DSP/除法状态、
帧、插值字及数值/周期失败。已选同步必须从原冻结`*-full-trajectory.npz`读取；
首版误读另一制品的字段导致退出，原日志/源码保留，没有用新插值改写同步答案。
原输入IQ只读，派生文件独立保存。

首轮远端CI44432949858在固定回归输入SHA检查退出：驱动误将跨平台生成的派生NPZ
压缩字节与冻结原件封装SHA比较。官方失败制品中的IQ、静默及载荷NPY成员与原冻结
索引逐字节SHA一致。修复复用捕获层已有的`verify_input_container()`，冻结原件模式
仍严格要求整包SHA；派生模式只接受全部成员大小与原始字节SHA一致的封装，并校验
父级manifest、冻结成员索引及已记录回执。结果同时保存原件及当前派生封装SHA，
不把派生文件标为原件。算法、参数、数值预算及期待载荷不变；已查看保留集重跑只作
修复回归，不重新选型，也不宣称是另一份独立保留集。首轮失败日志及完整官方制品保留。
