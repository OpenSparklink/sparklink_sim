# 统一接收资源账本（RX-D0）

当前结论：现有FT2全相位搜索图在原预算下失败；部分存储账面可容纳，
但尚未分配的状态、端口及包内工作不能算作零，**不是完整接收机周期验收**。
本阶段不改接收选择或波形，接收增益、量化损失均沿用上一阶段，不虚构新包改善。

## 冻结假设及计算边界

实现前在`unified-rx-predevelopment.json`冻结200MHz、16MS/s、18个signed25×18乘法原语、
54个宽加法/比较单元及16KiB逻辑状态边界（SHA
`e7402a4deb8092490b2c259945c503ccb54177d16d00fe503d0d312ca7027fa0`）。
这些是既有捕获模块工程实验约束，不是整片FPGA容量、整机预算或标准资源限值。
整机收发/译码/实时MAC/接口的资源规划另行冻结，不能因芯片有余量静默扩大本模块预算。
遵循PSK§6.2.1.2；81抽头仍是实现选择。

当前采用具体RRC12/C18/19成对乘积结构、两套scaled10差分银行、一个共享原始能量检测器，
FT2的32同步符号/SPS4/1/8采样全相位细搜索；FT3/4更长同步不由本表推断成本满足。
逻辑状态、操作计数、单模块周期结果与整链周期/综合证据分开记录。

| 模块 | 当前映射与计账 | 尚未闭合 |
|---|---|---|
| RRC | 每输入82个实系数乘积；专用8乘法、43宽、64小单元、12前导检测器；24900bit | 监测更新、ADC转换、跨模块端口仲裁 |
| 双scaled10银行 | 每银行16个分片原语乘积/输入，12390bit/银行 | 指数/RNE/最大值流水、工作/FIFO状态及端口排程 |
| 共享原始能量 | 16位检测输入预留，两平方乘积/输入，只计一次 | 实际检测格式、阈值及状态/周期 |
| 单音抑制 | 持续每输入14乘/19加、块及激活非线性另列 | 定点、状态位宽、归一化及周期；未免费包含于DSP必要下界 |
| 细搜索 | 当前复用后的每请求至少10605个实乘等效；最坏每32采样请求 | 插值准备/归一化/工作区/端口/延迟反馈 |
| 包内环路/头/载荷/Polar | 未分配，明确保留未知 | 有限结构、位宽、端口、缓存和周期调度 |

银行使用实际普通FT2同步模板及系数能量确定阈值位宽，不用全1模板代替。
其原始实乘图每银行4个差分乘积、2平方功率、2平方分子；
21位平方和28位平方分别按2和4个signed25×18原语分片，共16个原语乘积。
固定阈值按移位加法另计，不误算成变量DSP；原始能量只在双银行之外计一次。
这些映射可由其他结构改变，但改变后须重新给出精度/成本证据。

仅RRC、两银行、检测及乐观细搜索的当前图需
`(82+2×16+2)×16M +10605×500k =7.1585G`原语乘积/秒，
18×200MHz只提供3.6G，必要乘法器数至少36。
细搜索中的每个宽变量乘积甚至只按一个DSP计，单音、样条准备和包内处理均未加入，
因此此失败有效；不是对所有重构/LUT乘法接收架构的全局不可能性证明。

保留已建模RRC的8路专用分配后，其余10路要先承担双银行和检测，
剩余最乐观每请求2912乘积，或当前10605图最多137293.73请求/秒，低于500000最坏请求/秒。
这仍忽略单音/插值等工作，**不能把2912当作已分配可用的完整细搜索预算**。
后续有限粗候选/有限相位须满足全部预算，不能直接重用已因0.155438采样起点差异被拒绝的local4。

## 分离状态和访存

| 不重叠分配 | bit |
|---|---:|
| RRC历史/系数/拥有乘积/流水/描述符 | 24900 |
| 双scaled10银行 | 24780 |
| 双384采样滤波历史，46bit/复字 | 35328 |
| 三个拥有的256采样细搜索窗，46bit/复字 | 35328 |
| 三个细搜索描述符 | 768 |
| 已知部分合计 | 121104 |

合计14.7832KiB，16KiB剩余9968bit（1246字节），并未容纳全部前述未知项。
若采用旧Q12排序环另加7464bit，仅剩2504bit；排序方案的召回损失仍必须单列。
46位历史是RRC19+19+8字的设计预留，单音/细搜索能否满足此格式的误差预算**未验证**。
物理RAM复制、BRAM粒度、选择网络及全部流水不能免费忽略。

RRC已要求8个原始字读/周期及1写、4系数读、4个乘积银行各1读/1写。
窗口复制另需每周期8源读/8目标写及持续历史写；不同存储不可凭相同地址或不重叠平均负载视为共享端口。
旧固定22位/单银行周期分配127874bit（15.61KiB）包含旧FIFO/工作寄存器，
既不是本双scaled10结构的完整状态，也不能机械加到新银行上或复用其II结论。
当前宽单元在RRC之后仅剩11个，其余尚未排程；小单元没有完整整链分配，不能据宽预算通过推断总逻辑满足。


`whole_rx_acceptance`也保持False，缺失调度不能用大预算变成通过。
报告列出每模块操作/位宽/状态/端口、未建模项及源码/依赖锁文件SHA；CI测试制品保留同一资源JSON。
没有整链可执行周期、延迟反馈或综合/时序结果，不宣称16MS/s整链、实时FPGA或完整SLE验收。
