# 目标窄带SLE整机资源与并发账本（SYS-A）

[移动合法尾界](moving-tail-horizon.md)的444bit/19沿节点相对静态界多38bit，
IQ RAM/DSP/端口不增加，但重复请求由每集合6次增至2867/2672/1852次，整包无增益，
已拒绝。输入保护/宽比较和复制流量另计，不能把状态小当作整机计算免费。
两次去过期诊断恢复只指向保存/调度缺口，不改变正式结果或放宽TX/译码/MAC预留。

[实际捕获→有限初始化桥](initialized-capture-bridge.md)新增单个1024×46私有1R1W
滑动历史（2 BRAM36）和628bit桥控制；原全局源、窗口、选定缓存不抵扣。
初始化/帧19DSP与相干1DSP未证明可共享，原18DSP/16KiB失败继续保留。
端口仲裁、总LUT/FF、载荷服务及整链100/160/200MHz期限尚未知；
不能把已建模前缀或功能交付当完整16MS/s，也不侵占TX/译码/实时MAC/接口预留。

[有界头预取](initialized-head-prefetch.md)只比较同一1024字私有源的复制调度：
新增84bit状态、单profile88bit常量及接纳21bit加法，桥预留628→712bit。
没有新增DSP、BRAM或读端口，不代表复制工作量免费；端口等待与丢弃逐窗记录。
多profile、控制LUT/FF及整链期限尚未知，原预算失败不改写，候选不自动成为默认。

整机规划现在与RX算法同时推进；RX验收门前仍不展开大规模TX实现。
当前只完成一个可审查的资源/并发下界闭环，**目标整机资源、截止时间和16MS/s尚未验收**。
18DSP/16KiB是既有捕获模块约束，继续有效，不是芯片总容量或整机预算。

[有限 B1 软译码](payload-polar-flow.md)估算 33/37 RAMB18 等效，
独立银行站点上界为 27 BRAM36，含两输入槽及全驻留几何 ROM。
现有候选余量下还需为其他 RX、TX 和实时 MAC 保留空间，尚未证明可部署。
200 MHz 两路最大帧组 18/906 字因两槽满载丢失，需继续缩短末块服务或
证明有限的 RAM/端口共享。码块拼接与 CRC 周期尚未纳入。

[压缩 B1 几何表](payload-polar-geometry.md)将译码器独立站点容量
估算上界由 27 降至 18 BRAM36，含两输入槽与有序结果保存。
同量化精度下各字更快，时序调度仍产生新丢帧，因此未计入可部署
资源节省。译码、TX、实时 MAC 的整机共享和截止时间仍待证明。

[B1 输入槽提前释放](payload-polar-ingress.md)保持两槽六银行，
200 MHz 两路新保留由 168/288 丢帧降到 55/288，同时有一个新丢。
所有权接口、错误描述符、CRC 与整机期限仍待合成及联合验证。

[有限 B1 帧服务](b1-payload-service.md)新增一个 2044 字节数据银行
及双 CRC、控制和帧身份。保留帧占用输出 RAM 时，后续帧在独立
新保留中出现 4 次资源忙失败。整机预算包含此银行并保留未验证
的头/载荷衔接、MAC 阻塞和时钟证据。

[定点软解映射](psk-word-demap.md)估算 3 DSP、513 位常量、632 位
主状态，无新增数据 RAM。第 24 沿交付的组件模型含导频间隔和译码口核验。
倒数准备、归一化/载波校正和其前后的实时占有、时钟和端口继续单列。

[PSK 同步残差增益](psk-sync-gain.md)估算新增 1 DSP、398 位
主状态和零数据 RAM。末符号至增益 23 沿，端口可与定点软解映射对接。
模板、归一化、完整载波及头部时限的联合时序继续保留，未计共享收益。

[B1 已选载波与载荷交接](psk-selected-carrier.md)另计 6784 位后缀
缓冲（128×53、1R1W）、72 位输入寄存与指数移位逻辑。现有 B2、
增益、软解映射和头/译码各自成本继续有效。B2 需要 42 沿，
160 MHz 的每符号 40 沿无法供给。200 MHz 的单帧服务局部可用；
上游节拍、连续帧、共用端口和整机资源仍待验收。

[B1 后缀环](psk-selected-carrier.md)将上述
原型的 53 位 RAM 项改为 36 位。128 项占 4608 位，队头缓存和控制
另计 63 位。1R1W 同步读与空队列前递，局部无新增周期或 DSP。
按器件宽深估算由一整块 BRAM36 缩为一个 RAMB18E1；
时序、实际布局和剩余半块的共享未证明，旧 16 KiB 失败继续保留。

[紧凑 N256/K51 B1 头银行](control-polar-word.md)将实际 parity
调度的逻辑位由 32841 降至 13963，RAMB18 等效估算 6→5。
站点上界仍为五，四个数据银行 2 端口及单读 ROM 独立记账。
SSC 4042 沿，未复用已分给载荷 Polar 或 TX 的银行。新的 160 MHz
头时限通过部分选定实验，B2 及整机 16 MS/s 验收保持开放。

[B2 并行 PI](carrier-fixed.md)把已选载波的可见延迟 42→39 沿。
另计第二路 RNE、额外 34 位加法与 34 位状态预算，共用原两读
ROM 和 6 个实乘 DSP 的估算。160 MHz 已选 B1 路径的收敛及
共享资源需要从实际入口再核对，原始 ADC/RRC、译码、接口与
TX/MAC 的共用和物理时序仍未验。

[已选归一化多帧日历](psk-selected-carrier.md)把共享的 B1 头/载波和
实际 Polar/CRC/MAC 放进同一时钟。单路前端复用原后缀 RAM，需留
独占结束沿与 LLR 拍失败的回滚控制。合法包尾与相邻候选起点重叠时
仍可能必须丢候选，因此维持整链吞吐门和 ADC/定时生产并发缺口。

[末码字暂存实验](payload-polar-ingress.md)另计 1152 逻辑
LLR 位、3 个单口银行和至多 443 位控制/寄存及额外描述符。
可估 27 个 RAM64X1S 的存储位片，备选是 3 个 RAMB18 的
独立银行上界。合规时序和整机布线仍未验。单帧 ADC→MAC
吞吐和有阻塞多帧采用门维持开放，候选的原成功退化有单独证据。

[MAC 共享环形字节 RAM](b1-payload-service.md)保持 2044 字节，
按相同容量的一读一写真双口映射估算。额外 377 位地址、
描述符和控制，至多三帧预留。含末码字槽的压力保留仍有
2 次容量退化，通用采用失败，实际跨 RX/TX/MAC 的存储和
截止时间仍待验证。

该基础工程SYS为100MHz，匹配布线WNS+0.044ns、TNS0、WHS+0.035ns；

[两位商定时结构](timing-radix4.md)为显式精确实验：额外51bit寄存器、无新DSP/源RAM/端口，三路51bit比较与选择减法未验证Fmax；当前串行子图仍至少128周期/符号，24新旧连续前缀全部资源退出。不能挪用TX/译码/实时MAC预留来宣布通过。

[数据期定时/归一化联合调度](data-joint-service.md)使既有两套4DSP银行同时工作，新增128bit公共控制，无新源RAM/端口。两银行原本分别计费，不能另外计共享收益；若未来改成4DSP时间复用，就会失去本次并发收益，必须重算期限。当前非旁路子图约120周期/符号，连续场景仍溢出，不改变TX/译码/实时MAC预留和四项总门。

## FPGA与ARM分工及范围

B1长度独立反例已在浮点严格路径修正，详见[B1长度合同](b1-length-contract.md)。
其有限整数几何节点另见[帧几何](head-length-words.md)：实际常量减法/零分支与串行除乘，
FT2/B1最坏181/69周期；标量节点8452/7684bit，DSP/RAMB18为0的分布式LUT/FF估算，
完整LUT/FF及Fmax未知，不能加成整链已通过。真实有限头部服务已显式接入，详见[CRC后帧消费](head-word-gate.md)。
[实际55位字头交接](live-head-replay.md)已补头部硬判决、收集和注册服务，
组合头状态为A2 20247/20255bit、B1 44129/44133bit（dense/parity），
RAMB18分别3/5与6/6，BRAM36站点上界3/5与4/5；组件DSP为0估算。
这包含原SSC、CRC和几何，不能再与子节点重复相加。
回放控制另增129bit，其中128bit统计已在公共控制总量中计入。
标准与legacy的两组头后连续前缀都保留资源失败，载荷/译码及整机并发调度仍开放。
本项真实CRC/字段/长度变换已有组件注册周期，额外12位回执另计，完整端口仲裁及综合仍未知；
不把头部语义正确当成全链定点、整机资源或16MS/s通过。旧B1自回环矩阵显式保留legacy合同。

机器可读清单为[system-target-ledger.json](system-target-ledger.json)，每功能包含放置、并发、
位宽/端口、II/延迟缺口及LUT/FF/DSP/BRAM区间。无可靠估算的上下界为null，
明确表示未知，不是0或已获资源。新的可用系统预算必须在相应验收前冻结。

| 功能 | 规划位置 | 决策依据及缺口 |
|---|---|---|
| 数字接口、CDC、连续滤波/检测/同步/插值/环路 | FPGA | 逐采样、无法容忍Linux抖动；接口/位宽/流水需闭合 |
| 头部CRC/解析、载荷CRC/加扰、必要BCH/速率匹配 | FPGA期限路径 | 实际profile使用范围逐项审计，不能按模块存在推断整链 |
| Polar译码/编码 | 优先评估FPGA；ARM须先证明最坏服务 | 现有硬件Nmax512/LLR16仅独立参考，目标MCS/codeblock RAM/周期尚未映射 |
| TX组帧、映射、成型、量化、确定输出 | FPGA；ARM提供已准备数据 | 现在预留资源，不提前大规模实现；发包后欠载明确中止，禁止悄悄插零 |
| 精确TDD、跳频触发、即时响应、ARQ执行、时间戳 | FPGA实时MAC | ARM只给策略/上下文；响应间隔、RF转向及完整期限尚未冻结 |
| AES-CCM包处理 | 按实际安全profile有条件配置 | ARM管理密钥/策略；位置按认证/回复最坏截止时间决定，不按平均CPU耗时 |
| MMIO/SPI/DMA/缓冲代次/恢复所有权 | ARM独占内核+FPGA数据/执行 | DMA带宽/QoS、描述符、完成预留必须显式计费 |
| 建链、协商、配对流程、一般管理/业务策略 | ARM | 不承担无法容忍软件抖动的逐包实时动作 |
| 调试/IQ观测/统计 | 有界FPGA+ARM收集，可选 | 单独收费、不可反压实时路径；满时丢诊断并计数 |

首要目标为单射频窄带4Msym/s QPSK/8PSK、16MS/s，FT2/3/4的严格模型覆盖见`rx-scope`。
FT1/GFSK独立验收：既有硬件1M固定profile证据不替代本模型完整16MS/s连续MAC接口。
UWB、多音、未知厂测编码前缀及未定义多连接并发在本版范围外，不虚构支持。

## 最坏并发和共享条件

```{mermaid}
flowchart LR
  ADC[连续ADC与下一包捕获] --> RXT[当前包尾处理]
  PREV[上一包Polar译码] --> AUTH[CRC与可选认证]
  RXT --> AUTH
  AUTH --> RESP[实时回复决策与截止时间]
  PREP[下一包TX准备] --> ENC[编码与可选CCM]
  ENC --> PREFILL[有界TX预填充]
  RESP --> PREFILL
  PREFILL --> DAC[定时首采样与连续DAC]
  DMA[DMA与包缓存仲裁] --> PREV
  DMA --> ENC
  DMA --> PREFILL
```

RF的RX/TX互斥不消除上述处理重叠。上一包译码可能覆盖下一包捕获；RX尾部/认证仍在运行时
必须准备下一包TX；编码、CCM与DMA可能同时请求包RAM。密集包、最长包、持续候选及下游阻塞
不得由空闲平均负载替代。共享候选须计上下文、仲裁、RAM端口复制、清空/重装和切换时间。

已经验证的是算法层的一次RRC输出分送原始/单音支路、银行差分/能量及重叠窗复用。
RX/TX乘法器、Polar编/译码、双向CCM、RAM/DMA的**整机硬件共享尚无已证明收益**。
`calendar_conflicts()`验证显式半开周期区间及资源数，不因TDD自动免除重叠；
测试中的前包译码/后包准备重叠反例是合成压力日历，不冒充实际协议期限或完整数据流模型。

既有实时MAC草案的`response_interval_ticks=null`，完整目标响应期限仍未知。
必须满足`RX尾部+译码/CRC/认证+决策+准备+RF转向+TX释放+余量≤实际profile响应间隔`；
当前不能把未知项填0后宣布回复可行。标准条款、RF转换及端口服务最坏界将由后续SYS-B补齐。

## 物理存储及工作量敏感性

[AMD RAMB36E1](https://docs.amd.com/r/2025.2-English/ug953-vivado-7series-libraries/RAMB36E1?contentId=Nm2aVbtVbH5UQNZ3PFqKqw)
的TDP模式以1/2/4/9/18/36位×对应深度计费；36Kb包含奇偶位，可用宽度依模式而异。
`bram36_layout()`明确一端口读、一端口持续写，多读用副本广播写；不把1R1W算成2R1W。
它是一个具体映射估算，不是所有银行化/LUTRAM/不对称端口方案的最优下界。

| 直接映射候选 | 逻辑内容 | BRAM36 |
|---|---|---:|
| RRC原始128×32bit历史，8读/1写副本 | 4096bit，不含复制 | 8 |
| 四个拥有乘积银行，每个33×69bit，1读/1写 | 每银行2277bit | 8（4×2） |
| 每个384×46bit滤波历史，8读/1写副本 | 17664bit | 16；双路32 |
| 草案五个独立2048字节包槽 | 10KiB | 5 |
| 同五槽合并32位池的容量估算 | 10KiB | 3；仲裁/并发未证，不能先记共享收益 |

仅上述RRC及双滤波历史的直接副本映射便需48BRAM，超过25%预留候选下的32个新增额度，
还未含其余功能。这拒绝的是该直接映射与该候选预留的组合，不等于芯片不可能容纳目标系统。
合理下一步是证明银行化/时间复用/LUTRAM和生命周期，或有证据地调整系统架构；
不能把16KiB逻辑状态直接除36Kb当物理BRAM资源。

32位复IQ在16MS/s每方向最低64MB/s；同时捕获与输出准备可要求128MB/s原始搬运，
尚未含描述符、对齐、重复读写、FFT/译码和DDR竞争。现有基础构建没有目标DMA，
这只是带宽需求，不是DDR服务能力证明。长下游停顿必须有限准入/丢弃，ADC不能暂停。
规定业务负载需保证不丢；持续干扰过载允许有界运行并明确丢弃，算法漏检和调度丢弃分别报告。

载波有界权重、有限候选及相干确认已有分阶段证据，仍为明确的实验配置；
最新一步初始化因新保留集61→60退化而拒绝，不用旧集61→62替代验收。

## 有限相干确认的交错算术（M34，显式实验）

[交错确认](interleaved-coherent-confirmation.md)在原 M33 专用单 DSP 上复用 signed22×18 原生乘积，
增加一个 ALU32、三个在途上下文及全部队列/选择网络。新节点及交接控制 8067 bit，
与原帧所有者共 9554 bit；替换 M33 节点时寄存状态净增 2906 bit，不能把两节点叠加或漏算队列。
原系数 1 RAMB18、模板/CORDIC ROM、单选中缓存读口不变，无新增 IQ RAM/源端口。
4 路 275 bit 请求选择、4 路 256 bit 回执选择和每沿最多一次 issue/take 均单列。

在新开发/冻结独立各 12 包中，完整交付由串行 6/3 提升至 8/5，与浮点确认 8/5 相同；
这修复已证明的局部调度损失，不提高浮点接收边界。局部整数值精确，
没有降低旧数值或误检要求，没有使用 CRC 挑路径，也未抵扣 TX、Polar、实时 MAC 或 DMA 预留。
100/160/200 MHz 的整机调度、98>50 沿定时反馈、原数值失败及全系统资源缺口仍在。
本节点没有新增综合或布局布线证据，不能据此宣称完整 16 MS/s。
