# 全局样条的有限字长节点（SYS-B3B）

本阶段把SYS-B3A的相同全局样条准备与固定八分之一相位求值实现为整数节点。
标准关联是同步§6.2.3；定点格式、公共指数和插值器都是接收实现选择。
默认接收器、同步评分、候选数量、相位网格、门限、峰值等待、Gardner/PI和载波处理不变。

## 格式、尺度和数值规则

在新开发组合上比较源分量18/21/24位、系数小数14/16/17位，共九种格式。
工作节点保留四个带符号保护位；在被比较的格式中，按先源宽再系数宽选择满足全部门的最小格式。
选定**18位源分量、22位工作分量、14位系数小数**，不是任意格式的全局最优证明。
实际采用规则和参数保存在`tests/data/spline_fixed_format.json`，关联第一次新保留评价前
已经写入的`selection.json`的SHA。驱动还核对数据通路AST哈希，后续成本/诊断增强没有改动通路或参数。
原成功压力样本只用于否决退化，不用于选择另一种格式；新保留失败后不能换格式重试。

窗口已经完整拥有后，扫描最大分量，选择共同的带符号10位二次幂指数；转换完后保持不变。
这是因果的**窗口预处理**，新增扫描和对齐延迟必须计费；不是逐采样即时AGC。
公共指数不增加ADC有效位数、不改善信干比，强弱同时存在仍可能丢失小分量。
浮点输入构造器只是参考边界；`from_rrc_words()`使用真实实验接口的19+19+8整数输入，
用19位归一化幅度比较及指数比较选最大值，再执行有限移位、guard/sticky和RNE。
单独测试实际`FullMantissaRRC`字及±128指数边界；不因此清除该上游的量化失败。
浮点边界的`2^±220`窗口只测缩放后的节点数值，超出19+19+8端口可表达范围，不能当作实物动态范围。

存储节点、加减和幂二移位显式有符号饱和，所有完整乘积保留到RNE后再缩回工作宽度。
RNE为最近偶数，负数对称；越界、非有限输入、不支持长度、非八分之一查询及指数溢出明确报错。
每次最多128个窗口内查询，没有外推、无限历史或未来包样本。
相位CSD累加器为33位/实分量，分母1024，最后RNE；整数相位直接取源字。
溢出次数、节点、被舍零分量和位增长保留；显式搜索接口遇到饱和会报错，不把截饱和的分数当成功。

## 系数与DSP数据通路

消元系数从精确有理方程在离线生成。C0=2使用硬移位；末端倒数拆成`2+α`，
只将分数部分α送乘法器，不把含整数2的无符号宽系数误叫成一个18位有符号DSP操作数。
选中格式的系数是带符号15位、工作操作数22位，完整乘积37位，
当前分片规则下每个实系数乘积一个DSP25×18原语；24位源/28位工作候选则需要两个。
这仍是原语映射估算，没有新综合或200MHz反馈路径的时序证据。

量化后的C表和末端α表尾部各自为常量，按短前缀加常量尾保存，逐项与未压缩1275字核对，
**量化后的每个系数字精确一致**。选中格式合计10字、150个逻辑常量位，
并非把14位量化误差也说成无损。其他被测格式为11–12字。
小型常量可用LUT实现；地址比较、选择器、广播/复制和路由没有综合证据，不将其成本填为零。

## 冻结预算与结果

新定点节点预算在生成新数据前冻结为相对窗口峰值误差`2e-4`（0.02%）。
它不同于浮点结构`2e-12`及上游RRC局部2%预算，不能相互覆盖。
另外保持分数误差0.005、起点误差0.125采样、相对采样轨迹0.25采样、零饱和、
原成功零丢失、固定负例零新增候选和误交付。

开发/保留改变了载荷模式（斜坡/零与FF组合/随机）、合法帧型、MCS、长度、导频及干扰组合，
不是仅换种子。波形比特/相位排列和脉冲来自独立参考；现有标准编码器仍被复用，
因此不把自回环当作全部标准互通证据。真值只在接收选择之后用于关联误差和BER。

| 评价 | 浮点基线 | 选中定点节点 |
|---|---:|---:|
| 新开发8个合法包捕获/头CRC/数据CRC/完整载荷 | 8 / 7 / 5 / 5 | 相同 |
| 冻结后新保留8个合法包 | 6 / 6 / 5 / 5 | 相同 |
| 原SHA绑定成功包，整段/257固定块/随机块 | 完整正确 | 全部保留 |
| 新定点保留窗口100个 | 全局样条参考 | 最大相对误差4.006e-5，0饱和 |

开发九格式各100个数值窗口；独立节点真值另有多项式、极值、精确Fraction舍入和实际RRC字测试。
数值审计在每窗至多97个预定义点观察，实际搜索对照覆盖接收器请求的九相位；
不将抽样验证写成任意输入的解析误差上界。开发完整采集12个实际细搜索窗口用于格式比较，
不依靠期待载荷、CRC或真值筛选窗口。选中格式在完整接收对照中逐次检查所有搜索。
格式已冻结后只评价这一个格式的新保留，整段/固定块/随机块判定及轨迹分别比较。

**接收收益0，已观察的量化新增整包损失0**。开发3个失败（坏头及14/3比特错误）、
保留3个失败（2漏检及3比特错误）继续保存，不能因为定点不退化就叫这些包恢复。
误差/BER只针对已关联并实际观测到的符号；坏头、未捕获或长度不匹配时不能计算整包BER。
保存的CFO真值误差是捕获初始估计，不能代替后续整包载波细化的误差。
原35个压力失败与61/96正式结果不变；未知厂测编码前缀、FT1/GFSK及更多配置不由本阶段推断支持。

每组另有4个按配置生成的背景负例：开发50540采样（3.159ms），保留34759采样（2.172ms），
各观察到0候选/0交付。保留组`burst_step`负例是增益变化前的背景，
没有覆盖与该正例完全相同的强弱切换；这个缺口不能用本次零误检覆盖。
`model.json`、每流`summary.json`给出实际样本数、触发/预筛/搜索/
候选/头CRC/数据CRC计数，可以按实际样本量计算每百万采样数量。
只有有限观察中的零新增候选/交付，重复分块不重复计入负例观察时长。
全部输入NPZ/元数据、节点结果、每次搜索、坏头、CRC失败及轨迹均保留在清单中。

## 计算、存储与调度

256点准备仍有1018个实常系数乘积、原4092个加减，末端拆分额外2个实加。
另外逐点扫描最大值、输入对齐各256次，涉及绝对值、两路前导检测、比较、
两路桶形移位和RNE。运行时准备不使用除法或开方，评分与载波仍需各自实现。

| 单个活动256点节点的估算 | 数量 |
|---|---:|
| 额外量化源/工作信息 | 20480bit（2.5KiB） |
| 两者具体TDP36×1024映射 | 1+2个BRAM36 |
| 连同在途、最大值状态、控制/监视预留与常量的额外信息 | 22886bit（约2.79KiB） |
| 已有捕获部分信息下界加本节点 | 173010bit（约21.12KiB） |
| 包含扫描/对齐排空的串行地址日历 | 1544周期 |

原始46位窗口另由既有搬运模型计费，不免费覆盖/借用其填充空间；上表使用分离缓冲，
是具体保守映射，未证明为BRAM最小值。监测位增长的可选LZC、选择和更新排程仍需验证。
节点先范围扫描排空两周期，再对齐写入排空两周期，之后才开始递推。
地址日历逐项检查两读源、Q一读一写及原位覆写期限；插值阶段Q可双读，不能同时另行写入。
它是可执行端口/期限情景，不是逐周期定点算术RTL或时序证明。

只收准备、让评分免费，4096采样的121个每32点请求在100/160/200MHz
仍分别队列丢弃103/94/87个；每256点请求的16个均完成。
因此单引擎最坏吞吐已经不满足，实际评分/确认/包内工作只会增加约束。
这些是资源请求丢弃，不是实际丢包率；算法漏检在前面的实际接收结果中单列。
16MS/s、200MHz每400周期一个最坏请求，单准备至少需要4个并行上下文；
376/632点准备分别需6/10个，尚未安排评分和候选反馈，原三拥有槽不能免费升级。

若保持前阶段条件小计89BRAM，单节点小计92；四节点的缓冲小计101，
还需第4个拥有的原始窗口2BRAM及384bit描述符，保守部分小计103。
不能免费提前释放原始槽而没有相应所有权/端口证明。四上下文的端口/期限尚未验证。
再用尚未批准的25%整片预留35，四节点后仅剩2个BRAM，而粗筛/包内载波/Polar/TX/MAC/DMA等
仍未全部分配；不能把这些剩余块当成零，也不能按TDD直接共享它们。
未缩放的22位评分直接图还涉及45位差分、51位相关及更宽功率，不能沿用一个任意乘积一个DSP的假设。
该评分数据通路仍浮点，宽度图是后续设计依据，没有通过评分定点或整链16MS/s验收。

用户授权后可依据收益/精度/端口/截止时间论证新的工程预算。
当前约21.12KiB单节点、含第4原始槽/描述符约30.98KiB四节点的信息量是规划输入，
**没有将原16KiB失败重标为通过，也未在本阶段批准32KiB整机预算**。
上游RRC的2.34835%>2%反例保持有效，本节点通过不能替代它。

## 采用结论及复现

保留18/14格式为显式实验节点：
`search_candidate_grid(..., interpolator="word-eighth", spline_format=SplineFixedFormat(18,14))`。
主流水线尚未提供默认选项，脚本对主接收路径只替换此函数，其他处理仍按原方法执行。
具体而言，能量检测、单音、RRC、评分/相干累计仍有浮点部分；
同步成功后接收器会用原四点局部插值重新取同步样本并做浮点载波初始化，
包内定时/载波、软信息及译码接口没有由本节点变为全定点。
因此起点不变时后续采样轨迹相同，并不证明这些下游节点已经通过定点验收。
下一阶段优先准备计算复用/有界并发与评分归一化，补齐真实端口、反馈和译码/TX期限。

```sh
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_spline_fixed.py \
  --output /tmp/sle-spline-fixed
```

输出目录须不存在。预期返回1：节点通过与资源/整机未通过分开记录。
依赖、源码及原始输入SHA在`protocol.json`、元数据及递归`manifest.json`。
`selection.json`在生成新保留前写入；冻结参数/通路哈希不符时拒绝评价，不自动选择别的宽度。
实际Rust环境只加速原有支持模块，本整数节点本身是Python，不混用墙钟结论。
