## 检查规则

`check_test_shards.py`检查各JUnit失败、错误、测试数、重复身份和时长；合并后端检查要求每片的提交与实际加速能力一致。覆盖率从当前七个真实独立进程的数据合并，不用覆盖率数值代替关键反例。新划分不改变源算法、冻结参数、接收能力或任何FPGA计算/存储预算。
