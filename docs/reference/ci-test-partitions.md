CI的测试运行时长门与接收算法、数值、资源和16MS/s验收分开。当前为core/front/rrc/head/replay五份互斥分片，Python/Rust单元作业各五片；独立Python覆盖率也执行相同划分。每片必须小于120秒，合并覆盖率至少90.1%，失败仍上传JUnit、日志、后端身份及诊断。

## 检查规则

`check_test_shards.py`检查各JUnit失败、错误、测试数、重复身份和时长；合并后端检查要求每片的提交与实际加速能力一致。覆盖率从四个真实独立进程的数据合并，不用覆盖率数值代替关键反例。新划分不改变源算法、冻结参数、接收能力或任何FPGA计算/存储预算。
