# 全局样条的有限准备与固定相位结构（SYS-B3A）

本阶段保留现有全局、均匀网格、not-a-knot三次样条，将长度相关的消元系数预计算，
按一次前向/反向扫描准备二阶导数，使用固定八分之一相位的移位加法。
它不是此前因起点误差超预算被拒绝的四点局部替代，也不改变Gardner/PI包内环路。
标准关联为同步§6.2.3；这些是接收实现选择，不是标准规定的插值器。

## 接口与验收范围

`search_candidate_grid(..., interpolator="uniform-eighth")`为显式低层实验接口。
默认仍是`"reference"`，主流式接收器没有自动开启这个节点。
保持相同整数候选、归一化差分评分、九相位位置、排序、最大峰等待和相干确认。
不使用CRC、载荷或真值选择答案；回归脚本只替换插值函数，其余接收流程不变。

节点拥有4–640个有限复数样本，查询至多128个窗口内的精确八分之一位置，
不外推、不隐式读取未来输入。窗口未完整拥有时不能准备；跨块收集及源过期由既有
有界搬运模型处理。准备后样本与二阶导数只读。包间不重用另一窗口的导数，
EOF不伪造新同步样本。这不等于已经完成所有上下游的连续输入集成。

实现前冻结浮点相对峰值误差`2e-12`、幅度`2^-220..2^220`及采用规则。
先保留独立解析三次多项式真值，再与SciPy1.17.1全局参考比较；
输入包含旋转PSK、强弱切换、脉冲、单音噪声、零和常量。
早期静态复制的参考源码实为系统SciPy1.16.2，原文件及误标记录保留在冻结根；
实际比较一直运行锁定1.17.1，首尾方程重新核对，驱动现自动记录实际导入源码SHA。
独立窗口验证改变长度、尺度和组合，增加双音、混合幅度、随机游走及短突发，
不是仅换种子。所有输入和两种输出均保存；这不是新的RF捕获验收集。

| 对照 | 数量 | 结果 |
|---|---:|---|
| 开发窗口 | 320（含40个独立多项式） | 最大相对误差1.223e-15，0超预算 |
| 冻结后窗口验证 | 175（含35个独立多项式） | 最大7.773e-16，0超预算 |
| 配对搜索（1/2峰） | 48 | 最大峰位置、评分与等待判定通过 |
| 原成功合成IQ及两种固定负例，整段/固定257/随机块 | 18条后端/分块路径 | 交付相同，轨迹按原0.25采样预算检查 |

正例只有**一个原成功包**，不能据此宣称弱包收益或完整支持矩阵。
负例只有静默与原静默噪声片段重复组成的32768个不同输入位置/后端，
16MS/s下2.048ms；三种分块不重复计入观察时长。没有新误交付不代表全环境零误检。
这是软件浮点结构验证；18位系数、64位工作字只是成本情景，**没有通过定点门**。
没有测得新接收增益，原61/96正式计数及一步载波初始化的退化结论不变。

## 数据通路及运算

前向准备斜率的右端项，再用预计算消元系数；反向在同一工作区覆写为`M=y''`。
首尾满足实际not-a-knot方程，末端二阶导数单独暂存到最终写回。
固定相位`t=m/8`的四个整数权重、共同分母1024为：

```text
128*(8-m), 128*m, ((8-m)^3-64*(8-m))/3, (m^3-64*m)/3
```

对`y[i],y[i+1],M[i],M[i+1]`以有符号数字展开后累加，最后右移10位。
当前浮点实现用`ldexp`执行这些移位；未来定点必须重新验证中间增长、舍入及饱和。
等宽操作数的展开临时和预留11位增长，不代表M与输入天然同幅度。

| 256点窗口、32同步符号、一峰九相位 | 每请求 |
|---|---:|
| 准备实常系数乘积 | 1018 |
| 准备实加减 | 4092 |
| 准备源读（含逐点范围扫描，边界重复值寄存复用） | 1280 |
| 工作区读/写 | 511 / 512 |
| 固定相位插值变量乘积 / 实加减 | 0 / 3200 |
| 插值源读 / 二阶导数读 | 544 / 512 |
| 差分、功率及相关幅度的原乐观乘积图 | 1413 |
| 原相干确认乐观乘积图 | 324 |

只消除了固定相位求值中的1536个通用Horner乘积情景；
不能把它当作整请求净节省1536个乘积，旧图未计入准备而新图明确收取1018个准备乘积。
还需归一化、比较、角度、端口和包内处理。常系数乘积的实际DSP分片待格式验证，
不将一个任意宽乘积计为一个DSP。窗口复制已在SYS-B1计费，本表单列、不重复收费。

639+637个配置常数在配置期求倒数，运行时准备无除法/开方；
评分仍需其原有归一化处理，不能声称整个捕获链无需除法。
参考ROM是81664bit浮点值；18位候选ROM为22968bit，精度、符号扩展和实际原语映射未验证。

## 端口日历、吞吐与整机账本

`preparation_calendar()`产生逐周期地址日历：源RAM每周期最多双读，工作RAM单读/单写，
范围检查256周期，前/反向各514周期，共**1284周期**。
两周期反馈、边界暂存及最终写回已列入；数据运算、路由和时序仍是假设，
这是可执行地址日历，不是完整定点算术周期模型或综合结果。
准备与其他窗口不能同时占用这一个引擎；不借用RRC、TX或译码的未排程空槽。

把准备服务时间接入既有三拥有槽、384点历史、双输入路径的TDP搬运模型。
100/160/200MHz均覆盖每32点请求与每256点请求，保存所有队列满和源过期。
32点请求在200MHz每400周期到达，单准备已经1284周期，**当前串行引擎无法持续承接**。
4096个输入点共121个请求，100/160/200MHz分别因队列满丢105/95/89个，
没有新的源过期；每256点一次的16个请求在这段有限日历中均完成。
评分/确认服务仍为乐观预留，不能从有限模型完成推导16MS/s全链通过。
资源丢弃按请求计，与算法漏检、丢包分别记录。

在64bit工作字情景，一个串行引擎额外256字工作区按双口36bit切片计2个BRAM36；
三并行上下文为6个，不能把所有拥有槽默认等同并行引擎。
另列1024bit控制/在途预留（8个64bit活跃数据字、256bit控制、256bit计数），尚非综合FF数。
插值需要源/工作各两读，准备日历的一读工作口不能自动证明插值端口满足。

前一阶段整机条件小计89BRAM加串行工作区为91，三上下文为95；
若仍采用**未批准**的25%整片预留35，则分别剩14/10BRAM。
尚须为系数口、粗筛、包内载波、Polar、TX、实时MAC/AES和接口明确分配，
这些不是零成本。100/160MHz既有RRC丢弃仍有效，200MHz只有旧基础100MHz时序证据，
本轮没有新综合或布局布线证据。

## 预算调整与后续验收

用户已授权在有必要、性价比合适时调整工程实验预算。
后续可比较精度、接收退化、存储、端口和最坏截止时间的折中，形成前瞻新预算；
旧2%量化与16KiB下的失败、输入SHA和报告继续保留，不能重标为原预算通过。
标准硬限值与工程实验预算分开，不因这项授权放宽标准要求。
本阶段仍使用原先冻结的浮点预算，没有据结果临时提高通过线。

候选仅保留为浮点结构节点，默认接收器不变。下一阶段先在新动态范围开发组合上
扫描有限的系数/工作格式，冻结后评价新的独立节点及原始IQ集合，
同时研究跨窗口准备复用或有界并行调度，避免仅加FIFO掩盖过载。
只有数值、端口、并发、误检和整机预算都完成相应验收后才考虑集成或扩配置。

PYTHONPATH=src uv run --frozen --no-sync python scripts/model_spline_preparation.py \
  --output /tmp/sle-spline-preparation
