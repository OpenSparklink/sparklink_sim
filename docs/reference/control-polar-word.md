# 头部硬判决 Polar 的有限整数与银行模型

本实验补上已经选定头部码字的一个服务点，尚未接入完整未知起点接收周期路径。
不改变现有 SSC 算法、硬判决可靠度、同步候选或默认接收器。CRC 明确为
`not_checked`，不以译码完成代替真实头CRC，更不据此直接读长度或交付MAC。

## 格式与独立依据

只编译普通 FT2 A2 的 N64/K40，以及 FT3/4 B1 的 N256/K51。
B1 为27位控制信息加CRC24B；不是K39。最初只读算术探查误标K39的结果保留，
主接收器的CRC上下文原本正确。本模块没有修改参考载荷或CRC规则。
FT2 A3、FT1、WS63未知厂测编码变体及软头译码不在这个服务的支持范围。

依据原始 T-XS-10002-2025 的 §6.3.3–6.3.5、§6.4.1.3.2、§6.4.2.2.2、
§6.9.1.4及附录C。两版原始PDF的全部1024个可靠性序号独立提取后相同，
见[原件核对范围](standard-sources.md)；使用GF(2) Kronecker矩阵产生六个独立编码向量，
没有调用本项目编码器。完整输入和SHA在`tests/data/control_polar_reference.json`。
任意接收硬位对照仍使用现有实际Python/Rust SSC，独立矩阵向量单独检查。

## 数据通路与状态

输入为已经完成硬解映射和解扰的一个64或256位寄存字，接口是整码字并行握手；
输入串行收集、交替旋转、导频去除、解扰调度、CRC和字段解析的工作尚未包含，不能计零周期。
硬位映射为±1，最小和f/g与现有±10输入齐次，零值判决和rate-0/rate-1剪枝保持一致。
深度d的绝对值上界为2^d，因此signed10覆盖最长N256的±256；本模块无舍入、饱和或回绕。
该结论只适用于此硬输入，不是对任意软LLR的位宽承诺。

运行时不递归，不查预先译好的答案。编译ROM存节点类型和信息位地址；
固定最多9帧遍历栈，四个有界上下文，每边沿最多一个操作发射、一个ALU操作和一个退休。
物理RAM读1边沿，ALU1边沿，再注册写回。每个块/变换级排空后才更换地址基础；
rate-1的u工作区复用叶层B平面，保存的beta在其他深度，不增加无界临时数组。
同址读写明确停顿，不依赖器件read-during-write模式。

输出保持至下游接收；忙时拒绝新码字并计数。中止清空上下文、待返回读和栈，
显式reset后允许下一包。RAM不逐包清零，遍历保证每次读前已由本包确定写入；测试复用
同一实例交替多个完全不同码字，未初始化读明确报错。统计计数溢出也不静默回绕。
观察回调是主机诊断设施，不存入硬件无界轨迹。

## 单因素银行对照

两候选仅改变真实物理银行映射，算术、剪枝、位序和遍历顺序相同。
下表为实际可执行模型完成同一码字的边沿数，含装载和信息位提取，不含接口外尚未建模工作。
每种格式525个任意接收/独立矩阵向量均精确匹配两个实际后端，数据与首包逐边沿轨迹字节一致；
两后端是同一批向量，不能当作独立接收样本。接收率增益未评价。

| 格式/布局 | 周期 | 逻辑RAM/ROM/状态合计bit | RAMB18等效 | BRAM36站点下界/保守上界 |
|---|---:|---:|---:|---:|
| N64/K40 dense |1662|8592|3|2/3|
| N64/K40 depth-parity |1404|8600|5|3/5|
| N256/K51 dense |5512|32837|6|3/4|
| N256/K51 depth-parity |4042|32841|6|3/5|

N256周期减少26.67%，但上界多一个BRAM36站点；N64减少15.52%，原语等效容量增加66.67%。
因此不是所有格式都应采用相同银行布局。当前仍是显式实验，不据此推广接收器默认。
容量候选预算在实现前定义为逻辑8KiB、最多6个RAMB18等效/5站点、4上下文、9栈帧，
不是已批准整机预算，原16KiB失败继续保留。最多110592bit物理原语容量不能写成32841bit。

操作计数N64/N256分别为f/g各126/599、总XOR171/634、硬判决40/51、
节点47/123、RAM读1139/4539、RAM写729/3173；银行布局不改变这些工作。
f计两绝对值、一次最小比较、符号异或和条件取负，g计条件取负及一次加法；
无除法、开方、变量乘法或新增DSP。四个12位地址加法通路、10位ALU、银行选择、
仲裁及流水寄存器仍需LUT/FF映射和综合，不能填零。
每数据银行真双口、ROM单读口，访问冲突真实停顿；状态表逐项包含四个192bit上下文、
栈、输入/输出、读回复、控制/命令和13个64bit统计量。

## 时钟与系统边界

N256 parity在100/160/200MHz的纯服务时间分别40.42/25.2625/20.21µs，期间16MS/s
连续输入最多新增647/405/324采样。未计入头解映射、解扰、CRC、字段、仲裁和其他RX工作；
这些采样也不是自动获得缓存。单码字只能一个在途，输出阻塞可无限延长就绪保持，
但模块状态有界，上层必须定义缓存与过载策略。
当前整链仍会在头前因历史窗口/串行处理退出，这个模块没有证明已消除那些丢弃。
不计入RX/TX/载荷译码的共享收益；是否能共享须在实际并发和截止时间上重新证明。

该实验通过算术与模块容量候选门，不代表完整流式、全链定点、整机资源或连续16MS/s四项通过。
没有综合、布局布线或实际时钟证据。下一步将真实硬解映射、解扰、头CRC及合法字段
接入同一服务，并验证有效头后按合法帧尾消费；头CRC不能成为同步/载波重试选择条件。

## 复现

```sh
PYTHONPATH=src uv run --frozen python scripts/model_control_polar.py \
  --output /tmp/control-polar-new --random-cases 512
```

输出目录必须不存在。返回0仅表示此模块实验精确一致，`full_RX_gates_passed`始终False。
制品包含原始输入/输出NPZ、首包完整真实读/算/写轨迹、SHA、实际参考后端、位宽、状态和银行成本。
