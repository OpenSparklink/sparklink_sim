# 因果载波PI实验：头部预热与验收边界

RX-carrier-continuous-B1对应§6.2.1.2的接收实现选择，不改变合法发送波形。
它研究用持续有限状态替代随整段载荷增长的FFT工作集，保留浮点FFT参考，
保持捕获、同步确认、Gardner/PI定时、单音抑制、头部解码和载荷译码不变。
未知起点接收由实际原始IQ→MAC路径运行，实验钩子只替换载波处理；默认接收器不变。

## 更新规则与有限状态

输入已经使用实际选中的同步估计作增益、频率与相位校正，环从零残余频率/相位开始。
每个符号先按旧NCO相位输出校正结果，再由当前符号更新下一符号的状态：

```
e = wrap_to_nearest_PSK_center(atan2(corrected) + actual_alternating_rotation)
e = clip(e, -pi/(2M), +pi/(2M))
f_next = clip(f + ki*e, -2pi*.1/M, +2pi*.1/M)
phase_next = wrap(phase + f_next + kp*e)
```

奇偶索引使用实际字段全局位置，在角度域补规定旋转，不增加复数旋转乘法器。
不使用期待载荷、导频内容、CRC或真值作误差、频率或相位选择。

沿用已有因果功率节点：初值1、更新1/64、上升输入限于前值2倍，范围2^-16..2^16。
功率低于前值1/16或高于4倍时暂停误差注入，功率状态仍因果推进，NCO按已有频率继续。
这能限制异常样本拉动，不能恢复已损坏的信息，也不能改善信干比。
输入浮点适配器限制有限复数及每分量绝对值不超过10^6；不是ADC精度或已验收定点范围。

`PSKCarrierLoop.feed`每次借用1..32符号，仅保存相位、频率、功率、索引与有界计数，
不保存符号历史；每包最多131072个已处理线符号，包括头部预热。
字段切换保留状态及奇偶位置，包间新建节点。EOF只关闭，不冲入虚构零样本；空输入明确标为`no_symbols`。
该长度上界可容纳目标最大包的符号数量，但完整最大合法包仍需单独端到端验证。

批量适配器仍拥有整段输出及诊断数组，现有接收器仍保存一帧用于解码。
因此本节点具有因果有限状态，不代表整条RX已经改成逐符号载波/解码调度。

## 开发、冻结与独立验证

先冻结两组增益：slow为kp=1/64、ki=1/8192，medium为kp=1/32、ki=1/2048。
新开发改变载荷内容、FT2/3/4、MCS0/6/8/12、导频0/8、长度、干扰组合和CFO/SRO/起点，
所有此前集合只作开发或固定回归。

载荷才启动的两方案，整包数虽未下降，错误21bit增至3598/3601bit。
主要退化dev-6的实际同步频偏估计约差−4949.49Hz，数据开始前已积累相位不确定性。
这不能单独证明具体周期滑移，因为原始IQ的总载波相位没有精确真值。

保存原实现和输入后，单因素增加实际头部线符号预热，增益、保护、定时和解码不变。
头部仍由原路径解码；预热只盲处理实际已接收头部，按profile规定的BPSK/QPSK调制，
随后切换载荷调制，保留同一PI/功率状态。它不使用正确头部比特来挑答案。

| 新开发8合法流 | 捕获/头CRC | 完整正确 | 错误bit/可算bit |
|---|---:|---:|---:|
| 全包FFT参考 | 8/8 | 5/8 | 21/21728 |
| slow，载荷启动 | 8/8 | 5/8 | 3598/21728 |
| medium，载荷启动 | 8/8 | 5/8 | 3601/21728 |
| slow，头部预热 | 8/8 | 5/8 | 3587/21728 |
| medium，头部预热 | 8/8 | 5/8 | 21/21728 |

仅medium-head满足开发门，并通过旧tone成功包的整段/固定/随机块否决检查。
参数、采用规则、源文件SHA及独立输入生成器AST在`tests/data/carrier_loop_policy.json`冻结，
之后才生成种子720117、PID5、不同载荷/配置/干扰组合的新保留集；不在保留集上挑其他增益。

独立8合法流：参考与medium-head均8捕获、8头CRC、6完整正确、7/25744bit错误。
validation-0和validation-7分别仍错6和1bit，均保留CRC失败。
前者是7字节未编码8PSK短包，线符号不足32，实际解析器继续仅用同步估计，未调用本实验环。
因此不能宣称它已经验证短载荷载波跟踪，也不据此对该保留集调整启用条件。

负例的采样数/时长、全部候选、头/数据CRC、长度、MCS、载荷及每百万采样漏斗分别保存，
五个算法臂重复处理同一输入不算五倍独立观察。旧228流/96包固定回归按原冻结索引SHA在真实Python/Rust环境重放：两方案均87捕获、61完整正确，
原成功零丢失、恢复0；余下35失败原样保存。168负例6985435采样（约436.6ms）零候选/误交付，
只陈述本次观察，不宣称全环境绝对零误检。密集流每输入含4包，状态按每包重新初始化。
本阶段没有重新评价真实RF采集，不能宣称真实接收增益。

## 真值、收敛与残余错误

独立解析角度/载波参考使用新的QPSK头部与BPSK/QPSK/8PSK载荷，8000数据符号，
加入频率斜率、幅度变化、复噪声、两次7符号强异常及4符号擦除。
已冻结门为：2000符号后相位RMS≤0.08rad、频率平均误差≤50Hz、无已知相位扇区变化；
收敛要求256符号窗口的相位RMS达标且扇区正确，窗口起点≤2000。
数据首符号已经经过64头符号预热；收敛起点0不能解释为没有启动延迟。

三种调制的独立参考相位RMS约0.02318/0.02466/0.02945rad，平均频率误差约−2.82/−1.53/−0.30Hz，
均无已知扇区越界。相位NCO回绕和检测器限幅分别记录，不能冒充真实周期滑移。

独立原始IQ注入CFO可与实际采样中心计算相对首数据符号的漂移分量，
初始总相位未知；该相对漂移不是总相位误差或判决残差。
一比特载荷错误仍是失败，诊断未恢复不证明理论不可恢复。

## 四层状态与整机成本

| 层 | 本阶段证据 | 尚未完成 |
|---|---|---|
| 浮点参考/因果结构 | 固定带宽PI、因果保护、无FFT/历史、IQ→MAC及分块对照 | 更广目标配置与所有固定回归门 |
| 定点 | 既有功率节点可复用；其余仅格式规划 | 相位/NCO/CORDIC、反馈量化、指数对齐及损失 |
| 周期/数据流 | 操作与寄存器/FIFO分项估算 | 实际数值运算、端口日历、积压与截止时间 |
| 综合/时序 | 本阶段无新增证据 | 实际资源、布线与目标时钟 |

每线符号旋转四实乘/二实加、功率二实乘/一实加、一个atan2和一对sin/cos，
另计PI移位/加法、模相位、功率更新、比较与统计。角度非线性不是免费硬件。
18+18复字、32bit相位只是未验收规划；六个18×18实乘对应六个25×18 DSP片的估算，
超宽乘积、指数对齐及CORDIC仍须另行计费，不能由此宣称定点损失为零。
四项深度输入/输出FIFO及状态寄存器共1942bit（分项规划）；两端FIFO各1读/1写，不凭空取得跨包/译码共享收益。

整机仍保留原RX帧缓存、Polar、TX、实时MAC/AES、DMA与接口并发需求。
原2%RRC、16KiB及细搜索串行吞吐失败继续有效；本节点无FFT不等于整机资源门通过。
100/160/200MHz均只列情景，尚无已验证每符号周期和连续16MS/s结论。
后续先做固定NCO/角度数据通路及实际反馈延迟，再决定是否接入默认接收路径。

## 复现与证据

在工程目录执行：

```sh
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_carrier_loop.py \
  --split development --output /tmp/carrier-loop-development
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_carrier_loop.py \
  --split validation --output /tmp/carrier-loop-validation
```

输出目录须不存在。两命令预期返回1，表示整机验收尚未完成，不能把候选局部通过当作完整RX通过。
输出包括实际profile、输入和源码SHA、冻结策略、所有失败、逐符号NCO/保护轨迹与独立真值参考。
`carrier-continuous`冻结证据保存载荷启动失败、预热对照、原输入回归、双后端及实际CI制品。
