# 捕获相关模块的硬化模型

基线`3915798`，沿用工作分支和哈希冻结输入。仅离线算法、模型、测试、文档和CI，
无设备/SDK/生产RTL/综合/Release操作。对应PSK §6.2.1.2、同步 §6.5/6.6及CRC §6.9，
下述预算是开发验收约定，不是标准合格门限。

## 分层及首个闭环范围

| 层 | 目的 | 验收 |
|---|---|---|
| 既有浮点接收参考 | 能力边界 | 捕获、头/数据CRC、合法长度/MCS、完整载荷、BER、真值误差 |
| 连续整数相关结构 | 相邻窗复用、有限状态及因果性 | 操作/访存数量、容量、最坏工作量及等价预算 |
| 同模块定点 | 位宽、量化、饱和及动态范围 | 开发集选择，冻结后量化损失、临界门限和排序 |
| 子模块周期/数据流 | 连续输入承接 | II、延迟、有限FIFO积压/溢出及资源假设 |

首个模块仅替换整数相关**预筛**；保留浮点RRC、32相位细搜索、峰值准备条件、
包内定时/载波和严格解析作端到端对照。不把该子模块周期能力当作整条接收链能力。
旧默认浮点API保持；实验结构/定点需显式选择。未来定点和RTL才逐位对照，当前不用
NumPy浮点舍入顺序约束结构设计。

## 先验预算（生成新开发集前固定）

- 整数搜索网格、搜索范围、跳过已消费包的边界和最大峰等待规则不变；新位置/候选策略另列召回。
- 浮点结构平方分数绝对差≤1e-10；接收成功零退化、负例零新增候选/交付。
- 定点选择条件：未饱和且参考相关分数≥.55的窗，分数误差≤.005；归一化排序损失≤.005。
  新开发整包成功零损失、负例零新增交付；冻结后对新保留及全部旧成功另验，不据保留集重调。
  临界门限改变和不满足预算的位宽保留为失败，不用CRC/载荷为单包挑模型。
- 候选输入位宽先扫描10/12/14/16/18；差分采用明确缩放及增长位宽，门限平方常量24分数位。
  合成IQ预设满量程1024，硬件原int16来源预设满量程262144（含浮点RRC头间余量）；均不按期待载荷调增益。
- 捕获中心误差相对参考≤.125采样，包内轨迹≤.25采样；真值另行报告，不能用参考偏差替代真值误差。
- 首个结构状态/系数≤16KiB（不含未硬化的RRC/细化/包缓存），持续输入不允许静默省略成本。
- 周期情景先定200MHz、16MS/s、有限FIFO深度64；并行度2/4/8比较，所有多宽乘法与端口假设公开。
  周期模型没有综合证据，不能声称E310资源/时序已经满足。

## 阶段与输入

基线证据 → 结构候选及浮点验证 → 定点扫描 → 周期/资源 → 冻结回归及独立提交。
新开发种子340116、新保留350116，各输入独立随机载荷、噪声及离网格起点；保留集冻结后才评价。
原已查看保留集只作固定回归。新集合包含零输入、AWGN、持续单音、错PID、突发干扰，
各背景分别叠加合法弱包，另含4包连续流；长度37/73/255/511、QPSK/8PSK/编码QPSK、
CFO 0/+30/-25/+45kHz、SRO 0/+100/-100/+25ppm及幅度.125/.25/.5/1组合。
这是有限组合而非穷举矩阵；SNR/SIR按实际波形功率记录，不将幅度标签当实测SNR。
独立发送为解析RRC、16符号发送尾，接收为既有10符号滤波/插值，真值不进入接收选择。
脚本后处理才匹配真值并分别检查CRC、长度/MCS/载荷及可计算BER。所有负例候选即使CRC失败也保留。

```sh
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_capture_hardware.py \
  --generate development --output /tmp/acquisition-development
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_capture_hardware.py \
  --inputs /tmp/acquisition-development --output /tmp/acquisition-baseline
```

主接收器关闭静默跳跃执行该审计，避免以跳过静默的平均运算冒充持续输入的最坏预算。

## 基线证据

新开发44流共434331采样，含32合法包：24捕获、17整包正确，8漏检、7数据CRC失败，
所有负例零候选/交付。AWGN/单音/错PID/突发/密集流的捕获数分别4/1/1/2/16，
整包数3/1/1/0/12；密集流分母16包，其余每类4包。失败内容与可计算BER均后处理保留。
原始生成器及未含后处理BER的首批结果也保存；补充元数据后的44个IQ/静默NPZ哈希逐个相同。
真实旧采集继续按既有冻结元数据读取，未打开新保留集。

源码核对：整数筛每32样本重建4相位差分；256采样窗下共252个差分，通常131个合法相关位置，
每个位置仍循环31个差分系数。Rust源码的幅度平方实际先求norm再平方，分数还含norm、sqrt和除法。
以上是源级算法工作量描述，不是DSP综合统计；NumPy底层实现及编译器FMA等不能由循环数推断。
结构候选将比较共享差分/滑动能量、只计算新位置以及平方阈值；归一化排序需独立交叉乘积验证。

基线阶段Python3024通过、32明确跳过、覆盖率90.72%；Rust+SM3 3067通过，ruff与严格文档构建通过。
完整基线结果、输入/源码SHA和全部失败在证据根`rx-acquisition-hardware/baseline-development-final`。

## 连续相关结构（浮点验证）

新增`DifferentialBank`，输入是因果RRC输出，每次最多8*SPS采样，信号/差分/功率延迟线及命中位环
跨块保存。每个输入仅形成一次`d[n]=x[n]*conj(x[n-SPS])`，仅为新位置计算长度K的相关。
能量按各采样相位作滑动加减；浮点仿真在抵消明显时重算有限窗以防残差，定点整数累加不需要此保护。
零能量直接拒绝，不做除零或以epsilon制造可接受分数；样本序号有显式有符号64位上限。

FT2差分系数为共同缩放的`±1±j`，共同`1/sqrt(2)`在归一化中抵消，可用符号加减替代系数乘法。
记去除公共缩放后系数总能量`A=2K`，门限为`Re(C)^2+Im(C)^2 >= threshold^2*A*E`。
排序单独验证交叉乘积`N1*A2*E2 > N2*A1*E1`，不按相关幅度排序。
本预筛实际上只输出合法范围内是否存在命中，不选择细相位；细搜索和最大峰等待条件完全保留。
单元反例覆盖零能量、强但归一化差的相关、门限±1e-8、动态幅度1e-6..1000、
随机直接相关参考、有限历史及计数溢出、坏头/坏数据CRC、最大峰等待及任意分块。

显式选`correlation_backend='structure', quiet_batching=False`；默认`reference`不变。
结构必须持续处理静默和已捕获包内部输入，禁止丢掉前面样本后只给搜索窗。
`integer_screen_backend`报告实际`structure`，不会把安装了Rust扩展误报为执行Rust整数预筛。
预筛通过后现有浮点细搜索仍计算32相位，未实现旧NumPy路径的4整数相位缓存共享，成本分别记录。
未知系数形状会明确拒绝，不把该特化套用到任意同步profile。

新开发44流的所有帧、交付和轨迹与浮点基线相同，仍24捕获/17整包，无改善亦无退化，
8漏检/7坏CRC保留；`structure-development-final-comparison.json`实际轨迹差值0。
7392字节是浮点结构仿真的数组容量，未来逻辑位宽/打包容量另算。

源级运算图估算（不是综合）：连续干扰、每32采样搜索一次时，旧整数核每次252个差分、131个相关，
新结构每输入一个差分和一个新相关；相关位置工作约4.09倍复用，差分约7.88倍复用。

其中新乘法含一个常量门限乘法，之后可评估移位加法；符号控制最多124次/输入，系数62比特读取。
每输入逻辑数据读68标量、写9标量（含命中位）；合法范围查询还需至多256命中位的掩码OR。
这需要分布寄存器/分银行或并行端口，不能把所有读取塞进单个双端口BRAM而宣称同一II。
浮点抵消保护最坏另加30次加法/位置，计数单独保存；它不计入未来整数核心的图。
新开发合法位置计数490260→430723，且新结构始终处理输入，不能将持续干扰的复用倍数
当成所有流量的实际节省倍数。NumPy可能先算非法位置再遮蔽，源级估算也不代表其CPU指令数。
所有运算量仍排除未硬化的RRC、32相位细化、包内环路和译码，没有整链16MS/s结论。
