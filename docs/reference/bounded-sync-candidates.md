# 有限候选与固定局部搜索（RX-CAND2）

这是显式实验搜索结构，不替换默认全网格算法，也不解除原误检或资源预算。
此前local4方案因起点误差0.155438采样超过0.125预算而被拒绝，继续保留。
本方案保留原`CubicSpline`和归一化差分评分，不使用local4的Lagrange/抛物线预测。
规范依据为已冻结原始PDF的§6.2.1.2（PSK）和§6.2.3.2（同步信号2），
版本/SHA见[标准来源](standard-sources.md)；不改实际同步字、旋转、导频或CRC上下文。
源码沿用的“§6.5/6.6”是历史模块标签，不作为当前原始PDF的同步条款号。

## 搜索合同

```python
rx = MacStreamReceiver(profile, quiet, quiet_batching=False,
                       correlation_backend="scaled",
                       sync_search_method="bounded-grid",
                       sync_candidate_count=1, normalized_coarse=True)
```

目前仅SPS4、1/8采样网格及显式因果相关银行，候选数1或2。
这些是实验边界；尚未对其它配置形成完整验证。
能量门倍率2、整数预筛0.6、细搜索0.85、峰值等待16采样均保留。
同步选择不读期待载荷、CRC或真值位置。

1. 共享已有差分/滑动能量/相邻窗相关及Q12归一化分数环，不重算相关银行。
2. 按归一化分数贪心取1/2峰，峰间至少4采样；屏蔽范围严格为距离小于4。
3. 分数相同按原全搜索的相位优先、随后位置顺序选择；不按相关幅度排序。
4. 每峰固定评价−0.5..+0.5、步长1/8的9个位置，去重后按原全搜索顺序处理。
5. 范围外位置不评分；最终只取已评价的归一化最大值。
6. 最大值需要未来样本时继续等待，不以较弱的就绪峰替代，也不按CRC重试。

`normalized_coarse=False`为浮点排名参考，复用原整数搜索缓存；这会重复整数排名计算，
不得作为硬件复用收益。Q12路径在原有256字分数环至多扫描2次、每次至多131字，
不重新实现归一化器。零能量环不产生候选。
主流式路径仍每32个新采样最多一次细请求，每请求最多9/18次局部评分；
保留原窗口过期和`skip_until`。跨窗重复请求如实计数，不新增静默限流或无界候选队列。
候选数、评分位置及局部范围属于算法变化，其召回损失单列，不能称作浮点容差。

诊断驱动在真实选择之后另运行全搜索并记录窗口，返回值始终是实际局部结果；
这个对照成本只在离线诊断中发生，不进入接收算法，也不拿它恢复实际漏包。
外部诊断数组及保存的窗口不作为硬件内部状态。

## 工作量与周期情景

`model_sync_candidate_work.py`复用已有有界FCFS窗口模拟器，
不复用其旧固定44位/相关银行容量假设；当前账本仍是双scaled10银行、46位历史及3份已计费快照。
新的峰寄存器保守分配每峰78bit/银行，两银行1峰新增156bit，2峰312bit。
已知部分状态加Q12分数环及峰寄存器为128724/128880bit，
距离16KiB只剩2348/2192bit，尚未计完细搜索准备、管线和包内工作。

一种直接Horner乘加情景（跳过每峰的整数位置插值）为：

| 每请求，32符号同步 | 1峰 | 2峰 |
|---|---:|---:|
| 局部评分上限 | 9 | 18 |
| 插值实乘加乘积 | 1536 | 3072 |
| 差分/功率/相关模平方实乘积 | 1413 | 2826 |
| 合计实乘积等价量 | 2949 | 5898 |
| 除法、开方、相角各自次数 | 9 | 18 |
| 粗排名分数字读取上限 | 131 | 262 |

这是一个特定图的估算，假定同步系数可符号/交换布线、三实乘复数差分；
未证明每个任意位宽乘法只需一个DSP，未计样条消元/系数准备和非线性单元调度。
固定八分之一相位的常乘可另外研究移位加法，但会占宽加法/流水/端口，当前没有实现或免费收益。
不能把2949当成所有合理结构的数学下界。

200MHz、当前RRC预留和双银行后乐观剩余为2912实乘积/请求，直接图两方案均超出。
按剩余资源分配7个细搜索乘法单元、3份快照、每32采样请求、持续输入262144采样：
1峰丢425请求，2峰丢4299；丢弃明示为队列资源不足，不记作同步评分漏检。
下游阻塞增加丢弃；100/160MHz也分别保存积压/丢弃，且RRC自身在这些较低时钟未通过16MS/s。
该日历不反馈到真实接收器，只是隔离资源情景，不是整链周期闭环或综合/时序结果。

浮点样条系数数组为4×255个complex128、16320字节；
即使假设未验证的32位复数系数也需32640bit，尚未覆盖消元及其它临时量。
是否只生成所需局部系数、改变插值器或利用共享RAM，需要后续独立结构和数值验收。
有限字精搜索、零能量/动态范围/宽比较、原ADC到符号的量化链尚未完成，
本阶段只能验证已有Q12粗排名，不能宣称整个细搜索已经定点化。
