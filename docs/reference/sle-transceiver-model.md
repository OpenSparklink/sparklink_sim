# 窄带SLE收发算法模型总目标与验收门

本轮总目标：先完成目标接收机的离线算法、有限结构、定点分析和连续数据流验收，
形成带失败证据的接收机设计/边界报告，再进入发射机设计与优化。优先4Msym/s、
16MS/s的普通窄带链路；厂测profile独立。所有阶段仅模型/测试/文档/CI，
不操作设备、SDK、生产RTL、Release，不自动合并master。

## 阶段任务与顺序

| 阶段 | 任务 | 完成条件 |
|---|---|---|
| RX-A | 基线与逐窗归因 | 冻结哈希、预筛旁路、突发真值控制和数值节点；保留所有失败 |
| RX-B | 有界干扰捕获 | 新开发选型、冻结新保留、旧成功/负例/轨迹/成本回归；候选允许被拒绝 |
| RX-C1 | 检测相关动态范围 | 有限缩放/指数、固定预算、强弱切换、节点精度及运算/状态闭环 |
| RX-C2 | 前端和环路定点 | RRC、插值、定时/载波、软信息及译码接口逐模块误差/饱和/稳定性 |
| RX-D1 | 捕获数据流 | RRC/细搜索/窗口快照/有限队列/背压，公开资源假设与不达标情景 |
| RX-D2 | 全链调度 | 头/载荷/译码/交付周期、状态跨包复位、有限缓存和EOF错误 |
| RX-E | 支持范围补齐及验收 | FT1/GFSK与FT2/3/4逐MCS的严格未知起点到MAC、连续流、新保留与固定回归 |
| RX-GATE | 接收机设计与边界报告 | 四层证据齐全；硬约束不达标给出证据和取舍，不得静默转TX |
| TX-A | 现有接口/字段审计 | 继承TxConfig/tx_chain/MAC接口，独立标准/字段参考，锁定包配置 |
| TX-B | 映射+因果多相RRC | 浮点/结构/定点/周期，历史、尾冲洗、保护间隔与包间复位 |
| TX-C | 编码和确定输出 | 有界码块/帧双缓冲、调度、输出FIFO及欠载中止策略 |
| TX-GATE | 发射边界报告 | 内容、独立波形、EVM/频谱/PAPR/饱和/瞬态及16MS/s假设 |
| TRX | 独立收发闭环 | 独立向量、脉冲与重采样真值；自回环仅一项证据 |

低SNR点失败不自动阻止报告完成；缺失处理环节、定点/资源模型或关键反例不能算完成。
若现预算不支持最坏16MS/s，必须先提供有界丢弃行为、工作量下界和设计取舍，
不能仅以局部吞吐或单元测试宣布接收机完成后转入发射机。

## 起始盘点（需逐项实测补齐，不是支持声明）

- `rx_chain`/`iq_to_mac`仍是已知对齐且外部给长度的兼容仿真接口，不代表未知起点能力。
- FT2/3/4 PSK：`PSKReceiveProfile`、`PSKStreamReceiver`和`MacStreamReceiver`
  实现严格未知起点、头CRC后长度、载荷CRC后交付和任意分块；现有端到端用例只覆盖部分
  FT/MCS组合，不可从profile允许MCS0..12推断全部组合经过严格验证。
- MCS0/1为编码BPSK，2..7编码QPSK、8未编码QPSK，9..11编码8PSK、12未编码8PSK。
  同步/头部使用各帧型既定调制方式，不能与载荷MCS混为一谈。
- FT1/GFSK：有调制解调、整体捕获和A3比特候选严格CRC局部测试；当前通用MAC流式适配只
  实例化PSK接收器，FT1尚缺完整有界未知起点到MAC流式路径，不能标为完成。
- 原模块级整数预筛定点/周期证据已完成；RRC、细搜索、环路、译码的整链四层证据尚未完成。
- WS63 A3的已知未编码profile独立冻结同步字/CRC种子/比特序；未知编码前缀不剥除、不猜答案。
- UWB、多音及其他非目标波形不在本次窄带完整接收/发射验收范围；不由已有局部模块推导互通。

每项完成后更新逐帧型/MCS实测矩阵及输入/源码哈希。普通与厂测保持编码、导频、加扰及CRC上下文独立。
定点只对未来RTL要求逐位一致，浮点与结构按开发前冻结的性能/误差预算对照。

## 当前约束及提交纪律

原捕获受限对照为200MHz、18个25×18乘法原语、16KiB逻辑捕获容量，宽加法/比较1周期为假设；
新增模块、端口复制、队列和流水单独计入总成本。不能用静默跳跃或CRC挑选稀释最坏工作量。
全链预算、各节点定点格式及TX EVM/频谱等限值在对应开发前冻结并说明标准依据，未知限值不虚构。

当前阶段状态：RX-A已冻结(`924d226`)；RX-B浮点回退已冻结(`fc2e014`)，
新保留捕获/整包各增加4/96；RX-C1有限指数相关已冻结(`3f2a477`)，
相关点预算通过但仍保留4个输入指数下限事件。RX-D1A补充当前细搜索图必要条件及有限队列诊断，
显示原18路/200MHz假设下的最坏工作量失败；它没有完成RX-D1/D2的延迟反馈和整链调度。
RX-D1B舍入折叠与旧整数逐点相同，但新增小计数状态；RX-D1C四次局部细搜索的新保留
整包数未变，仍因一个同步起点差异超预算被拒绝。Q12归一化排序独立保留，未据少算位置宣布16MS/s。
RX-C2、逐FT/MCS支持补齐及RX-GATE仍待完成，尚不进入TX。
AGENTS指定标准文件当前缺失，后续FT1合法配置/TX限值需读取适用来源后确认，不能从理想API推断。

每阶段：基线证据→实现→针对性测试→ruff→全量/覆盖率→CHANGELOG/文档→原子提交推送→
实际CI及制品核验。当前执行细节与失败索引见`rx-interference-capture`及冻结证据根。
