对应普通PSK §6.2.3的接收结构。复用既有功率复用、几何等待及两ALU相位并发，

## 恒等式和位宽

当前字为`a+jb`，前一字为`c+jd`，均为有符号22bit。
原复差分`(a+jb)conj(c+jd)`用四次22×22实乘；实验使用：

```text
P = a × (c-d)
Q = d × (a+b)
R = c × (b-a)
real = P+Q = ac+bd
imag = P+R = bc-ad
```

三次预加减采用signed23；不直接对最小负输入取反，不舍入或饱和。
通用22×23乘法保守返回signed46，按输入范围每个乘积实际满足signed45，
因此送入既有signed45差分加法是精确接线，未丢失有效位。
最终相关、能量、平方分子、交叉排序及阈值保持原完整增长格式。

每次22×22及22×23均由两次正24×17部分积组成，放入25×18 DSP原语；
不能把任意22×23乘法当成一次DSP乘法。
差分原生部分积8→6，另增加三个23bit预加减及寄存反馈，实际周期由既有逐字引擎执行。
原共享缓存和Y/M端口不增加，第二峰仍按原顺序处理，选中相位仍重新取样回放。

默认仍为False，旧默认结果/成本结构保持。它不是新的同步答案选择或CRC重试路径。

保守增加三预加结果69bit、三乘积138bit，每个活动相位207bit；不扣除原四乘积槽或原分配余量。
宏模型单相位207bit；逐字并发九相位1863bit，低于实现前2048bit增量研究界。
既有两ALU设施及九上下文合计20936→22799bit，仍按原24576bit研究界评价，
原查询状态继续另计。无新DSP、采样RAM、IQ FIFO或读写端口。
监视节点仍装在原80×8bit预留中，控制ROM、译码、选择及Fmax没有综合证据。

这些是候选的增量与寄存预留，不是已批准整机预算。新增FF必须进入整机账本，
