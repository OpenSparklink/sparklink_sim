# 目标窄带接收机的实现与验证范围

最新[实际捕获→有限初始化桥](initialized-capture-bridge.md)限普通FT2/3/4、
4Msym/SPS4、MCS8/12、A2+LQI/B1的显式组合。真实头通过后才消费合法帧尾；
已有有限初始化/定时/字头复用，新增1024字私有源和628bit桥控制另计。
元数据和载荷服务仍非完整有限周期实现，FT1/GFSK、编码MCS及WS63不进入该桥。
默认接收器不变，四项总门不由此关闭。

本表描述源码实际可运行的配置和已执行的验证，不替代适用标准的合法组合审查。
原始标准已在独立`sparklink-standards`找到，版本/SHA见[标准来源](standard-sources.md)；
FT1的目标配置及新增规范限值仍须逐项核对，不能推测。
优先4Msym/s、SPS4，即16MS/s离线输入。未知起点由接收器选择，真值仅用于事后误差评价。

本轮[真实有限头部接入](head-word-gate.md)仅显式普通A2+LQI/B1，硬位SSC→真实CRC→
有限几何→同一帧消费。A3/WS63和A2无LQI不支持word头，继续原参考。
新开发/冻结新保留各5/6，三路径相同、增益0；原SHA WS63 A3的6原始/8派生重放判定与轨迹相同。
组件端口/容量与整链调度分别记账，四项验收仍未通过。

## 严格浮点流式路径

`MacStreamReceiver` → `PSKStreamReceiver` → 校验头CRC → 读取长度/MCS → 载荷/数据CRC → MAC交付。
FT2普通A2的MCS由协商profile给定；FT3/4的B1从**已校验**头部读取MCS。
理想对齐`rx_chain`保留兼容，不作为本表的流式验收依据。

**B1长度审计修正**：早期FT3/4矩阵使用payload-only长度，现作为显式
`legacy-b1-payload-length`固定回归保留，不证明标准B1长度合法。
新普通profile按标准包含数据CRC，四个原始独立B1长度反例已恢复；
不同CRC、零长度、坏头/非法长度及分块验证见[B1长度合同](b1-length-contract.md)。
下文旧矩阵的2047字节载荷只属于legacy实验；标准B1最大信息/MIC为2044/2043字节。

| 波形/帧型 | 已实现 | 本阶段严格IQ到MAC证据 | 尚未完成 |
|---|---|---|---|
| FT2 PSK/A2 | 未知起点、有界分块、真实头CRC12、载荷CRC | MCS0–12各37字节，导频0/8，两种分块；MCS8/12另有1/2047字节 | 全MCS长度/干扰/量化/整链周期边界 |
| FT3 PSK/B1 | 头CRC24B及LLID；标准长度含数据CRC | CRC24/32独立长度反例及零长度；旧全MCS矩阵显式legacy | 全合法配置/导频末尾规则/定点/周期 |
| FT4 PSK/B1 | 同上，BPSK同步/头部 | 同上 | 同上 |
| FT1/GFSK | GFSK模块、整体捕获、A3判决比特严格解析 | 仅既有局部/整体记录；PSK流接口明确拒绝FT1 | 有界未知起点到MAC流式路径、四层模型 |
| WS63 FT2/A3已知变体 | 显式同步字/种子/比特序/导频profile，已有真实IQ固定回归 | 继续引用冻结真实IQ，未混用普通profile | 量化/整链周期和未知编码变体 |

源码MCS表0/1为编码BPSK，2–7编码QPSK、8未编码QPSK，9–11编码8PSK、12未编码8PSK。
本阶段矩阵覆盖这些**配置实现**；未凭缺失的标准原文声明全部FT/速率组合规范互通。
未知厂测编码前缀、UWB、多音不纳入当前窄带完整接收机支持声明。

显式标准 B1 编码码块模式已补齐实际末块几何和逐块 CRC。FT3/4 的 MCS 0–7、9–11
各有 4 Msym/s 标准长度和多逻辑块的合成 MAC 成功证据。独立 FT3 MCS4/FT4 MCS9
向量另验证 1216 位布局及坏码块拒收。载荷 Polar、载波及 CRC 周期仍未计入
整链有限调度。详细参数和未覆盖范围见[编码载荷](b1-coded-payload.md)。独立的
[有界 B1 帧服务](b1-payload-service.md)已在有限译码输出端执行真实双 CRC、
截断拒绝和带缓冲交付，仍待接入 ADC 起始的整链联合调度。

## 本阶段的冻结试验

`tests/test_receive_scope.py`有104个针对性用例：

- 78组FT2/3/4 × MCS0–12 × 导频0/8；载荷37字节。
  起点分数为`((FT*13+MCS)*.137)%4`，CFO为-25kHz/30kHz，SRO为±100ppm。
  每组比较整段与固定种子440117的随机1–513样本分块，均在EOF前交付。
  头CRC、数据CRC、长度、MCS和完整载荷分别检查；有真值的符号中心最大误差预算0.25采样。
- 12组未编码QPSK/8PSK在三种帧型下的1/2047字节字段边界，导频8，30kHz/100ppm。
- 4组B1实际MCS6/12与调用者配置MCS8不同的接收，验证不能靠调用者预知载荷长度/MCS。
- 三种帧型的6组坏头/坏数据CRC、3组合法头CRC但长度超profile上限，均不向MAC交付。
- FT1明确拒绝作为PSK流式支持，不用跳过或固定成功标志冒充GFSK实现。

独立解析RRC脉冲和角度映射产生RF参考；比特编码仍复用既有发送模块。
因此该矩阵只能补齐严格接收和接口回归，独立标准向量/字段参考仍是另外的验收门，
不能以收发双方共享编码的自回环宣布互通或完整SLE验收。

```sh
RX_SCOPE_EVIDENCE=/tmp/rx-scope-evidence PYTHONPATH=src python -m pytest \
  tests/test_receive_scope.py -q --tb=short --junitxml=/tmp/rx-scope-evidence.xml
```

证据目录按实际IQ/quiet/profile哈希保存独立NPZ、分块轨迹、实际CRC/交付、成本计数。
统计只在接收选择完成后写出，不参与同步或判决。默认CI不需外部IQ或可选Rust；
Python/Rust作业分别执行相同矩阵。原始硬件IQ未被修改。
本轮实际两环境的181个接收臂逐帧/交付/轨迹数组完全一致；
原生整数筛选等后端特有运算计数不同，分别保留，不作为相同硬件成本或吞吐结论。

新增归一化状态7825bit及原控制192bit独立计费，不改变FT1缺口、旧数值门或四项整体验收。

[已知同步精确流水](known-sync-pipeline.md)只改变上述实验字接收的计算结构：
普通FT2/3/4、4Msym/SPS4和power30/error32，未扩大配置矩阵。

## 接收配置快照

MCS许可输入在构造profile时复制并封存为元组，最多13项，读取上限为14项。
调用者随后修改原列表不会改变当前接收上下文；空集合仍表示拒绝全部MCS。
非法索引或无限迭代器在接收前明确报错，不因配置准备导致无界工作量。
这是配置所有权修复，不改变同步/定时/载波/CRC或压力实验的通过标准。
B1长度字段的独立标准反例另行留证与修复，不能以本项通过代替帧语义验收。

## 当前局部结构与四项总门

以上各阶段文字保留当时的限制和失败，不能把历史104边沿或“头部仍浮点”当成最新局部状态。
当前显式已选帧路径已有实际定时/归一化字、头部硬位/SSC/真实CRC和合法帧尾服务；
可分别选择两位商、双独立银行join、功率/TED重叠及[原始四字复用](retained-raw-stencil.md)。
残余载荷载波、LLR和译码仍未接入完整有限字/周期服务，off-clock完成会使完整周期证据失效。
原始源所有权在终止门之后才归还；合法帧尾及依赖退休不等于已经完成下一捕获与译码的并发交接。

四项总门仍分别未通过：完整流式含FT1缺口；全链定点保留RRC和插值原失败；
整机资源含旧16KiB/4096/2048失败及TX/译码/MAC并发缺口；连续16MS/s仍受串行反馈和512字历史溢出限制。
新64bit局部控制预算不批准整机扩容，默认路径不变。当前支持矩阵的局部/理想与严格原始IQ列仍须分别读取。


## 连续初始化的显式窗口候选

M17另提供[增量共同指数](scaled-window-maximum.md)显式实验类：仅普通FT2/3/4的scaled10/SPS4目标几何，原/新评分、候选、真实CRC和MAC保持，默认路径不变。功能RF对照不包含四/七沿注册延迟，最大值节点的初始化、有限状态与端口已有独立周期模型；它们尚未与RRC/相关/细搜索/解码整链调度闭合。当前不扩大帧型、MCS、包长或厂测支持宣称，四项总门仍分别开放。


## 实际捕获到合法帧消费（M26，实验）

其余包内功能算术仍 off-clock，全链绝对延迟未知，不扩大以下支持范围或关闭四项总门。

[实际候选与帧所有者](captured-legal-frame-owner.md)连接已有RRC/差分粗核/全相位细搜索和严格帧参考，
