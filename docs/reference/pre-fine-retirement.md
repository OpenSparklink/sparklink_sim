# 细搜索前的注册退休检查（M28，实验）

本模块是普通PSK同步实现（§6.2.3）的有限调度实验，接续
[实际捕获与合法帧消费](captured-legal-frame-owner.md)。不改变差分评分、归一化排序、
网格、峰值等待、相干门限、Gardner/PI、载波或解码，也不依据CRC或期待载荷重试答案。
默认关闭，四项接收机总验收继续分别开放。

## 已确认的浪费与保守条件

M26原SHA输入的20条已查看流中，15次细搜索完成后才以`source_already_consumed`拒绝，
合计387110模型周期。新复现的单包在完整交付后仍执行两次细搜，额外33176周期；失败留证。
这些集合只作固定回归，不再用于新方案选参或称为新保留集。

原窗口为`[end-window,end)`，实际选择端口保证`0<start_tick<8×window`，
所以绝对选中起点严格小于`end`。若`end<=retired_through`，窗口中所有可能起点
都早于已消费前缀，原后级必然拒绝，无需计算相关分数。部分重叠不能据此排除，仍执行完整细搜。
比较只读取源端点与实际消费位置；头CRC影响原帧如何消费/终止，数据CRC影响交付，
二者不作为该比较器的输入。坏CRC也不会清除已经消费的事实或启用另一同步答案。

## 接口、生命周期和记账

`CaptureTransport.simulate(...,retire_before_fine=True)`要求已连接实际源、
`CaptureFineWorker`选择缓存及`CapturedFrameReplay`。旧接口默认False，原结果字段不增加。
检查在原同步窗复制完成且成为活动拥有者后进行，不跳过实际输入检测或复制。

所有窗口都支付一个注册比较沿。复用原活动描述符及`finish`时间字段，
注册排除位与检查阶段各1bit；下一沿才释放过期槽或启动原细搜。
排除结果为`retired_before_fine`，不计入`completed`或细搜评分结果。
它没有`start_tick`、`FineService`或虚构的零周期细搜。

同一活动槽排他占用检查/细搜/帧消费，下一细搜期间帧所有者必须不活动，退休位置不能前进。
诊断观察器分别记录检查、真实细搜开始和可用沿，独立核对该不变量；回调不返回选择指令。
源epoch故障取消活动检查及其他拥有槽，继续计入后续ADC输入；EOF不补字。
下游阻塞不停止输入；内部过期回收可继续，真实帧读取仍遵守原信用和堵塞规则。

请求核算为细搜完成、预先退休、槽满、历史过期、启动不足及源取消之和。
`pre_fine_retired`是冗余候选退休，不是已恢复包或资源丢包。多候选不能当作多个独立包。
算法漏检、CRC失败、资源丢弃和完整交付分别关联输入SHA。

## 增量成本与周期边界

| 项目 | 本模块增量 | 说明 |
|---|---:|---|
| 状态 | 66bit | 64bit退休计数、1bit注册决定、1bit阶段；实现前研究界128bit |
| 比较 | 每检查1次unsigned63 | 两个已有寄存器操作数；跨模块扇出/路由未综合 |
| 加法 | 每退休1次64bit | 计数耗尽报错，不静默回绕 |
| 检查延迟/II | 1/1沿 | 所有窗口计费；需验证宽比较的物理时序 |
| 新IQ RAM/DSP/采样端口 | 0 | 原4096点共享历史、三拥有窗及选择缓存不扩大 |

`estimate(measured_worker=True,released_requests=True,retire_before_fine=True)`
在原运输寄存器预算中单列66bit，不重复加入帧所有者已经保留的退休位置。
观察器的日志、原输入参考和数组属于台架，不当成免费硬件状态。
对100/160/200MHz，一比较沿分别假设10/6.25/5ns；不是达到这些Fmax的综合证明。
当前实际RRC/粗细/帧组合仍只按原200MHz实验条件验证，不能据此扩展其他时钟支持。

纯整数比较不改信号格式、系数、舍入或饱和；相同源窗及请求几何的细搜整数结果必须精确。
原RRC 2.34835%>2%、插值0.000150245>0.0001、16KiB和整机并发失败保留。
本节点66bit合格不批准整机扩容，也不抵扣译码、TX、实时MAC、DMA或调试资源。

完整相干确认、包内浮点消费、残余载波及译码服务仍为未知，完整延迟为`None`。
细搜周期加检查周期是部分已计工作；乐观逻辑日历不等于完整ADC服务率或实际FPGA吞吐。
持续干扰且没有可退休前缀时，仍可能每32采样请求一次完整细搜；新节点还多一比较沿。
三个有限槽不能消除这种过载，必须保留槽满丢弃，不能以合法包的平均节省证明最坏16MS/s。

## 验证与采用规则

独立解析脉冲/重采样产生新两帧压力流，变化载荷族、FT2/3/4、MCS8/12、合法单帧长度、
导频、分数偏移、CFO/SRO、幅度、间隔、噪声、持续单音、错误同步字及突发。
强度按实际干净RMS标定，不把旧参考中较小的`amplitude`参数直接当信号RMS。
单帧格式与实际前导40/48/64符号分别核对；该压力流的MAC帧间隔一致性尚未验收。
没有新增厂测编码、FT1/GFSK或其他速率支持宣称。

所有旧成功完整载荷零丢失；固定负例零新增确认/交付；源描述符、原字和相同窗口整数评分精确。
相同后端整段/固定/固定随机分块逐字节比较。采用已有冻结的分数0.005、起点0.125采样、
相对轨迹0.25采样预算，不能把坐标平移的浮点舍入顺序当作新的硬件一致性要求。
最初更严格的逐值设想及生成新数据前的预算依据澄清均留证，不改写原预算或失败。

同时要求整体细搜加检查工作下降、槽满/历史过期不增加、128bit增量界和原端口上限满足。
任何条件失败即拒绝该实验配置，不因恢复个别包而放宽规则。
真值仅在输出后关联定时和BER；只对实际译出且长度相符的载荷计算BER，未捕获部分不是零误码。
缺失、NaN、伪布尔、遗漏请求及数值超界的报告不能作为合格证据；原型反例保留。
