# 整数载波数据通路与有界周期模型

RX-carrier-fixed-B2延续[因果载波PI](carrier-loop.md)，对应标准§6.2.1.2的接收实现选择。
保持medium增益、头部预热、功率保护、同步/定时/解码不变，研究固定输入表示、NCO、角度和PI。
它是归一化输入之后的模块闭环，不是整条定点接收机，也未成为默认接收后端。

## 字、范围与算术

- 输入/输出I、Q分量为有符号18bit，开发比较Q10/Q12。Q10分量范围约±128，Q12约±32。
- 相位/频率为32bit整周字。相位有意按2^32回绕，积分频率限于RNE(2^32/(10M))。
- NCO复用原1024×17bit四分之一余弦表，12bit地址RNE，输出有符号18/Q16系数。
  新`phase_rotation_words`接收实际变量相位；原同步NCO仍最多128符号，没有解除旧API限制。
- 四个旋转实乘保留36bit乘积、37bit求和，RNE缩放后饱和到18bit；功率用另外两个18×18实乘。
- 功率转换到已有41bit/Q16节点，状态33bit、更新1/64、上升限2倍、保护κ4。
  分量被舍为零与功率平方被舍为零分别统计，不把它们写成无损弱信号放大。
- CORDIC对量化后的同一向量作有限公共左移，x/y为24bit、角度暂存34bit，18次向量迭代。
  公共移位只保护内部算术，不增加ADC信息；零向量返回“无角度”，溢出明确报错。
- 交替旋转在角度字中补偿，最近PSK扇区、误差限幅及PI都用整数。
  kp=1/32、ki=1/2048的缩放采用有符号RNE，负值也处理guard/sticky和偶数舍入。

`feed_words`每次1..32对已知整数，不含运行时浮点运算。NCO/CORDIC系数离线生成。
`track_fixed_carrier`仍有显式浮点→字桥，原同步增益归一化、滤波/插值和LLR/译码接口并未全部定点化。
该桥逐项报告饱和/擦除，不根据CRC换格式，不改期待载荷。整段输出/诊断仍由调用者持有。
每包最多131072线符号（含预热），字段切换保留状态，包间新建实例；不伪造EOF符号。

独立检查包含解析三角参考、Fraction舍入、全部象限、极值/零向量、公共缩放、
字段切换、任意1..32分块、实际IQ→MAC及严格BER重放。将模2π的两个坐标直接相减曾误报约2π，
原测试及失败已保存；改用连续解绕差，峰差预算仍为0.02rad。

## 开发选择与真实数值反例

新开发种子730117、PID1，改变FT2/3/4、MCS0/6/8/12、导频、载荷内容及长度、
单音/错误同步/突发与幅度变化、CFO/SRO和分数起点。先比较两种预定义格式：

| 8个合法输入 | 捕获/头CRC | 整包正确 | 错误bit/可算bit | 数值门 |
|---|---:|---:|---:|---|
| B1浮点PI | 8/8 | 6/8 | 4/22960 | 参考 |
| Q10 | 8/8 | 6/8 | 4/22960 | 通过 |
| Q12 | 8/8 | 6/8 | 4/22960 | **失败** |

冻结误差预算包括：输出归一化RMS≤0.005、峰差≤0.02，相位轨迹RMS≤0.005rad、峰差≤0.02rad，
平均频率差≤2Hz，且原成功零丢失、可算载荷BER不增加。不能用整包相同覆盖数值失败。

Q12的development-6在第1018数据符号附近，与浮点的检测误差分别取+π/8和−π/8，
下一相位差约0.025045rad，超过预算。此前相位差仅约0.000116rad，未见累加溢出或饱和。
这是最近星座扇区边界的路径敏感性反例；分数位更多并不保证轨迹更接近。Q12被拒绝，不在新保留集上重试。
原输入SHA、字轨迹、错误符号及源码在`carrier-fixed/development-first`及诊断中保存。

仅Q10通过开发后，格式/源SHA/预算被冻结。原计划使用PID6生成FT3/4时失败：
实际§6.2.3.3/4序列索引为0..5；部分首流、原生成器和异常全部保留，视作已查看开发资料。
先增加全配置预检，再冻结独立替代配方（种子760117、PID4、新长度/配置组合）才生成，
接收算法、格式、门限、预算及采用规则没有改变。不是将接收失败包换输入后判通过。

替代新保留8包：浮点与Q10均8捕获、7完整正确、2/28240bit残错，数值门通过。
Q10新验证的最大输出归一化RMS差约0.000787、相位RMS差0.000109rad、峰差0.000348rad，
平均频率差最大约0.662Hz（按4Msym名义速率换算，不是绝对RF频误差真值）。
单比特/少量残错仍按CRC失败保存；这不证明失败包理论不可恢复。

原SHA固定228流/96包已在真实Python/Rust环境复核：两方案仍87捕获、61完整正确，
零原成功丢失、恢复0，35失败保留。可算83帧/144248bit的错误为FFT参考4990、Q10为1423；
这是已查看固定回归观察，不把相对先前浮点PI的3bit差异外推为定点接收增益。
168负例6985435采样约436.6ms，未新增候选/交付，不宣称任意环境绝对零误检。
所有以前查看集合只作固定回归，后续不得围绕本保留集调参。

## 逐周期值与资源

周期模型携带实际整数旋转、每次CORDIC向量迭代及PI状态：

| 周期 | 工作 |
|---|---|
| 1..4 | 相位地址/ROM/系数；功率乘积3、求和4 |
| 5..9 | 功率RNE5、保护6；旋转乘积7、求和8、输出RNE/饱和9 |
| 10..12 | 领先零检测、公共移位、象限处理 |
| 13..30 | 18次CORDIC；已有功率节点8周期宏在13完成 |
| 31..33 | 规定交替旋转、扇区误差及限幅 |
| 34..40 | PI逐项RNE/相加/限幅和相位提交 |
| 41 | 计数/完成；下一字可通过显式状态转发启动 |

单字模型和直接整数节点逐字、逐状态对照，不只检查结束时间。
即使静默/低功率/异常向量，也按最坏41周期调度，不用跳跃静默的平均工作量代表吞吐。

模型假设ROM4周期、DSP3周期、宽加法/RNE各1周期、CORDIC每周期三个并行加法器，
以及同周期状态转发；这些是待实现验证的原语/端口假设，不是实际布局布线结果。

分项资源估算：6个25×18 DSP片（实乘均18×18），CORDIC并行24/24/34bit加法器，
旋转两路37bit加法器、34bit PI ALU、42bit功率ALU、领先零检测及两路24bit桶形移位器。
移位器的第11周期左移与13..30周期右移不重叠，可在该日历下复用；双向/操作数选通成本尚未映射为LUT。
18个19bit计数器及对应并行更新也计入；每包最多262144次分量事件，不需要无限增长计数。
另计系数/相位流水、队列与临时字。NCO额外一块RAMB18、两读零写，不能无证据与同步并发免费共享。
atan表18×32bit使用组合读，LUT/FF/布线与可选调试设施成本尚未完成。

原四深度输入FIFO与四深度输出FIFO持续有界。新增八深度输入候选多224bit，
属于事先声明的同一8DSP/2BRAM36模块研究范围；原16KiB失败不改判。

512个已知输入字、最坏SRO取整到4000401符号/秒的模型结果：

| 条件 | 发出/因资源而作废的字 | 最大字延迟 |
|---|---:|---:|
| 100MHz、连续 | 6/506 | 123周期 |
| 160MHz、连续 | 158/354 | 200周期 |
| 200MHz、连续 | 512/0 | 42周期 |
| 200MHz、同平均速率四字突发、输入深4 | 512/0 | 162周期 |
| 200MHz、八字突发、输入深4 | 0/512 | 整包作废 |
| 200MHz、八字突发、输入深8 | 512/0 | 322周期 |

输入不能暂停。首次队列溢出使整包无效，活动/待处理/输出及后续字的丢弃均有tag和原因，
不能把后来丢弃的字解释为评分算法漏检。下游长时间阻塞也明确作废，不能无限缓存。
出队的字不等于MAC包交付，缺失任一字后整包不得交付。

这只是载波字节点。捕获细搜索积压、同步后头部历史回放、头译码就绪时间、归一化、
RRC/插值、LLR/Polar和TX/MAC并发尚未接入本周期模型。八字突发通过不证明320头符号历史已被承接。
实际基础工程仅有100MHz证据，200MHz仍需后续独立时序论证。
**不能将本节点的200MHz条件结果写成整链接收16MS/s或实时FPGA能力。**

## 复现与下一步

```sh
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_carrier_fixed.py \
  --split development --output /tmp/carrier-fixed-development
PYTHONPATH=src uv run --frozen --no-sync python scripts/audit_carrier_fixed.py \
  --split validation --output /tmp/carrier-fixed-validation
```

目录须不存在，预期返回1，表示完整系统未验收。输出保存源/输入SHA、实际profile、
全部CRC/数值失败、字轨迹、每场景周期/丢弃及资源账本。旧228流可使用
`replay_carrier_loop_regression.py --word-fraction-bits 10`按冻结索引严格重放。

后续优先处理实际捕获/头部回放与载波队列的统一调度、100MHz下反馈延迟/并行取舍，
以及尚未定点化的增益和接收接口。保留原2%RRC、16KiB、细搜索最坏吞吐和整机缺口，
在完整RX验收前不展开大规模TX。
