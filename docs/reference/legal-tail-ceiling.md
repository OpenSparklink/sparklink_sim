# 实验：合法帧尾上界与有界保存

本模块服务于§6.3/6.9实际头校验后的样本所有权，普通FT2/3/4、4Msym/s、SPS4、
MCS8/12；标准版本与SHA见[标准来源](standard-sources.md)。不改变波形、同步评分、
候选/相位、Gardner/PI、载波、头部或数据CRC规则，默认接收路径不变。

## 依据与单因素候选

[移动下界试验](moving-tail-horizon.md)在新开发及两个固定集合均无接收增益，
却增加数千次控制计算，已拒绝。两个实际选中的尾部过期包，在保持原样本、
同步答案、PI/载波/解码且只放宽全局源过期时完整恢复；这指向保存/调度缺口，
不等于未知起点连续接收已经修复。旧25个失败与所有旧预算结论保留。

`UpperTailCaptureReplay`只把M38B静态下界换成一次合法上界，继续复用原控制器、
1024×46bit私有FIFO、4096字全局历史、3拥有窗及原样本端口。没有三槽整段尾部。
真实头CRC、长度/MCS合法后，已有严格解析器给出本包实际符号数N：

```text
maximum_step = UPPER_Q32 + RNE(KP_Q48 * maximum_clipped_error) = 17416609614
upper_fence = min(sample_limit,ceil((q0+(N-1)*maximum_step)/2**32)+3)
```

q0来自实际选中同步位置。最大步进包括500ppm积分器限幅之外的比例误差项，
不能只使用UPPER_Q32，也不能把瞬时最大步进当成实际SRO估计或标准合格限值。
逐步有`q[k+1]-q[k]<=maximum_step`，因此该界不小于同一实际PI的最终插值接纳界。
如果本包需求已经超过原sample_limit，仍是明确截断/资源失败，不制造输入。

这是可能需求的保存上限，不是实际消费末尾。保护字、比例项余量及头部未验证时
的临时预取可能最终未用；全部占用原FIFO信用并在终止时单独报告，不能计为消费。
每次实际查询仍按已提交NCO读取，同一包到达严格末尾立即停止；CRC失败不能
触发重选同步、频率或相位。EOF不补零，取消会清除本上下文而不发布陈旧尾界。

## 四层模型与成本

浮点/同龄有限字接收组件沿用已有实现；本节点只有有限整数计算。17沿移位累加、
1沿ceil/clamp、1沿注册输出，共19真实沿，每个真实合法头至多1个请求，没有队列。
53bit累加器、52bit移位常数、17bit余量、5bit步数、21bit界、3bit模式、63bit
影子时钟和192bit统计合计406bit，与静态下界相同；系数35bit，不新增位宽。
影子时钟借用既有时钟总线，不凭空增加高速发生器。

|成本|本候选|
|---|---|
|每合法头数学|最多17次53bit加法/固定移位，17bit N-1，21bit ceil/clamp，OR32|
|逐沿控制|5bit减一/零检测、模式/使能、源复制21bit比较/选择|
|统计|原3个64bit计数更新，未记共享收益|
|DSP/私有源RAM/全局读端口增量|0；原私有源2 BRAM36仍收费|
|桥控制总预留|1034bit；不等于整机物理FF总量|
|FIFO|原1024字1R1W；原窗口及共享历史不抵扣|
|未知|控制LUT/FF、布线/Fmax及整链载波/译码/端口期限|

没有逐符号PI快照、额外队列或重复计算服务。更多预取会增加实际读写与竞争，
必须连同误检、原成功退化、资源退出一起评价，不能只报寄存器相同。
512bit为开发前冻结的节点实验上限，原18DSP/16KiB等失败继续有效。整机仍须
保留TX、译码、实时MAC和接口/DMA资源，不能把本节点通过当作整机通过。

19沿在100/160/200MHz假设下为190/118.75/95ns，只是控制节点的可执行周期结果。
宽加法一周期是公开假设，没有综合或布局布线证据。持续检测、RRC、相关、细搜索、
窗口、插值、环路及残余载荷工作不能填0；不由该节点II推导整链16MS/s。

## 冻结验证与范围

```sh
PYTHONPATH=.:src:scripts uv run python scripts/model_legal_tail_ceiling.py --output /tmp/legal-tail-new
```

上述为M40冻结提交中的实验命令。后续B1输入检查修复后，该原实验的越界请求
会明确报错；复核历史结果使用证据目录内归档提交与`reproduce.py`，不重新生成输入。

新开发改变载荷族、FT/MCS、导频、短/长包及干扰联合配置。冻结设计原本想加入
CRC24的B1最大2044字节载荷，但实际配置继承了CRC32：2044+4=2048，超过11bit。
独立审计发现生成器把这个值截成0，再生成了正确的空头CRC；理想符号也复现。
因此该流第0包是非法测试输入，不能作为合法长包的接收或数值失败。原IQ、SHA、
期待载荷和CLI的名义12包统计全部保留，另列11个实际合法包，不改参考答案。
该配置的合法上限是2043，尚未用新IQ验证；A2长度不含CRC，B1包含实际CRC字节数。
现有信道参数范围保留，但与这些新配置/载荷的组合不同，不仅更换随机种子。
三个已查看集合仅固定回归。源码、参数、预算和采用规则冻结后，只有新开发和
三个固定集合全部通过才生成独立新保留集；失败不围绕保留集调参。

完整内容、头/数据CRC、长度/MCS、BER、定时/CFO、资源丢弃和数值预算分别检查。
不完整事务不计数值通过；同龄对照共享引导/插值，不能代替独立插值资格。
有限负例零新增误检必须附独立采样量，重复块/后端不增加观察时长。
要求无原成功丢失、无新增误交付、资源退出不增，并有真实整包或相同召回调度
收益；否则拒绝，不改默认。旧2.34835%>2%及独立插值失败不能由整包相同覆盖。

完整流式、全链定点、整机资源、连续16MS/s四门仍分别开放。FT1/GFSK、未知厂测
编码及其他符号率/SPS不因控制器可计算而扩大支持范围。

## 冻结结果与采用结论

|集合|实际长度合法包|原参考正确|静态下界正确|本候选正确|相对静态恢复/丢失|
|---|---:|---:|---:|---:|---:|
|新开发|11，另1非法生成向量|8|3|4|1/0|
|固定M38B|12|8|4|5|1/0|
|固定M37|12|8|4|5|1/0|
|固定M39|12|8|3|5|2/0|

五个恢复均经过真实头/数据CRC及完整MAC字节比较，不是真值边界回放。四组细搜索
工作分别保持240020/225418/192510/221824沿；复制从20385→20635、19964→20238、
14924→15127、19457→19814字，增加的访存全部收费。每组仍只需6次尾界请求，
每次19沿；不是移动方案的数千次重算。私有峰值达到原1024字，不增加容量或端口。

相对原参考仍丢失4/3/3/3个成功包，队列退出仍增加，四组采用门均失败；新开发还
有独立的输入合法性失败。因此**不推广默认、不生成保留集**。保留29个未完整
匹配的名义向量：28个合法包失败和1个生成器溢出。诊断不把失败解释为理论不可恢复。
下一独立修复先拒绝B1越界打包；当前输入不改成2043后重算通过。

候选合法包捕获关联为7/8/7/7，数据CRC与完整载荷均为4/5/5/5；头CRC计数7/6/6/6，
其中新开发含上述错误生成的空头1个。合法长度、期待长度、MCS分别记账，头CRC
通过不代表发送者意图正确。可计算BER为271/6416、2/5088、2/4688、2/6880；
可计算子集不同，不用这个分母变化宣称BER收益。突发残余错误仍是失败。

25个完整同龄数值对照均满足原预算，最大中心误差3.922e-6采样、速率0.002999ppm、
归一化RMS9.607e-6、峰值7.776e-5。不完整事务排除而非通过；同龄共享引导/插值，
不是全链定点或独立插值资格。旧2.34835%>2%、Lagrange及16KiB失败保持。

整段、固定和随机RRC输入块按原协议严格一致；两实际后端329份科学文件中的
411个NPY成员逐字节一致，69处后端标签单独核对，不声称JSON整体相同。
16份不同SHA负例共131072采样，即16MS/s下8.192ms，零新增相干确认/误MAC；
重复分块及后端不增加独立观察时间。这不是全环境零误检或新射频路径验证。

本地73项针对性、6168/6179项全量，覆盖率93.93%/93.94%通过；模型采用失败与
测试通过分开记录。证据根的`legal-tail-upper-envelope/`保存完整漏斗、原始报告、
输入/源码SHA、未配对记录、恢复及失败关联、成本和依赖。`reproduce.py --backend both`
使用归档真实提交及原SHA输入；内层预期返回1，外层0只表示复现一致。

此前阶段CI被后续推送取消的事实保留。CI并发组改为保留运行、最多100个等待，
避免原子推送中断长模型证据；不删除作业、不提高120秒/覆盖率门。队列行为依据
[GitHub官方说明](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency)，
远端实际状态和制品另存，排队不等于通过。没有新综合或布局布线结果。
