# 标准 B1 的有界重组、双 CRC 与 MAC 交付

本阶段连接[译码输入槽](payload-polar-ingress.md)和 U/O 的注册输出，
使用第 6.9.1.3 节、附录 A 的标准 B1 分块及帧 CRC24A/CRC32，
多逻辑块使用块 CRC24B。接受已验证 FT3/4 头提供的长度、码率和链路
CRC 种子，入口为 4 Msym/s QPSK/8PSK 已解扰的 LLR。旧 IQ 到 MAC
接收路径维持，有限帧消费者通过 `replay_b1_payload_frames` 独立调用。

## 服务和失败边界

1. U/O 末端实际按每沿两位交付，首对有效位在寄存读后一沿。同沿先处理
   输入侧资源丢字，再处理输出位。每个接纳字携带帧身份和物理字几何，
   已开始的译码和两个槽最多同时涉及三个有待退休的帧身份。
2. 逻辑块前导填充不进入 CRC。逻辑块 CRC 包含该块数据及其末尾 CRC，
   跨物理字连续更新。帧 CRC 消费拼接后的数据与帧 CRC，跳过块 CRC。
   两个移位寄存器均验证余数为零，块种子取实际配置的低 24 位。
   块、帧结论和坏块总数分别留证。只有真实长度和所有适用 CRC 都通过
   才准许读出帧 RAM。
3. 暂存数据 RAM 容量 2044 字节。写入最多每四个结果沿一字节，
   待 CRC 成功后每沿可向 MAC 发一字节，读寄存器延迟一沿。
   MAC 未准备好时保留已验证的帧；这时另一个开始输出的帧明确记录
   `mac_buffer_busy`，按模型继续退休其译码字。单 RAM 服务不向
   Polar 反压。空载荷也要通过帧 CRC，之后可产生零字节交付。
4. 资源丢字即标记帧无效，阻断其暂存内容的交付。EOF 截断记录时
   清除截断帧，已完整接纳的较早字及已经验证的帧可继续退休。
   错误 CRC、错误种子、缺字、截断和输出 RAM 忙的反例分别验证。
   所有位决策维持原 Polar 运算，CRC 不参与捕获、配置或软值选择。

可显式加入[末码字暂存](payload-polar-ingress.md)。候选可让两
常规槽之外的一字完成真实双 CRC，但其通过后使用同一帧 RAM。
输出阻塞时，先验证的帧继续持有 RAM，后来帧可收到
`mac_buffer_busy`。独立试验保留这种恢复与退化同时存在的证据。
扩展估算按四个描述符，仍为单帧交付 RAM，默认两槽保持。

## 同一块 RAM 的环形分配实验

`mac_ring=True` 按可信 B1 头给出的长度，为开始重组的帧预留整段
字节。仍使用 2044 字节 RAM，含正在重组的帧最多有三个预留。
已通过双 CRC 的描述符入队，按帧序用原一沿注册读端口交付。
帧最后一个字节完成后释放整段。CRC、资源或 EOF 失败只撤销
正在重组的最新预留，持有的较早帧保留。空载荷也占用描述符。
字节容量和描述符用尽分别报告 `mac_capacity_full`、
`mac_descriptor_full`。验证覆盖跨界环绕、撤销和相邻帧。

预留按逻辑地址连续排在队尾，回绕用一次比较与减常量 2044。
释放只移除最老段，撤销只移除最新段。预留总量受 2044 约束，
因此读区和在写区互不重叠。允许每沿一读一写，
禁止同地址读写；定向回放验证了同沿不同地址。按 2048×9
RAMB18E1 真双端口一读一写估算，沿用一块数据 RAM；
另计 377 位描述符、位宽有界指针、控制和地址预留。
控制寄存器、LUT、布线和 Fmax 仍需实际验证。

| --- | ---: | ---: |
| 两槽 + 单帧 | 22 | 0 / 0 |

| 两槽 + 环形 | 28 | 6 / 0 |

保持末码字槽时，环形布局在固定 60 个帧臂把完整交付 38→42，
消除上个实验的四次已验证 MAC 争用（开发与先前保留各两臂）。
新保留中，最大帧与已在 RAM 的数据相加可超过容量。
2043+2 和 122+2044 两例分别在 160/200 MHz 丢失一个旧参考成功，
组合方案未通过通用采用门。两槽环形在本组未观测到旧成功退化，
各布局继续作为明确选择。当前压力模型使用有界的初始 MAC 停顿，
后续须以实际时隙、MAC 服务和连续 ADC 联算。阶段证据在冻结根
`b1-mac-ring`，包含真实 Polar/CRC/MAC 执行、旧回归与容量失败。

## 周期、容量及证据

先前的独立几何核对遍历 24534 种合法长度与 CRC/码率组合。
最大 71 个逻辑块、末块最多 4 个物理字，相关边界均为偶数。
实现流式保存头尾两套逻辑块参数和当前计数，RAM 不为每个块复制。
额外数据容量为 16352 位，按 2048×9 单口一块 RAMB18 估算。
输出持有与帧写入互斥，所用端口有读寄存器延迟。两 CRC 累加寄存器至多
56 位，控制与上下文另估 579 位。两位更新的 XOR2 上界分别为
块 CRC24B 26、帧 CRC24A 16、帧 CRC32 30，另计零余数比较和选择。
采用紧凑 Polar 时，本阶段把数据及几何/译码 RAMB18 等效由 18/22
增加到 19/23。估算无新增 DSP。LUT、物理时钟及共享端口仍需验证。

独立整数多项式长除法核对校验，另用 SSC 参考重组完整码字。
开发业务 24 臂、72 个帧结果中 52 交付、12 CRC 失败、8 资源丢帧。
冻结后的新保留 36 臂、108 个帧结果中 56 交付、16 CRC 失败、
32 资源丢帧、4 输出 RAM 忙。新保留包含 100/160/200 MHz、
CRC24/32、不同种子、最大合法长度、受损 CRC 及 MAC 停顿。
开发的 CRC32 最大 2043 字节帧在有界 RAM 中完整交付。
分别保存两后端每个帧的实际 LLR 哈希、CRC、字节和时间戳。

两份标准布局冻结 IQ 以整段和随机分块接收，在原解码器入口抓取
实际已解扰 LLR，再送有限消费者的两种定点格式，共 8 臂。
交付内容、块/帧 CRC、分块及采样中心一致。原八份 B1 IQ 父版
正反证据和另外 228 流固定回归逐项保留。合成和冻结测试的交付
结果不改变完整流式、全链定点、整机资源和连续 16 MS/s 四项验收门。

未完成的接口包括实际头部到本模型的时钟内转发、连续 MAC 响应期限、
对上游的联合反压以及更完整的整机功耗和布线证据。输出 RAM 持有时的
丢帧继续计入资源边界。后续[有限软解映射](psk-word-demap.md)已按导频线序送入实际 B1 端口。
冻结证据根下 `payload-b1-crc-service`
含 `REPRODUCE.md`、源码与输入 SHA、逐沿结果及所有失败。
