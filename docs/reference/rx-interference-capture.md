# 持续干扰中的捕获改进

本轮从`3a275d7`开始，模型对标PSK §6.2.1.2、同步 §6.5/6.6、CRC §6.9。
仅离线算法/测试/文档/CI。沿用浮点参考、硬件结构、定点及周期四层，未重做已有相关银行。
所有原始IQ只读，旧证据按冻结元数据和SHA读取。

## 阶段及先验预算

1. 保存逐窗漏斗、预筛旁路及突发错误真值诊断，先确定缺陷位置。
2. 新开发选择少量有界因果捕获候选，冻结后新保留及旧成功回归。
3. 新动态范围开发选择有限缩放结构，冻结后新保留及旧数值失败回归。
4. 将RRC、细搜索、窗口保存、有限队列/背压纳入周期模型，公布失败情景。

定点有效未饱和参考分数≥.55时，分数误差和归一化排序损失各≤.005；
浮点结构平方分数差≤1e-10。同算法分块中心差≤.25采样、捕获起点差≤.125；
原成功零损失、固定负例零新增候选/误交付。算法本身变化另列真值误差和召回，不把变化藏进数值容差。
新捕获开发/保留种子370117/380117，新动态范围390117/400117，旧集合只回归。

资源受限对照沿用200MHz、18个25×18乘法原语、16KiB逻辑捕获状态目标，
新增队列、流水、端口都计入，可重新分配原FIFO；超预算或达不到16MS/s明确失败。
既有整数预筛15.61KiB/II12是模块级假设结果，不等同于整链或综合。
原始持续检测计全输入成本，不用静默跳跃后的平均工作量代表最坏吞吐。

## 第三阶段：相关银行有限指数格式

新增显式`correlation_backend='scaled'`，默认10位尾数；`fixed`原固定缩放及旧失败保持。
输入是每个复采样共用一个7位有符号指数、两个有符号尾数，物理值`mantissa*2**exponent`。
指数仅允许[-48,32]，保留一位尾数余量；按本采样最大实/虚分量做二次幂规格化、最近偶数舍入。
无估计窗口、无未来样本、可包内更新；这只是表示格式，不能改善SIR，也不能恢复ADC已丢信息。
指数钳位、尾数饱和及中间越界分别计数/报错，不将格式范围外样本算成精度通过。
当前边界接收浮点RRC输出，未来硬件需明确上游二进制定点及小数位；不是全接收机定点化。

共享差分及差分功率仍只算一次，同时保存8位差分指数。
每个新整数位置用31个非零差分的最大指数对齐，差分与已缓存功率各自RNE右移；
重新求和对齐后的能量，不错误地混用旧指数下滑动能量。
平方门限和归一化交叉乘积排序保持整数；无除法/开方进入选择。
零能量明确拒绝，大于字宽的移位明确归零，正/负半LSB用同一偶数舍入规则。
整数尾数/指数端口用于未来RTL对照；浮点比较仍按已冻结误差预算，并不要求浮点逐位一致。

新开发种子390117的24个数值端口用例包含固定比例、随机分块比例、连续斜坡及
1e-8↔1e5强弱切换；这是输入端口数值压力，不冒充合法包通过率。
8/10/12/14位最大分数误差分别.003755/.001051/.000311/.0000631；

保留753个参考分数≥.55的位置：最大分数误差.001088、排序损失0、门限判定差0，
无指数越界、饱和或中间溢出。8位开发也未超.005，不谎称更低位宽必然失败。

新格式分别.000396/.000182，未改参考答案；这只是两个节点的恢复，整包回归另列。
已有96包固定回归仍83捕获/58完整正确，细搜索161，负例零候选/误交付；
浮点/有限指数、整段/固定/随机及实际Python/Rust的匹配轨迹差均为0。

## 第四阶段A：细搜索工作量及有限队列边界

本阶段是当前细搜索图的必要条件和诊断调度，不是整捕获链周期验收。
`capture_capacity`按源代码计算网格尺寸：256采样、SPS4、32同步符号、1/8采样网格，
共有32相位、1040合法位置。即使假定4个整数相位完全免费、参考相关只需符号加减、
插值/系数准备/归一化全部免费，剩余28相位仍有1757次复差分和910个平方相关分子。
按复乘的三实乘形式，变量乘法等效数下界为`5*1757+2*910=10605`/请求。
这是**当前逐相位操作图在所列复用后的下界**，不是所有数学重构的全局下界。

每32输入一个请求时，16MS/s对应500000请求/秒，需53.025亿实变量乘法等效操作/秒。
若变量乘法只映射到DSP，且每次甚至只占一个原语，18路×200MHz只有36亿次/秒；
仅细搜索便至少需27路，尚未分给RRC、检测、双银行或包内处理。
更宽操作的分片、非线性及端口只会增加本图工作；LUT乘法器、跨相位代数复用或新局部搜索
属于新的结构方案，需另列成本与召回，不能由这个下界推断任何可能接收架构都做不到。

### 存储、端口与未完成项

在44bit/复采样、双12202bit银行、384采样双历史、三个256采样拥有窗口、描述符、
RRC延迟/系数的假设下，逻辑容量**下界**96054bit（11.73KiB）。
扩大历史640/1024采样，下界分别118582/152374bit；1024已超过16KiB，尚未加入工作状态。
这些下界不含单音状态、输入FIFO、样条工作区、流水、端口复制和后级；不能与旧15.61KiB
（包含原FIFO/工作寄存器）的不同范围估算比较后声称节省，更不能称新方案已满足16KiB。
8读/周期复制同时需要8次目标写入及持续输入写；须银行化/复制或另行调度，不能当单个双口RAM。
实际BRAM/LUT粒度、位宽精度、RRC及样条执行调度、定时/载波/头/载荷/译码尚未闭合，未综合。

原保留只回归，不能用提高资源上限、CRC重试或更改期待载荷掩盖上述失败。
全链定点、FT1和逐MCS支持盘点、延迟反馈及最终RX-GATE仍未完成，不进入大规模TX实现。
