# 持续干扰中的捕获改进

本轮从`3a275d7`开始，模型对标PSK §6.2.1.2、同步 §6.5/6.6、CRC §6.9。
仅离线算法/测试/文档/CI。沿用浮点参考、硬件结构、定点及周期四层，未重做已有相关银行。
所有原始IQ只读，旧证据按冻结元数据和SHA读取。

## 阶段及先验预算

1. 保存逐窗漏斗、预筛旁路及突发错误真值诊断，先确定缺陷位置。
2. 新开发选择少量有界因果捕获候选，冻结后新保留及旧成功回归。
3. 新动态范围开发选择有限缩放结构，冻结后新保留及旧数值失败回归。
4. 将RRC、细搜索、窗口保存、有限队列/背压纳入周期模型，公布失败情景。

定点有效未饱和参考分数≥.55时，分数误差和归一化排序损失各≤.005；
浮点结构平方分数差≤1e-10。同算法分块中心差≤.25采样、捕获起点差≤.125；
原成功零损失、固定负例零新增候选/误交付。算法本身变化另列真值误差和召回，不把变化藏进数值容差。
新捕获开发/保留种子370117/380117，新动态范围390117/400117，旧集合只回归。

资源受限对照沿用200MHz、18个25×18乘法原语、16KiB逻辑捕获状态目标，
新增队列、流水、端口都计入，可重新分配原FIFO；超预算或达不到16MS/s明确失败。
既有整数预筛15.61KiB/II12是模块级假设结果，不等同于整链或综合。
原始持续检测计全输入成本，不用静默跳跃后的平均工作量代表最坏吞吐。

## 第一阶段：预筛漏检归因

旧88流/64包基线重放逐帧完全一致：51捕获、35整包；13漏检中11流有能量触发但无细搜索，
2流细搜索后无候选。诊断旁路仅取消整数预筛，保留能量门、.85门限、原相位网格、
搜索范围和最大峰未来等待规则，**仍51捕获/35正确，零恢复**。
细搜索90→7555次（约83.94倍），计算相位2880→241760，位置93600→7583886，
且零新候选/误交付。这不支持直接降低预筛门限；未证明降低预筛可以改善弱包能力。

`FunnelObserver`仅在实际处理之后计算独立整数/细搜索分数，保存包附近每个窗口的
能量/门限、归一化分数及位置、未来样本需求、skip范围、活动候选和拒绝原因。
真值只限制诊断日志范围/事后匹配，不进入基类选择；测试比较观察前后帧、CRC、等待状态及全部轨迹不变。
每流均保存按百万采样计数的能量触发、预筛拒绝、细搜索、候选及误交付。

突发干扰8包诊断：提供真实采样中心和注入CFO、只用已知同步字拟合复增益，
随后仍走同一严格帧解码，只有1/8整包正确，与实际链路相同。另保存实际定时/真值载波、
真值定时/实际粗载波分离对照；这些oracle不计入正式通过率。理想中心不能恢复已损伤样本，
没有证据支持直接重写定时环或升级Polar；坏数据CRC反例在oracle下仍失败。

旧定点失败精确节点：`sim-0021`起点195，滤波后最大分量.0113568，64个输入分量全部
被LSB=.125舍入为0，相关分数.5582528→0；不是中间溢出。
派生真实IQ起点1019184最大分量3.08231，64分量中61个非零；输入舍入经差分/能量传播使
分数.5815260→.5734784。两种原数值失败保留，不因整包相同视为通过。
