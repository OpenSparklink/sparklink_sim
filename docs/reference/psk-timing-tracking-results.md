# PSK持续定时跟踪：离线验证结果

后续对原九个噪声失败的分阶段修复见[噪声恢复结果](psk-noise-recovery-results.md)。

接收核心提交 `b1e664a`，初始捕获固定为1/8采样网格；另一臂打开
Gardner/PI包内跟踪。两臂的同步选择、能量分段、载波细化和验收规则相同。
控制格式为FT2/A3，数据无编码/导频/加扰，数据参考始终为完整PRBS9。
这份结果限定于离线算法模型，不代表实时FPGA或完整SLE验收。

## 整包结果

| 输入 | 固定相位 | 持续跟踪 |
|---|---:|---:|
| 仿真原开发/保留集 | 138/172 | 163/172 |
| 新增CFO50kHz/SNR30dB保留集 | 10/18 | 18/18 |
| 真实原始IQ完整包 | 63/63 | 63/63 |
| 真实IQ附加±100ppm派生完整包 | 84/84 | 84/84 |
| 4份静默对照的同步候选 | 0 | 0 |

208对输入中恢复33个包，未发现原成功包退化。
真实QPSK记录末端的一个截断候选在两臂均保持截断，未计入完整包分母。
9个仿真输入仍失败：两集合、两调制的15/10dB共8个，
以及原保留集8PSK的100ppm+CFO50kHz+20dB+幅度渐变组合。
这些失败含能量段切碎、无足够长能量段及截断，仍保存原始失败判定。

2047字节、±100ppm原保留集的结果如下。
“包尾误差”使用独立发送真值和实际采样坐标，单位为输入ADC采样。

|---|---:|---:|---:|---:|---:|
| 8PSK | -100 | 2.1844 | 0.00776 | 0.51563 | 0 |
| 8PSK | +100 | -2.1474 | 0.00695 | 0.11786 | 0 |
| QPSK | -100 | 3.2776 | 0.00292 | 0.50800 | 0 |
| QPSK | +100 | -3.2406 | 0.00207 | 0.48724 | 0 |

环路带宽0.003、积分速率界±500ppm，在开发集三个带宽候选中按真值误差冻结。
新增seed33016、偏移0.317采样的18个输入在冻结后复核，没有再次调整参数。
单元测试另外覆盖未知随机数据、包内0→+100ppm时钟变化，以及8/16SPS的接收。

## 计算成本与限制

每份真实原始IQ为65.536ms，包含1,048,576复样本；以下是本次单进程实际耗时，
不是隔离CPU微基准，也不包含发送生成、压缩和写盘。

| 调制 | 固定平均ms | 跟踪平均ms | 固定/跟踪 Msamples/s |
|---|---:|---:|---:|
| 8PSK | 113.57 | 135.78 | 9.23 / 7.72 |
| QPSK | 133.48 | 162.56 | 7.86 / 6.45 |

整批实验18.80s，进程累计RSS高水位约310MiB（含生成、压缩、存档）。
反馈插值已使用预计算三次系数的标量Horner求值，但当前Python模型仍慢于实际采样率。
RRC居中滤波及样条预计算仍使用离线数据，不宣称流式硬件实时性能。

真实IQ原始SRO未知，积分器速率只是接收机估计，不是校准真值。
限幅事件不等于失锁或周期滑移；已知真值的误差稳定区也不是接收机锁定声明。
长包仅验证A3字段及模型范围，未证实WS63厂测或具体调度配置允许这些包长。
