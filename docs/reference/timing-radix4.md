# 两位商定时除法结构（RX-TIMING-RADIX4）

本阶段只改变现有有限 Gardner/PI 服务的除法调度，适用 §6.2.1.2 PSK 链路模型，
不是标准规定的实现结构。捕获评分、候选、插值、环路参数、功率更新、RNE、
头 CRC、长度与载荷算法均保持。原 `full` 和 `bounded-prefix` 默认行为不变；
新配置 `timing_divider="radix4-prefix"` 只作为显式实验。

## 数据通路与误差门

继续使用已证明的零商前缀，在一个真实注册边沿检查前缀并载入余数。
接着用一个边沿计算并保存 `3D`，`2D` 只需连线。
每个后续边沿把余数左移两位并拼接两个被除数位，与 `D/2D/3D` 三路并行比较，
优先编码得到商位 0–3，选择一个倍数并做一次减法。
没有把两次串行逐位迭代或 Python 整除藏在一个时钟内。

分母 49 bit；中间量小于 `4D`，需要 51 bit；提交余数小于 `D`，仍为 49 bit。
商寄存器复用原 `error_bits+2` 位。三个已编译格式剩余商位均为偶数，
不新增任意格式接口。最后沿用原倍余数比较和 ties-to-even，符号处理及限幅不变。
零输入、零结果/限幅旁路不经过新除法，错误分母、前缀或计数溢出仍明确失败。
未完成计算不得提交功率、误差、积分器或 NCO；反压保留结果，EOF/abort 不重试答案。

预先定义的采用条件为字、状态、轨迹、帧判定和全部载荷精确相同，
原成功损失 0，无新增 DSP、源 RAM 或端口，新增寄存器不超过 128 bit。
该新结构预算不修改原 4096 bit/16 KiB 等失败，也不放宽任何浮点误差预算。
每拍 51 bit 比较、选择、减法是一项尚未综合的延迟假设，不能当作 200 MHz 时序证明。

## 运算、存储与系统关系

| 节点 | 原 bounded-prefix | 两位商候选 |
|---|---:|---:|
| 30/32 除法迭代 | 34 | 17 |
| 注册前缀检查 | 1 | 1 |
| 注册 `3D` 准备 | 0 | 1 |
| 每迭代比较/减法 | 1×50 / 1×50 bit | 3×51 / 1×51 bit |
| 30/32 非零非旁路定时服务 | 75 边沿 | 59 边沿 |
| 相对前缀版寄存器增量 | 0 | 51 bit |
| DSP / 新源 RAM / 新端口增量 | 0 / 0 / 0 | 0 / 0 / 0 |

新准备需一次 51 bit 加法；移位为固定连线，迭代无乘法、除法或开方原语。
选择网络上界从 100 到 202 bit，不把它当寄存器或免费布线。
4 DSP 定时银行保持，不因 TDD 给出与 TX/译码共享收益。
候选定时组合状态上界 5612 bit，原 4096 bit 门仍失败；LUT、FF 实际映射和 Fmax 未知。
整机 RX/TX/译码/实时 MAC/接口预留仍见 [系统账本](system-feasibility.md)，
机器记录在 `system-target-ledger.json`，替代节点不能与旧节点重复相加。

即使按 59+45 运输+24 归一化的当前串行结构下界，仍需 128 周期/符号，
超过 100/160/200 MHz 下分别 25/40/50 周期预算。
这个下界还没有完整捕获、载波、LLR、译码、包调度和接口开销。
不能把本地运算节省计为整链连续 16 MS/s 已满足。
如果每次比较/选择/减法必须切成两个反馈边沿，17次迭代变为34边沿，
另有新增准备边沿，非旁路服务将为76边沿，反而比原75多1；
这是延迟假设的算术敏感性估算，不是已执行的两级流水模型。
因此是否采用还取决于未来组合路径与布线证据，不能仅据Python可运行选择。

## 重放与验证分层

```bash
PYTHONPATH=.:src:scripts uv run --frozen python -m scripts.model_timing_radix4 \
  --output /tmp/radix4-development
PYTHONPATH=.:src:scripts uv run --frozen python -m scripts.model_timing_radix4 \
  --freeze /tmp/radix4-development/freeze.json --output /tmp/radix4-validation
```

两个命令预期退出 1，且必须生成并核对 `model.json`；异常退出不能计为保留资源失败。
输出目录必须不存在。开发后冻结源码、政策、预算与采用规则，再运行独立整数验证种子。
整数验证以独立 `Fraction` 舍入和 `divmod` 为依据，不以 CRC 评价数值。
没有新 RF 参数选择，所有已查看波形仅作固定回归，不能称为新的接收保留集或接收率提升。

固定 9 输入覆盖 FT2/3/4、标准 CRC24/32 及显式 legacy 长度合同，
两头银行、固定与随机输入分组，逐项比较真实头/数据 CRC、长度/MCS/载荷、
四轨迹、两组环路状态及所有保留源字。期望载荷只在接收完成后核对。
两个原输入各自以两银行、100/160/200 MHz 对比新旧连续后缀，
持续输入只从头等待开始，前序源可暂停，输入是已滤波 46 bit 字，不含连续 ADC/RRC/捕获。
缓存保持 512 字，首个资源失败及未处理后缀明确记录；头未验证为 null，不伪造 MAC 交付。

完整流式、全链定点、整机资源、连续调度四门分别保持开放。
旧 2.348%＞2%、插值误差、全部失败/资源退出和正式 61/96 压力结果不重写。
真值诊断失败不表示理论不可恢复，本结构精确不变也不声称恢复更多压力包。

## 固定回归和资源观测

开发整数向量 5172 项全部与独立舍入/整除参考相同，所有商位 0–3 均被实际覆盖。
固定 9 输入、两银行和三分组共 54 次对照，旧完整包全部保留、误比特为 0，
无新增接收率收益；本项不是新 RF 保留验证。
30/32 每次实际非旁路服务省 16 周期，固定帧累计省 2112–10928 已建模边沿，
完整载波/译码的延迟仍为未知，不能把这个差值写成整包延迟。

两输入、两布局、三时钟、新旧两方案共 24 份连续前缀日历全部历史溢出。
标准 B1 CRC32 的 dense/200 MHz 从 6588 边沿、225 符号延长至 6638、226；
parity/160 MHz 从 5310、226 延长至 5350、228；
parity/200 MHz 从 7338、240 延长至 7538、244。
三个场景头 CRC 已真实通过，载荷未完成、数据 CRC 为 null。
低时钟未完成头的场景退出保持相同，不把省周期换成 CRC 重试。
这些日历只复用两个输入，不是 24 个独立接收样本，也没有增加负例观察时长。

候选仅接受为逐值精确的显式结构实验，连续调度验收未通过；
同一通路的 51 bit 并行比较能否达到目标时钟仍需未来综合/布局布线。

30/32 每个非旁路符号的除法部分由34次50bit比较、34次50bit减法，
变为51次51bit比较、17次51bit减法及1次51bit准备加法。
SPS4下，最坏每输入采样分别为12.75次比较、4.25次减法、0.25次准备加法；
这是除法子节点折算，功率/TED/PI、运输、归一化及其他模块另计，不能当作整链操作总数。
循环少不代表所有门级计算都减少，三比较同时工作需要更宽的组合资源。
