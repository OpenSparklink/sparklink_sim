# 实验：细搜索与已选帧回放重叠

范围为普通 FT2/3/4、4 Msym/s、16 MS/s、MCS8/12。帧与 CRC 的核对范围见
[标准来源](standard-sources.md)。基线为[合法尾界与排队淘汰](queued-tail-composition.md)，
采用门和容量记录在 `scripts/fine_frame_overlap_policy.json`。候选只改变调度时机，
保持同步评分、相位网格、定时环、头 CRC、载荷处理及默认入口。

一个细搜索服务与一个已选帧所有者可以各占一个候选窗。保持 3 个候选窗、4096 字源
历史、1024 字私有 FIFO、两个源访问端口以及一份选中同步字缓存。帧完成相干确认
及初始化、安装帧状态后才释放同步字读权。下一细搜索可以使用释放后的缓存。
完成的选中结果等待唯一帧所有者。失配结果可提早退出。预细搜比较优先占用同一
注册比较器，队首仍按上一沿的实际消费前沿决定是否释放。输入 epoch 中止会回收两
个所有者与其窗口。下游阻塞按原有限队列处理。

第一版在相干确认或初始化还在读选中同步字时已经启动下一个细搜索。保留失败测试
及第一版报告。修正只推迟复用时点，保留原门限、相位、容量及采用门。第一版已经
使用过的开发输入归入固定回归。独立保留集只在开发和固定回归通过后生成。

调度模型计入 133 位新增寄存器状态，以及至多 448 位额外描述符选择逻辑。独立候选
窗使两者可以并行读，源 RAM 仍共用原端口，模型未增加 IQ RAM、DSP 或采样端口。
源历史估计占 8 块 BRAM36，三个候选窗占 6 块。计入原有私有历史 2 块和选中
缓存 1 块，这部分合计 17 块，独立于 RRC、细搜索暂存、译码、TX、实时 MAC 与
接口缓存。此处按 46 位历史数据、44 位选中缓存数据及实际端口映射取整。
同龄数值门比较时钟与相位相同的完整对照。资源中止和部分轨迹单独报告。该结果只
覆盖已建模的调度费用，载波、载荷和译码尚未获得完整周期账本。

```sh
PYTHONPATH=.:src:scripts uv run --frozen python scripts/model_fine_frame_overlap.py \
  --role fixed-regression --inputs /path/to/inputs.json --baseline /path/to/results.json \
  --output /tmp/fine-frame-result
```

冻结复查需要原输入清单、相同 SHA 的 IQ 和未重叠调度的基线报告。退出码 1 表示
冻结采用门拒绝。FT1/GFSK、WS63 厂测 profile、全链定点以及整机资源和时钟验证依照
[验收范围](rx-scope.md)单独跟踪。

## 本地复核与时钟假设

Python/Rust 环境分别执行 6214/6225 项，跳过 38/5 项，覆盖率均为 93.94%。
首轮争用下有分片超出 120 秒，保留完整原日志和失败报告。保留测试身份后，原
超期片补跑通过，最终可核验报告的最长分片为 112.604/116.447 秒。Ruff、严格
文档构建和针对性测试通过。远端实际作业与制品另按提交 SHA 记录。

本阶段重放使用 200 MHz、16 MS/s 的 RRC 发布历和两个源端口，输入不能暂停。
孤立 RRC 的 II12 要求至少 192 MHz，100/160 MHz 下已不满足该配置的必要条件。
200 MHz 下仍观察到有限队列和首续样过期，且载波、载荷及译码服务周期不完整。
17 块 BRAM36 是已列出的存储子集估算，保留原 18 DSP、16 KiB 失败和独立的
2.348% > 2% RRC 量化失败。全链定点、FT1/GFSK 流式、整机资源和连续
16 MS/s 调度仍待验收。本阶段无新综合或布局布线结果。
