# QPSK/8PSK 定点软解映射与 B1 端口时序

实验入口 `replay_b1_symbol_frames` 接受已归一化并完成载波校正的线序
符号。已验证头提供长度、MCS、导频间隔、绝对符号奇偶及扰码和 CRC 种子。
已知同步残差方差或显式方差在首个符号前提供。本组件把带时间戳的 LLR
送入[实际 Polar 输入槽](payload-polar-ingress.md)，随后由
[有界 B1 帧服务](b1-payload-service.md)执行重组、CRC 和 MAC 交付。
原 IQ 接收默认保持。

## 运算和节拍

- §6.2.1.2 的 Gray 映射和奇偶轮转编入两个系数表。每符号有
  4/8 个带符号投影乘积，反点取负；max-log 消去同一星座的公共能量项。
  相应最大值差用 38 位有符号字，恢复按噪声方差加权的 LLR。
- I/Q 为有符号 18 位、14 位小数，系数为有符号 18 位、16 位小数。
  投影保留 37 位。增益使用 18 位、17 位小数尾数与带符号指数，
  高低部分的乘积合并在 56 位。输出舍入到最近偶数并饱和到 ±64，
  提供 Q8.0/Q9.1。极低方差沿用 1e-12 下限，超出输入动态范围的
  截限和软值饱和计数留证。
- 导频仍占一个完整线序符号。去掉导频 LLR 时，绝对奇偶、实际到达沿
  以及数据符号号保持。仅数据的有效编码位按 §6.10.4 前进扰码状态，
  B1 的 256 头位跳转采用七个 GF(2) 列。尾符号的填充位不进入译码。
- 线序符号到其 LLR 的注册交付为第 24 沿。组件计划依次使用最多 8 个
  投影乘积发射沿、8 次候选更新和 3 次并行分拆增益乘积发射，
  寄存及舍入留在预算内。模拟器对实际有值输出逐拍标记与核对。
  100/160/200 MHz 的符号节拍分别 25/40/50 沿，按规定 4 Msym/s
  输入只有一个符号上下文。LLR 通过共享符号边界时，Polar 的两个槽
  各接纳对应部分。内部算术宏单元时延属于结构假设，仍须综合核对。

估算投影一个 DSP、增益乘积两个 DSP，系数/标签/跳转常量约 513 位，
主状态约 632 位，无新增数据 RAM。LUT、时序及跨级合并须另验。
增益系数目前由给定浮点方差准备，真实有限倒数、归一化/载波校正及
头上下文到达时间仍待接入和明确计时。

## 实测边界

| 对照 | 结果 |
| --- | --- |
| 开发额定符号 | 2986 个软位，2 个有差异，最大 1 个量化码 |
| 独立保留额定符号 | 2946 个软位逐码一致 |
| 方差下限、轴附近及输入截限 | 2940 个软位，3 个超过 1 码，最大 128 码 |
| 开发带载荷业务 | 30 帧结果，24 交付、6 CRC 失败 |
| 独立新保留业务 | 54 帧结果，40 交付、4 CRC 失败、10 译码资源缺字 |
| 冻结的两份标准 IQ | 整段/随机分块及两种字宽共 8 个臂，8 次交付一致 |

额定门为未截限输入且方差至少 0.04，最大 1 码。边界组仍保留
全部差异及其符号位置。新保留的浮点解映射与定点模型使用同一有界
译码/后端日历，在帧内容、失败和完成沿上逐项一致，无新增丢帧。
该结论只覆盖上述独立业务。压力测试另保留一个短间隔跨帧反例，
第二帧首字在前帧的两个尾字释放前到达而缺字。延大同一夹具的间隔
可完成两帧，未改压力失败或时间门。资源边界继续计入整机预算。

从原 IQ 中抽取的真实载波校正后线序符号、奇偶、方差和头上下文保持
冻结，分块原接收及有限链的交付和采样轨迹都有回执。已有未通过的
RRC/插值量化预算、16 KiB 模块证据和 B1 有限调度回归仍保留。
完整流式、全链定点、整机资源及连续 16 MS/s 仍待联合验收。
冻结证据根下 `psk-word-demap` 包含复现命令、源和输入 SHA、
逐拍记录、预算与失败。
