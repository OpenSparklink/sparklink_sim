# 有界同步区归一化重叠及结果合并

SYS-C2E2H2沿用已登记标准§6.2.1.2、§6.3、§6.9的实际PSK/帧/CRC上下文。
本节仅改变接收实现调度，不增加标准限值。仅显式普通FT2/3/4、4Msym/s、SPS4、
power30/error32实验配置；默认接收不变，FT1/GFSK及未知厂测编码变体不在新增声明内。

## 唯一输入与状态交接

`OverlappedNormalizationFrameReplay`复用原严格帧末尾消费、实际同步缓存及Gardner/PI。
缓存的一次**注册回复**同时送至原同步功率流水与`PipelinedNormalizationService`。
二者都具备输入信用才消费回复；任一结果不齐，主定时/NCO与主归一化状态均不接受。
最多四个联合信用，无额外整段尾部、原始样本RAM或源/缓存读端口。

归一化使用四个显式寄存上下文、一个四路DSP银行及一个双读口系数ROM。
入队后的下一边沿才注册私有40bit相位及18bit序号预测，不把入队时的加法算作免费。
实际算术继续调用H1相同微操作；每阶段每边沿最多一次，三种乘法阶段共用一个银行。
ROM请求与返回保持一边沿及明确目的槽位，DSP乘积三边沿返回；先到上下文优先仲裁。
拥塞时保留上下文和结果，输入ready为假；不能无限排队或静默丢弃请求。

一个注册输出槽仅为队首准备主状态结果。合并前分别核对源字、索引、两主状态、
真实未来样本、计数溢出及原固定采样坐标；两方均通过只读预检后才各提交一次。
接受时复制注册结果，不重新旋转、除法或更新功率/定时。
CRC只控制后续真实字段处理及交付，不参与同步、定时、载波或调度答案选择。

同步末尾须排空四信用及缓存/功率/归一化结果后转入原数据处理。
同一服务以一个显式模式位切回H1的24边沿串行微序列；不新建主状态或第二套DSP/ROM。
数据期仍串行执行原查询、插值、Gardner/PI和归一化；不在同一实验更换环路。
EOF、历史溢出及取消保留失败；清空在途槽并统计取消数，已接受主状态不回滚。
跨包重新构建上下文，不继承上一包私有预测或增益。

## 有限格式、操作及成本

全部数值格式、RNE、共同指数、异常拒绝与
[H1有限归一化](finite-normalization-words.md)相同。
每线性符号仍10个原生25×18乘积、4次ROM读；每包一次30步恢复倒数。
新增的是有限相位预测与重叠调度，没有降低算术精度或减少同步候选。

| 项目 | 候选成本与边界 |
|---|---|
| 归一化外部寄存状态上界 | 7825bit，比H1的3469bit增加4356bit；不计未经证明的生命周期覆盖 |
| 原三项帧控制计数 | 192bit不变；合计8017bit在开发前8192bit候选门内 |
| DSP | 4个专用25×18，内部流水另计536bit；与原定时、插值、TX/译码/MAC不计共享 |
| ROM | 17408bit，估计1 RAMB18、最多1 BRAM36位置，2读口 |
| 原始样本存储及源/缓存读口增量 | 0；上下文源字副本、待返回地址和结果已经计入寄存状态 |
| 接口/队列 | 4输入上下文、1注册输出；两主owner按相同字和序号合并 |
| 独立图阶段资源 | 相位、地址、符号、35bit RNE、48bit合并/规范化、41bit和/规范化、提交与预测各有宏 |
| 组合访问 | 四个寄存槽及选择网络，不能称一个双端口RAM；宽比较、移位和仲裁的LUT/时序待验证 |
| 准备后无冲突单节点 | 线性II7、每字25边沿（含新预测边沿），由真实值调度测试验证 |
| 启动和拥塞 | 倒数33边沿、信用及输出背压单独执行；II7不是任意阻塞条件下的保证 |

首次开发发现将预测边沿带入所有数据符号会令最长固定包总周期增加42995边沿；
该源码、开发结果及原全量测试均保留。新保留集尚未生成时修正为同步末尾排空后
切回原串行微序列，并增加24边沿数据服务及唯一状态交接反例。
切换首次遗漏每边沿DSP忙标志复位导致显式拒绝的失败也单独保存，不计预期资源退出。

H2替代H1的归一化节点，不重复相加两套DSP/ROM；原定时保持/数据银行仅在排空后共享。
硬件宽宏一边沿是模型假设，不能从乘法器数量推断LUT/FF或200MHz已经实现。
实际资源账本保留必要TX、译码、实时MAC、接口/DMA及调试的独立预留与未知项。
原2%RRC、插值误差、16KiB、定时4096bit及控制2048bit失败不因本节点合格而改写。

## 复现与验收范围

`scripts/model_normalization_overlap.py`比较H1串行与H2重叠，保存实际服务压缩JSONL、
输入SHA、字/轨迹、真实头/数据CRC、长度/MCS/完整载荷、BER和失败关联。
固定/随机分块要求结果、采样轨迹、主状态与实际服务值精确一致。
新的开发配方改变载荷、帧型/MCS/导频/长度、干扰、CFO/SRO和分数偏移；
冻结全部算法/参数/采用门后才首次评价新保留集，不围绕保留失败调参。
已查看集合仅作固定回归；真值/期待载荷只用于事后评价。

```sh
PYTHONPATH=.:src:scripts uv run python scripts/model_normalization_overlap.py \
  --split development --timing-root TIMING --capture-root CAPTURE \
  --selected-root SELECTED --output /tmp/overlap-development
PYTHONPATH=.:src:scripts uv run python scripts/model_normalization_overlap.py \
  --split validation --freeze /tmp/overlap-development/freeze.json \
  --output /tmp/overlap-validation
```

两条命令完整产生model/manifest后预期退出1，表示四项整体验收仍开放；任意异常退出不算复现。
父证据与冻结SHA由实际protocol/freeze记录；不能改用被覆盖的共享输入索引。
上游仍为全记录差分最大值夹具，不将本节点结果计作新的实际有界捕获率。
头、残余载波、LLR/译码仍显式停住，完整周期/延迟为未知，不能填零。
连续16MS/s夹具逐到达样本执行100/160/200MHz、512点历史及资源退出；
该输入是已匹配滤波的字端口，未把RRC及捕获生产者纳入其时钟路径。
单节点II改善不代替完整流式、全链定点、整机资源或连续吞吐四项验收。
无本节点综合/布局布线证据，不宣称实际FPGA实时能力或完整SLE验收。

## 本阶段冻结结果

首次新保留前冻结400项源码/依赖/政策指纹，之后不改算法、参数、预算或采用规则。
两个实际后端的全量检查均通过，整体覆盖率93.24%；原测试身份全部保留，新增29项反例与回归。
纯Python4369个报告身份、38项明确可选跳过；Rust4380个、5项明确跳过。
所有本地分片均低于120秒；新节点没有Rust实现或加速声明。

| 冻结后新保留6包 | 6→6 | 0/14064 |
| 原30请求中15个可交接 | 13→13 | 2353/51640，原15个未交接请求保留 |
| H1原开发/保留12包 | 12→12 | 零误码 |
| G原开发/保留12包 | 12→12 | 零误码 |
| F原开发/保留12包 | 11→11 | 原单比特CRC失败保留 |

原成功零丢失，没有新增接收恢复，正式61/96未重算，未新增真实硬件IQ结论。
新负例开发116736、保留118784采样（16MS/s下7.296/7.424ms）被上游拒绝，
观察量内零新增误交付；不能表述为全环境零误检，也不能把两后端重放当双倍独立观察量。
H1/H2的已选字、注册服务值、主状态、采样轨迹、头/数据CRC、长度/MCS及完整内容精确一致。
新开发/保留有真值时的定时最大误差约0.132398/0.174894采样；
只是独立模拟真值对照，不是实际IQ定时真值或环路失锁判据。

同一输入与采样轨迹下，FT2/3/4每包已建模运输/服务分别减少560/1100/2252边沿；
未知头、残余载波、LLR/译码工作没有计为零，不能把此差值当完整接收延迟。
连续夹具仍9/9资源退出：FT4在200MHz下已接受同步符号40→126，
FT2/200MHz首次到头处理服务点9275边沿后阻塞；其他时钟/帧型也未整包承接。
FT4/100、160MHz的初始化溢出不受后级重叠恢复。
因此仅保留为显式实验值路径，拒绝据此推广默认或宣称整链16MS/s。
