# 已选符号的有限载波旋转与增益归一化

SYS-C2E2H1-NORMALIZATION对齐已登记标准§6.2.1.2 PSK、§6.3帧结构及§6.9 CRC。
本节的ROM、倒数及流水是接收实现选择，不是新增标准限值。
仅显式实验配置支持普通FT2/3/4、4Msym/s、SPS4、power30/error32；
保留默认浮点路径、实际profile及严格头/数据CRC，不扩展FT1或未知厂测编码变体。

## 接口及状态所有权

`WordNormalizationState`从**已经选定且有效**的有限同步拟合接收相位、频率及增益。
`SymbolNormalizationService`在实际边沿执行倒数、注册ROM/DSP及结果提交；
`NormalizedWordFrameReplay(...,normalization_format=NormalizationFormat("linear"))`
将结果送入同一严格头、合法长度/MCS、载荷和MAC门。
没有用CRC、期待载荷或真值选择其他同步、载波、时序或归一化模式。

```{mermaid}
flowchart LR
  F[有效同步拟合:phase40/frequency42/gain54+10] --> D[30步恢复除法/倒数30+11]
  T[原实际定时结果:22+22+8] --> P[40bit相位/相邻ROM]
  P --> L[16bit局部系数线性插值]
  L --> C[倒数与系数融合:18+18+11]
  D --> C
  C --> R[4个22×18旋转乘积]
  R --> O[注册22+22+11输出/有序唯一提交]
  O --> H[原严格头CRC/长度/MCS]
  H --> M[原载荷/数据CRC/MAC]
```

同步区保持原功率/Gardner策略，正常数据PI及采样轨迹不变。
定时与归一化分别只有一个包状态所有者；前者提交一次后，归一化消费同一原字。
输出被取走后只复制已注册NCO/计数，不能再执行exp、除法或定时更新。
未来样本边界仍由同一源/插值状态检查；观察者和`peek()`返回主机副本。

单符号信用和单结果寄存槽，背压时保持结果及主包状态。
包头验证成功后继续沿用实际合法帧末尾消费，头CRC失败/非法字段不读取载荷长度后试解。
EOF、历史溢出和正常结束分开；取消清除唯一在途上下文，记录取消后的计数，
同时保留取消前阶段快照。包间重新初始化相位、增益、倒数和计数，不跨包沿用。
输入字非法、格式拒绝及64bit计数耗尽都显式失败；不悄悄包裹或消耗已准备上下文。

## 格式、范围和运算

| 节点 | 表示及规则 |
|---|---|
| 输入 | 同一signed22 I/Q、signed8共同指数的52bit插值字；零输入允许旧别名指数 |
| 相位/频率 | turn40无符号、signed42每符号增量；相位模2⁴⁰，避免先把频率舍到32bit |
| 增益输入 | positive54 mantissa、signed10指数，原有限同步估计，不是AGC |
| 倒数 | 左规范化54bit除数，恢复30步，55bit余数比较/减法；RNE得到positive30+signed11 |
| 系数ROM | 原1024×17 quarter-ROM，Q16；解象限得到signed18，邻点差signed9 |
| 线性局部相位 | turn40直接RNE到12bit地址+16bit小数；35bit基值加乘积后RNE |
| 融合系数 | 30×18拆成17+13两个原生乘积；signed48合并，共同规范化signed18+signed11 |
| 复数旋转 | 四个22×18原生乘积；41bit和/差，共同RNE到signed22 I/Q+signed11指数 |
| 输出 | 55bit，零规范为全零；最大131072个符号，超限拒绝 |

共同指数操作没有削顶/AGC；一次进位需要重做共同RNE，不能分别缩放I/Q。
指数11bit覆盖合法增益及输入组合；宽度不足、指数或计数溢出拒绝，不饱和冒充成功。
输出转成binary64只是后续旧浮点模块的精确二进制视图，不重算此节点。
相位模回绕计数不是周期滑移；本节点不含判决反馈环，不能据此把剩余环路失锁计为零。

每线性模式符号：2个邻点差×16bit相位乘积、4个倒数分片乘积、4个旋转乘积，
共10个25×18原语乘积；4次ROM读，用一个2R ROM分两轮执行。
另有2次邻点差、2次35bit基值加法/RNE、2次48bit分片合并、2次41bit和/差，
两次共同指数规范化/移位/RNE、40bit相位加、18bit序号加和逐项64bit统计更新。
每符号除法、开方和运行时三角函数均为0；每包仍需一次30步恢复除法，不能计成零。
最近ROM控制组为8个原生乘积、2次ROM读；误差不合格时不能作为CRC回退路径。

## 真实周期及资源边界

| 项目 | 证据/假设 |
|---|---|
| 新逻辑状态上界 | 服务3469bit+帧控制3×64bit＝3661bit；逐项见`estimate().state_parts` |
| DSP内部流水 | 另计536bit；4个专用DSP25×18，3边沿返回 |
| 系数存储 | 17408bit，估计1 RAMB18，最多占1 BRAM36位置；真实双读口 |
| 新原始源RAM/源或同步缓存读口 | 0；新操作数、结果、计数等已计在寄存状态，不是零存储 |
| 包增益启动 | 第33边沿注册倒数；与ROM准备重叠，复位边沿发起则第46边沿结果就绪 |
| 准备好后的单符号 | 最近ROM18、线性24边沿；取结果后另有1个交接边沿才能发起下一字 |
| 宽操作 | LZC、48/41bit变移/RNE、35bit定移加、55bit比较/减法及计数宏暂假设1边沿 |
| 综合/布局布线 | 尚不存在该节点的证据，不据此宣称200MHz时序或LUT/FF已经满足 |

四个DSP目前专用，不与原定时4DSP、插值6DSP、拟合1DSP、RRC或TX/译码/MAC计共享。
新增逻辑状态在开发前8192bit候选上限内；这不是批准的整机资源分配。
沿用整机账本的接口、译码、必要TX和实时MAC预留，旧16KiB、节点4096bit、
控制2048bit失败仍独立保留。旧控制2090bit再加192bit为2282bit，旧门仍失败。

本阶段先建立单信用串行的逐值基线，不以离线跑完代替连续吞吐。
原数据定时104周期+运输45周期已经超过200MHz的50周期/符号；
加入实际归一化只增加已建模工作，不会自动修复该缺口。
连续ADC夹具保持512点历史，在100/160/200MHz逐到达样本计数；
头/残余载波/LLR/译码尚未建模时明确阻塞，不赋予零周期。
后续重叠、缓存广播或银行共享必须另做有界调度及端口验证。

## 冻结验证和四项验收

开发前冻结`tests/data/normalization_word_policy.json`的数值和资源上限：
独立节点RMS≤3×10⁻⁵、峰≤5×10⁻⁵；包内相对RMS≤5×10⁻⁵、峰≤10⁻⁴；
采样轨迹变化为0、原成功零丢失、新误交付为0（附观察量）。
110位Machin/Taylor及有理倒数参考不调用接收ROM/插值；逐值服务还对照独立整数功能节点。
整段/固定/随机输入比较相同字、状态、周期服务及严格帧判定。
新开发改变载荷内容、帧型、MCS、长度、导频、干扰及CFO/SRO组合；
冻结源码/参数后才评价新保留，旧集合只作固定回归。

已保留新实现中零字别名漏计、非法输入先更新倒数及取消事件漏计的首版反例和修复。
首轮开发配方PID6对FT3/4非法，原错误及生成到的FT2开发输入保留；
修正为合法开发PID4并增加全配置生成前校验，数值/资源预算不变、尚未生成保留集。
首个新测试误把首字延迟当作24；实际增益启动与缓存工作重叠产生33，后续447字24，
保留该测试失败及更正，不改接收算术或预算。
1103字节编码BPSK固定回归超过旧诊断800万边沿护栏；独立重放仍到达终止门，
不是接收器停滞，最终45373符号、8114072边沿且严格交付。
新实验驱动使用`65536+256×合法最大帧符号数`的有限主机护栏，
旧驱动默认800万不变；这是允许验证新增真实工作，不是放宽FPGA截止时间或资源预算。
连续ADC的原容量、到达率及溢出结果独立保留，不能以延长主机运行证明实时支持。

本节点功能/数值通过不能覆盖旧word-full12-c18的2.348%＞2%、原插值误差或资源失败。
浮点严格流式路径继续存在；有限全链、多包生产者、残余载波/头/LLR/译码及FT1仍有缺口。
四项接收验收全部保持开放，完整延迟为`None`，默认接收算法未改变。
