# 已选同步区的有限字初始化

SYS-C2E2C-FIT对应TXS-10002-2025 §6.2.1.2接收实现选择。
本阶段继续[初始插值缓存](initial-interpolant-reuse.md)，补齐此前未建模的初始
相位、CFO、增益和功率拟合；不增加捕获候选、不更换同步统计或Gardner/PI。
标准没有规定这里的CORDIC、格式和预算。原文版本/SHA仍见[标准来源](standard-sources.md)。

## 接口、边界和状态

`WordInterpolatedPSKReceiver`保留默认浮点初始化，实验路径显式指定：

```python
word_format=LagrangeWordFormat(16, 2, 22)
reuse_sync_interpolants=True
sync_fit_format=SyncFitFormat(30)
```

仅接受既有52bit局部插值输出、实际32/62/126符号模板、普通FT2/3/4、4Msym/s/SPS4。
不是解除配置检查或扩大WS63、FT1/GFSK及未知厂测编码变体的支持声明。
实际模板经主机配置编译为4bit相位ROM；运行时不调用三角函数生成系数。
同一插值字广播到缓存与拟合器，不重算、不再读一遍原样本或缓存。
浮点参考新增同义初始化钩子，运算次序和原结果保持，默认接口没有改变。

初始化只处理上游已经选定的一个候选。粗CFO以turn40最近偶数量化；
32次向量CORDIC提供幅度和相位，减实际模板相位与粗CFO的递推相位。
按相邻差严格超过半圈才解缠，恰好半圈不改符号；数字坐标轴相位精确处理。
不保留整份相位数组，使用前缀和：

```text
S = Σφ[k];  T = Σ(加入当前φ之前的S)
W = (N−1)S − 2T
slope = RNE(W / (N(N²−1)/6))
phase = RNE((2S − slope(N−1)N)/(2N)) mod 2**40
```

正量幅度和功率使用共同指数累加；对齐后被擦除的非零分量单独计数。
最终幅度乘离线K/N常量消除CORDIC增益，功率乘1/N。增益下限保持原二进制64浮点
`1e-30`对应的有限常数。零向量无相位，返回`invalid_sync_fit/zero_sync_phase`，
不默认成功、不切换CFO或同步答案重试。非法字宽、中间溢出和计数耗尽显式报错。

选定端口仍复用严格解析：真实头CRC失败不读取可信长度、不交付载荷；
合法头后用真实长度/MCS决定帧末尾。尾部只消费本包所需样本，未消费后缀留给调用者。
EOF不补造未来样本，截断头/数据分别报告；终止释放历史及插值缓存。
跨块保持同包状态，终止后不能继续同候选或复用陈旧回复。
包间重新创建候选上下文；整个捕获/运输器与MAC的物理调度仍未闭合。

`fit_as_floats`是剩余浮点接收器的显式桥。同步区保持期间的功率更新、
Gardner/PI、后续载波细化、解映射、LLR与译码仍非全链定点，周期未知，不能填零。

## 格式、舍入与成本

| 节点 | 格式及规则 |
|---|---|
| 输入 | 有符号22+22、指数有符号8，共52bit；实际插值输出 |
| CORDIC | 峰值30或34，坐标有符号33或37，32步；移位按算术右移，内部增长检查 |
| 相位 | 圈单位小数40；角度累加暂存42，解缠48，粗种子含正半圈需41bit |
| 矩 | S56、T64、W及截距分子64，显式有符号增长检查 |
| 幅度/功率和 | unsigned54、signed10公共指数；RNE对齐/归一化，零规范化 |
| 原功率 | 两平方和45bit，4个25×18原语分片乘积 |
| 最终缩放 | 54×最多36bit拆9个原语乘积，90bit累加分32/32/26bit进位；RNE回54 |
| 除法 | 两次实际64步恢复除法，余数20/分母19，商按最近偶数舍入 |

`SyncFitWordFlow`逐周期搬运真实字值，有一个输入信用和一个保持输出。
每字40周期，完成N字后做有界收尾；没有预录答案或把Python整包函数计成1周期。
一个3周期25×18乘法原语同时服务功率分片及最终缩放；两者执行时间不重叠。
字处理与最终矩/除法/缩放工作区互斥，按最大工作区计费，非两份数组。
该内部复用不等于已证明可与RRC、细搜索、TX或译码共享。

| 候选 | 拟合新增DSP | 寄存状态上界含诊断/流水 | 模板/常数逻辑位 | 开发最大初始CFO差 |
|---|---:|---:|---:|---:|
| 峰30 | 1 | 3247bit | 2281bit | 0.00009884Hz |
| 峰34 | 1 | 3255bit | 2281bit | 0.00000651Hz |

预算在新数据前冻结为DSP≤1、状态≤4096bit、模板/常数≤2560bit、无新增源读口。
选择达到预算的较小格式；没有因看到保留失败而增位宽或放宽门。
2281bit包含模板512、角度ROM1280、系数/增益下限361、微码128。
模板ROM估算8LUT6+4MUXF7；完整LUT/FF、宽移位/RNE和布线尚无综合证据。

每N符号拟合的主要工作为4N+18次原语乘积、64N次坐标加减、32N次角度加减、
64N次CORDIC可变移位、32N次角度ROM读、2N次前缀矩加法、128次除法位步进。
还需输入幅度比较/优先编码、指数比较与对齐、两条54bit正量加法/RNE、
解缠比较与圈回绕、状态/计数控制及最终三段进位加法；这些逻辑未折算成免费DSP。
变量乘法均已按25×18分解，宽加法/RNE暂假定1周期，必须通过后续综合/时序验证。

组合`InitialSyncFitService`借用原512×46历史、4字暂存、七阶段插值核和128×52缓存，
不新增整段尾部。插值原6DSP、2057bit流水、原6656bit缓存及841bit控制/暂存继续另计。
拟合+原源/缓存控制+EOF共4089bit寄存估算；这不含上述2057bit核和已有历史控制，
不能直接相加成已批准整机预算。源1R1W，缓存串行写/回放；拟合只用广播字，无额外RAM读口。
ADC不停顿时满历史显式中止并记录资源丢弃，不用无限FIFO或静默跳过请求。

## 冻结验证与结果

开发前冻结`tests/data/sync_fit_policy.json`，变化PID、载荷、FT/MCS、包长、导频、
CFO/SRO、幅度变化及噪声/单音/错误同步/突发组合。开发选峰30后冻结源码和参数，
再生成独立保留；全部已查看集合只作固定回归。本次没有对保留集重调参数。

| 集合 | 原字插值+浮点初始化 | 新有限初始化 | 恢复/退化 |
|---|---:|---:|---:|
| 新开发合法包 | 6/6 | 6/6 | 0/0 |
| 新独立保留合法包 | 6/6 | 6/6 | 0/0 |
| 固定原SHA请求 | 13完整 | 13完整 | 0/0 |

固定30请求中11个没有原可评分几何、19个可回放，保留原失败而不生成答案。
正确包的头CRC、数据CRC、长度/MCS及完整载荷分别核对；新12包BER为0。
全量开发+固定+保留的峰30初始化最大相位差2.850e−9rad、CFO差9.884e−5Hz、
增益相对差6.509e−9、功率相对差2.729e−11，分别低于预先2e−7rad、0.001Hz、1e−6、1e−6。
相对原字模式的整包符号RMS最大1.458e−6、峰差2.303e−6、中心差2.329e−10采样；
这些是两实现数值差，不冒充真实定时误差。真值仅事后计量。
整段32字供给、固定7/31和随机1..32分块逐数组精确。

负例开发39936、独立保留41984采样，在16MS/s下分别2.496/2.624ms，未观察新增误交付；
不据此声明任意干扰绝对零误检。驱动上游仍是整份记录的原差分最大值夹具，
所以没有证明未知起点流式捕获率提升，原正式61/96不在本阶段改写。

原字模式RMS0.000150245＞0.0001、RRC2.34835%＞2%、原16KiB和其他失败全部保留。
本模块通过不覆盖这些失败，也不推广整个实验接收器为默认。
预算可按整机性价比另行决策，但需先冻结新预算、采用规则并用新独立数据验收，旧失败不重写。

## 组合周期结果与四项缺口

持续16MS/s已选窗口输入、原512历史、不停顿、源注册读1周期，
插值32周期/II8与上述拟合共享原结果；末尾两原字保留供首数据中点。
以下为可执行值周期结果，不是综合/实现：

| 同步N | 100MHz | 160MHz | 200MHz |
|---|---|---|---|
| 32 | 初始化就绪2373周期 | 2853 | 3173 |
| 62 | 4326 | 5256 | 5876 |
| 126 | 索引592/3700周期溢出 | 索引1014/10140周期溢出 | 11636就绪 |

就绪为从输入起点0的绝对周期，含原未来样本等待；不能用不同绝对时钟值直接比算法速度。
FT4在160MHz缓存已写完但拟合收尾尚未完成即溢出，不能将缓存就绪当作可交付。
9个长堵塞情景全部显式退出。EOF缺未来样本则立即截断，已有样本足够时允许有限排空。
拟合虽使原“未知初始化服务”部分可执行，仍缺同步保持回放功率、PI反馈、
头/载荷及译码调度、候选与实时输入仲裁，不能把这些设成0周期。

四项结论分别见`rx-acceptance-gates.json`：完整物理流式、全链定点、整机资源、
连续16MS/s均未通过。下一步最明确瓶颈是拟合收尾与同步保持回放期间的源保留、
真实头终点反馈和包内服务；100/160MHz的资源失败不等于任何结构理论不可实现。
FT1/GFSK仍为独立缺口，TX/Polar/实时MAC/DMA的整机预留不抵扣本节点成本。

## 重复命令与证据

冻结根下`sync-initial-fit/`保存输入、参数、原SHA关联、全部轨迹、失败、源码归档、
纯Python/真实Rust后端元数据和CI制品。下面命令的四项总验收退出码预期为1：

```sh
PYTHONPATH=src uv run --frozen --no-sync python scripts/model_sync_initial_fit.py \
  --split development --selected-root "$SELECTED" --capture-root "$CAPTURE" \
  --word-root "$WORD" --output /tmp/sync-fit-development
```

三个输入根分别为冻结证据的`selected-frame/python-complete`、
`capture-fine-integration/python-container-fix`、`interpolation-word/python-gate-development`；
逐项校验原manifest及原归档SHA，不使用后来覆盖的数据集索引。
随后用`--split validation --freeze /tmp/sync-fit-development/freeze.json`冻结复核。
纯Python与原生环境分开执行，有限字拟合本身没有Rust ABI或硬件时序声明。
