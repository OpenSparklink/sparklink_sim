# 插值对齐保护位次序的独立候选

本阶段SYS-C2E2B-G属于TXS-10002-2025 §6.2.1.2接收实现选择，
不是标准规定的字长/舍入算法，也没有扩大严格接收支持范围。
沿用[有限Lagrange](interpolation-word.md)与[初始插值缓存](initial-interpolant-reuse.md)。

## 接口及唯一变化

原`LagrangeWordFormat(16,2,22)`继续默认先对齐到输入精度，再补两位零。
新增显式编译候选：

```python
LagrangeWordFormat(16, 2, 22, alignment_guard_first=True)
```

该标志必须为bool且只允许此编译格式；不是任意位宽接口或自动选择器。
输入19+19+8、状态25、输出22+22+8、相位16、四点窗口、Horner和除6均不变。
候选先将输入左移两位，再按公共指数执行最近偶数舍入。
初始拟合、同步功率保持、Gardner/PI、载波、同步评分/网格/门限及严格帧处理不变。
两种方式均可显式选择已有缓存，缓存不重算或更改结果字。
原API及默认浮点路径保持；该字接收器仍只有Python时序，未接入完整MAC/运输器。
普通FT2/3/4、4Msym/s/SPS4是本阶段实验范围；FT1/GFSK、WS63新字路径与未知编码前缀未补齐。

## 范围及独立算术依据

公共指数仅由非零分量决定；零字的任意指数不能抬高量级。
非零输入对齐移位0..255，超过有效精度时按RNE处理或擦除为零，不能绕回移位量。
零字遇到较高指数显式保持零。符号、负数中点、指数上下限、打包饱和/下溢继续原规则。
相同量化相位下，直接有理数Lagrange基函数为独立参考，未饱和分量绝对误差界：

```text
旧: 5/8 * 2**common + 3/4 * 2**(common-2) + 1/2 * 2**output_exp
新: 11/8 * 2**(common-2) + 1/2 * 2**output_exp
```

这是单实分量上界，复数模界需乘√2；不包含相位量化及初始化/环路传播。
输入对齐量级不超过2**20。系数绝对系数和最大12；三层Horner依次不超过
12、13.5、7.5倍输入界，累计舍入分别至多0.5、1、1.5LSB；25位状态可承接。
相位含端点1，正17bit相位放入18bit DSP输入，另一侧25bit状态；原乘法拆分不变。
独立有理数节点与实际七阶段值流水核对，包括极值符号组合、失真指数、堵塞回复和有限在途上下文。
局部误差界改善不保证非线性初始相位/CFO拟合和整包误差单调改善。

## 冻结验收与拒绝结果

采用规则、开发/保留配方和原预算先冻结；新开发变化PID、FT/MCS、包长、导频、
载荷、干扰组合、幅度和CFO/SRO，不只更换种子。所有既有集合仅固定回归。
数值门沿用RMS≤0.0001、峰差≤0.001、中心≤0.001采样、速率≤0.1ppm；
同时要求字段判定相同、零原成功丢失和零新增误交付。没有放宽任何门。

| 测试范围 | 原字模式 | 保护位提前 | 结论 |
|---|---:|---:|---|
| 新开发完整载荷 | 6/6 | 6/6 | 无接收增益 |
| 原SHA固定请求完整数 | 13 | 13 | 零原成功丢失；不是独立包接收率 |
| 新开发长MCS0包RMS | 0.000271853 | 0.000100124 | 改善但仍超0.0001 |
| 原固定数值反例RMS | 0.000150245 | 0.000284283 | 恶化，拒绝采用 |

固定30请求中11个原本没有可评分几何，19个可回放，15头CRC、13数据CRC/完整载荷。
新开发6包头CRC、数据CRC、合法长度/MCS及完整载荷均正确，BER为0；
完整和数值结果分别记账，不用CRC通过覆盖数值失败。
负例共35072采样，即16MS/s下2.192ms，观察到零新增误交付；不支持绝对零误检声明。
整段/固定/随机字块精确，逐字段及消费位置检查；上游整份记录8网格一次最大值仅是夹具，
不作为未知起点流式捕获率改善证据。旧正式61/96结果未在本阶段重算或宣称改善。

采用规则已拒绝，**不生成新的RF保留集**，不在同一集合挑其他保护位或改门限。
另用冻结的新种子执行256条独立算术节点保留及27个源/缓存周期情景；
这种节点验证不替代接收机保留集。候选保留为显式实验，不自动推广默认。
原RRC2.34835%＞2%、原16KiB和本轮两条数值失败均保留。

## 成本、端口与周期边界

| 项目 | 原字模式 | 保护位提前候选 |
|---|---:|---:|
| 对齐移位/RNE | 8×19bit | 8×21bit |
| 仅数据选择的五层二选一mux上界估算 | 760 | 840 |
| 每查询原语实乘/加减 | 6 / 30 | 6 / 30 |
| DSP估算 | 6 | 6 |
| 流水寄存器上界 | 2057bit | 2057bit |
| 除6逻辑ROM/读口 | 1344bit / 2 | 同原 |
| 核延迟/II假设 | 32 / 8周期 | 32 / 8周期 |

80个二选一mux增量只涵盖数据选择，不是总LUT。指数差、饱和、符号、sticky/reduction、
RNE加法、控制及布线仍须综合；不把更宽组合路径当免费资源或已证明同频。
三周期对齐阶段中的RNE仍假定1周期，21bit宏并无综合/时序证据。
输入/输出/状态寄存器宽度没有变化，因为保护位原已存在；标志是编译选择，不增加包内动态配置。

源/缓存复用原1R1W历史和既有6DSP，不新增源读口或DSP；
额外6656bit缓存、841bit控制/暂存仍按上一阶段另计，未免费共享TX/Polar/MAC或细搜索。
100/160/200MHz下27个日历仍保存7种资源退出；正常FT4缓存齐全需原未来等待后1036周期。
初始化拟合、同步功率保持、PI、头及译码服务尚未纳入，不能填零周期。
旧100MHz反馈超期、160MHz零余量、200MHz仅10周期插值余量不被本候选解决。
[整机账本](system-feasibility.md)与四项验收均继续未闭合，不能称整链持续16MS/s或硬件验收。

## 复现及下一步

```console
PYTHONPATH=src uv run --frozen --no-sync python scripts/model_alignment_guard.py --split development --selected-root SELECTED --capture-root CAPTURE --word-root OLD_WORD --output NEW_DEV
PYTHONPATH=src uv run --frozen --no-sync python scripts/model_alignment_guard.py --split validation --freeze NEW_DEV/freeze.json --output NEW_NODE
```

首次驱动误读未发生的头决定及新测试误用不存在属性的日志/源码单独保留，没有改变接收器或期待答案。
