# 有限银行 scaled10 粗捕获核（M18，实验）

本模块把既有 scaled10 统计图推进到逐沿结构；不改变同步门限、归一化排序、相位网格、
峰值等待或 Gardner/PI。对应普通 PSK §6.2.1.2 和帧结构 §6.3，当前仅编译
4 Msym/s、SPS4、FT2/3/4 的 31/61/125 个差分项。不是新的标准要求或默认接收后端。
FT1/GFSK、未知厂测编码变体和其他采样配置不由本模型推断支持。

## 所有权和数据通路

输入为已表示的复数有符号 10+10 bit、指数 7 bit（−48…32），上游 ADC 标度、
RRC 周期和原始能量标志的真实到达仍需后续集成。功能对照使用现有严格 IQ→MAC 路径；
其中 RRC 之后的单音抑制、细搜索和包内处理仍含浮点，不能标为全链定点通过。

```{mermaid}
flowchart LR
  I[连续字输入 FIFO16] --> D[注册差分与功率]
  D --> P[有界差分 FIFO64]
  P --> H[已验证串行指数最大值]
  H --> F[银行历史与固定批量折叠]
  F --> C[两累加上下文与有限 C/E 交接]
  C --> N[原生分片平方与阈值]
  N --> Q[注册 Q12 恢复除法]
  Q --> R[合并 hit/rank 环]
  R --> S[有限查询 FIFO2 与输出槽1]
```

保留 M17 的 4 相、161 个指数桶、7 沿延迟、II8 和 645 沿初始化，不免费清除 RAM。
差分字为 21+21+43+8 bit。相位历史深度填充到 32/64/128，每次每银行最多读一个字；
物理映射包含填充。仅旋转 5 bit 系数/有效标志，累加器按物理银行归属，避免免费旋转整条
93 bit 数据。最旧项产生后四采样所需的指数反馈；四项缓存标签不符时等待，不猜测或丢弃。

每项先算算术右移的 floor 和 RNE 修正，分别累加后归并；零能量、指数大差、负数半值、
符号和累加器完整增长均显式检查。平方按 signed25×18 原语分片，阈值常量用注册移位加法树。
Q12 用固定 12 级恢复式比较/减法，门限与排序分别保留原语义；不按相关幅度代替归一化排序。
没有 CRC、期待载荷或真值参与同步答案选择。

## 连续状态和过载

评分单元的两个物理槽会被复用，槽编号不能代表样本年龄。M19增加按最早存活标签交付的
有限仲裁；未完成的较早上下文也不能被较晚结果越过。合成的8/14/31沿单信用等待中，
旧结构在14/31沿时将标签1延至标签11之后，新结构保持0…11顺序。该反例只涉及模块
下游信用合同，不是默认流水线的已知射频漏包；默认13沿Q12流水线仍作原基线。
新增仲裁保守计入一个63bit标签比较、两个有效位判断及全结果数据的2选1选择，
不先计入与乘法派发的共享收益。没有新增状态、DSP或采样RAM，但组合路径和Fmax尚待综合。
串行归一化仍是独立未采用实验，不能以本项顺序修复宣称其资源或吞吐已经通过。

输入 `offer()` 返回 False 代表未消费；不可暂停的 ADC 调度器须以该原标签调用
`input_overrun()`，明确终止本代次，禁止压缩标签后继续。已接受未退休字单独统计。
差分队列总信用 64，含注册前端的实际存储、地址、有效位和读写控制全部计费；
同址读写冲突通过等待解决，不依赖器件未定义的读写碰撞行为。

查询只接受最多 131 个位置、原有最多 256 字年龄范围，快照锁存在入场时。
按原相位顺序遍历，严格大于才替换，保持同分先后关系。
事件队列满会明确拒绝并计数；下游阻塞导致历史过期时返回 `history-expired`。
不能将这些资源损失写成评分算法漏检。EOF 必须实际消费候选并排空；
输入完成与候选交付完成分别记账，不能以输入字无丢失覆盖候选丢弃。

## 初步成本与整机限制

下表是类型化逻辑容量、原语容量和逐沿模型的估算，不是综合 LUT/FF 或时序结果。
每个独立粗路径固定专用 12 DSP（差分/功率 8，平方评分 4）；没有与另一支路、RRC、
细搜索或译码共享的收益。表中已包含指数最大值、差分生产者和全部本核队列，不能重复相加。

| 帧型/银行 | 单路径逻辑 bit 上界 | 寄存器 bit 上界 | LUTRAM LUT 估算 | BRAM36站点预留 |
|---|---:|---:|---:|---:|
| FT2/8 | 56794 | 26370 | 720 | 2 |
| FT2/16 | 62810 | 32386 | 1232 | 2 |
| FT3/8 | 71625 | 26853 | 720 | 2 |
| FT3/16 | 77781 | 33009 | 1232 | 2 |
| FT4/8 | 99080 | 26016 | 1200 | 2 |
| FT4/16 | 105376 | 32312 | 1232 | 2 |

历史按 7 系列 RAM32M/RAM64M 的真实 SDP 宽深和端口计费，差分待处理队列使用 RAM64M。
两个独立 RAMB18 保守各预留一个完整 BRAM36 站点，不假定可免费合并半块。
FPGA SLICEM 可放置性、组合 LUT、布线和 Fmax 尚无综合证据。

单路径旧 18 DSP/16 KiB 研究边界不等于双路径或整机预算。若选择 FT2/3 的 8 银行和
FT4 的 16 银行，原始/单音两支路需 24 DSP、4 BRAM36 站点，以及
52740/53706/64624 bit 寄存器上界。FT4 已超出既有基础工程后、候选 25% 余量建议下
58089 FF 的新增候选额度，尚未含其他新功能。25% 未获批准，不是已冻结的系统约束；
也不能因单节点逻辑容量通过就宣称整机通过。完整归属与待验证项目见
[整机账本](system-feasibility.md)。

## 开发证据与验收状态

最初开发对照 15 个新 IQ 流、45 次整段/固定块/随机块比较，与旧字路径判定和轨迹精确。
9 个正常包完整 8 个，错误同步背景的弱包漏检保留；增益 0、原成功丢失 0。
坏头、坏数据 CRC、截断均拒绝；四类负例共 49152 采样，16 MS/s 下 3.072 ms，
零新增 MAC 误交付只适用于该有限观察，不能外推为全环境绝对零误检。

200 MHz 台架中 FT2/3 的 8/16 银行、FT4 的 16 银行可退休全部 2560 输入字；
FT4 的 8 银行在 160/200 MHz 溢出。100 MHz 从复位起先因启动积压失败，
另付 645 沿初始化后仍持续服务不足。这些失败分别保留，不靠无限 FIFO 消除。
每沿宽加法/比较、DSP3沿、注册 RAM 读等假设仅为周期模型，不是布局布线结论。

最终源码和每32输入字一次查询的工作负载已在新保留集生成前冻结。
新保留15流/45次分块比较仍为正常包完整8/9，捕获11、头CRC10、数据CRC8（另含三种控制反例）；
旧/新路径全部判定、载荷和轨迹精确，增益0、成功丢失0。负例57344采样，3.584ms，零新增MAC交付。
Python/Rust环境全量5313/5324项、覆盖率均93.77%；新核在两环境中仍是Python实现，
不能称为Rust新核。旧12流的37JSON/324NPY按原SHA回归；正式61/96压力集未重算。
200MHz首选布局的末512字最坏延迟为56/60/61沿，启动包含在内的最大值688/692/693沿；
131位置查询最大137沿。这些是本粗核的周期，不含上游RRC和后续细搜索/解调。
完整阶段的源码归档重放、原子提交及实际CI仍需分别核验。
原 word-full12-c18 的 2.348%＞2%、插值误差、旧存储预算与整链调度失败继续保留。
整包相同不覆盖原数值失败。RRC、细搜索、载波、头/载荷/译码的未集成周期为未知，不能填零。
四项接收验收均不能据本核通过而置为成功。

## 复现

```sh
PYTHONPATH=.:src:scripts uv run --frozen --no-sync python -m scripts.model_banked_scaled \
  --split development --output /tmp/banked-scaled-development
```

输出目录须不存在。完整运行预期退出 1，必须同时检查 `model.json` 中
`component_word_and_frame_exact=true` 和 `whole_RX_gates_passed=false`，不能仅检查退出码。
独立 validation 要求 `--freeze` 指向开发的 `freeze.json`，算法、参数、预算、采用规则和
源码须完全一致后才会生成输入。已查看输入继续仅作开发或固定回归。
