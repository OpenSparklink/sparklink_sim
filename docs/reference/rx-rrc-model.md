# 接收匹配RRC的四层模块模型

本阶段是RX-C2A的单模块闭环，尚未接入`PSKStreamReceiver`，没有整包率改善结论。
保持原有PSK浮点接收路径，后续须在固定真实IQ及新包开发/保留集验证集成。
**该原型不推广到接收主链**：全记录误差满足预定义预算，但强弱切换暴露局部RMS误差34.5%（后续独立复核46.3%）；
局部误差此前未设验收限值，保留这个边界并在下一结构阶段先冻结相应预算，不能写成弱信号验收通过。
引用现有实现的PSK成型/接收处理（§6.2.1.2），不新增或虚构标准频谱限值。

## 四层职责

| 层 | 实现 | 验证及限制 |
|---|---|---|
| 浮点参考 | 独立解析脉冲取样、单位能量归一化、SciPy因果卷积 | beta0.4、SPS4、单侧span10，共81系数；为当前工程参考 |
| 浮点结构 | `SymmetricRRC`，40对对称抽头及一个中心抽头 | 因果80样本历史；乘法162→82/复输入，加法仍160；非NumPy舍入顺序约束 |
| 有限字 | `FixedRRC`及显式整数输入端口 | 输入共享指数、最近偶数舍入、对称整数FIR、输出规范化及范围计数 |
| 周期/数据流 | `RRCFlow` | 检查读操作版本、队列/背压、启动延迟及加法树依赖；未综合/布局布线，也非完整RX |

## 状态和量化规则

现阶段选定12位有符号I/Q尾数、公共7位指数（允许-48..32）；
系数14位有符号Q13，预加13位、实乘积27位、保守全增长累加器33位。
输出19位I/Q尾数、公共8位指数（允许-96..48）。所有有符号端口按二补码值解释。
浮点输入适配器使用既有银行的共享量化函数，不假设真实ADC满量程或模拟增益，不能提高SIR。

每个新位置只查看81个过去/当前输入；零字不参与最大指数选择。
各输入分量先RNE对齐到最大指数，再做对称预加、系数乘法和无中间饱和的全增长累加。
输出共同幅度的最高位决定规范化移位，再RNE、指数范围检查及最终饱和。
零输出返回零尾数/零指数。输入范围、被对齐抹去的非零分量、输出范围及中间溢出分别计数；
不能因最终载荷或CRC相同而抹去数值事件。计数器为显式64位饱和，采样索引耗尽时报错。

`feed`支持任意分块，内部每批≤32且每行只用自己的过去/当前数据；不暗示32路硬件。
连续输入跨包保留滤波历史，包间不自动复位；新流创建实例。
`finish`对非空流明确冲洗80个零样本后关闭；这些虚拟尾样本与真实输入区分。
整接收机集成时必须统一EOF冲洗，不能与原接收器重复补零。
整数`feed_words`端口每次1–32字，拒绝浮点或超字宽数据，不隐式舍入非法整数接口。

## 操作、存储、端口及周期边界

有限字图每个复输入有80次实预加、82次实系数乘法、80次实累加，
另有80次指数最大值比较、162次分量对齐/guard-sticky及条件RNE进位加法，
2次输出RNE及输出前导零检测；历史地址/系数地址分别243/82次。
指数处理并未因乘法少了而免费。硬件输入端口已经是有限字，实际ADC到该格式的转换仍须单独设计。

周期假设为200MHz、16MS/s、7路乘法、7路增益扫描，反馈加法/比较II=1；
7路系数读取、14路历史数据读取、21路标签读取，128字物理历史，三处FIFO各4描述符。
增益扫描II12/延迟15、FIR发射II12/延迟15（含对齐RNE级），
四加法器执行两棵归并树4周期、输出规范化2周期。
增益和FIR各两个上下文保留启动/尾部流水状态，孤立端到端延迟36周期。
完整规则、读地址版本和EOF排空由可执行模型验证，延迟输入或下游阻塞不靠缓存整份记录解决。

当前12/14结构估算7乘法器、算术峰值46个加法/比较等单元，另计5个历史期限守卫操作、
2个全局计数更新，共53个宽运算单元；窄控制计数器另列。
寄存器抽头逻辑状态17206bit（约2.10KiB），含ROM端口复制、历史、队列、流水及监测寄存器。
输出FIFO每项必须保存470bit的部分和/公共指数，额外计入4项数据存储；
最多2个生产写端口、1个消费读端口及对应宽选择网络均单列，不能只有描述符而免费保留结果。
全量硬件监测的额外12个更新单元尚未排程，直接并列时总65个单元超过54预算；
当前II结论仅针对数据/控制通路，软件观测计数不冒充已完成的硬件监测实现。
对应读取选择网络有64512个比特输入，选择器/扇出/布线并未经过综合或时序验证。
若改用每副本专用1读/1写RAM的直接复制结构，逻辑容量77622bit（约9.48KiB），待归并FIFO仍采用寄存器端口结构；
这不是所有RAM实现的下界，也未计具体BRAM粒度，时间复用/读复用方案尚未设计。

在上述多端口假设下，模块II12满足每采样12.5周期的必要条件；
160MHz、二周期反馈或单系数端口的配置不能持续承接同样输入。
下游阻塞时采取有界队列、请求满丢新；物理输入仍写历史，过期操作数显式产生`history_gap`。
缺失/无效输出保留源采样索引，必须由下游处理流中断，不能删除索引后拼接成连续IQ。
周期模型只检查操作时序、依赖和数据寿命，整数数值由有限字参考定义，不是RTL逐周期仿真。

原捕获16KiB/18路乘法/54宽操作预算继续有效。整链组合时要替换原RRC占位、
加上同步/双银行/细搜索/环路/译码及共享调度，不能从单模块结果宣布整链接收或实时FPGA达标。
4096连续输入的默认情景零丢弃、零历史错误；160MHz丢新679、两周期反馈丢新1959，
单系数端口丢新3461且608个历史无效输出；4000周期下游阻塞丢新306且10个历史无效输出。
这些是真实执行的模块周期边界，全部源采样索引保留，未等同于真实信号漏包或整链实时验收。

成本复核先保存原RNE进位/流水及FIFO部分和遗漏的源码、报告，再修正计账。
滤波字算法AST除操作计数报告外保持不变；在新开发455117/保留465117复核相同12/14/19格式，
最大全记录RMS误差0.000691205、峰值相对误差0.001157130、局部64样本误差46.2839%，范围事件0。
后一个边界位于`blocks-3`的320–383采样，参考RMS0.000121878、误差RMS0.000056410；
输入SHA256为`d85aa50c6ae82774ffcb75c7130f1a565592e671a1103c577705be154471303e`。
新增FIFO成本只修改`RRCFlow.resource_estimate`，以明确的SHA/AST来源链复核；
其他算法/调度函数和所有来源仍须逐个SHA一致，不能借成本修订绕过参数冻结。
32条节点/统计与成本修订前、实际两环境的同一Python/NumPy有限字模型逐值一致；无RRC Rust加速实现。
新成本修订后周期轨迹也逐值一致。新旧局部损失都保留，不因此向主链推广。

## 完整12位输入候选：冻结后保留失败（RX-C2A3）

开发前冻结种子490117、新保留500117和原2%局部/0.002全记录/0.02峰值预算。
`FullMantissaRRC`只改变浮点到12位有符号字的转换，有限整数端口和成对乘积结构保持相同。
`rrc_input.quantize_full_rrc_words`逐采样选择公共指数，不预留一个尾数headroom位，
采用RNE；若任一分量舍入后超出-2048..2047且指数<32，指数加一，
两个分量**从原输入**重新舍入，而非把已舍入的字右移造成double rounding。
负数-2048合法，不因绝对值等于2048而误报溢出；指数[-48,32]的下溢、上溢和最终饱和全部计数。
零字返回指数0，不参与后续最大值。仍是因果的每采样规则，无包启动估计或未来样本需求。

这描述数字表示，不假设ADC有额外精度或已校准增益，也不能改善SIR。
真实有限ADC字到该表示的转换、原输入在重舍入期间的寄存、端口和流水尚待结构设计。
新`_quantize`钩子的默认实现沿用原函数；32条冻结旧输入的默认输出/统计逐值一致。
13位预加、31位乘积和37位累加范围原本已覆盖完整12位输入，无需增加这些字宽。
输出仍19位。新增64位有界重规范化计数，功能状态4206bit；
转换上界额外记录两轮共4个分量RNE、8个分量范围比较、公共峰值比较及指数修正，
不把软件二次计算或4206bit功能状态当成已完成物理实现。
