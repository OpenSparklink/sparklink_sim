# 已选同步窗的有限字相干确认（M33，实验）

本阶段将实际细搜缓存到相干确认的浮点空缺替换成一个可执行有限字节点，
再接回既有真实头 CRC、合法长度/MCS、帧尾和数据 CRC/MAC 路径。
它不改变同步搜索范围、候选数量、峰值等待、载波细化或 Gardner/PI 参数，
不依据 CRC、期待载荷或真值重试答案。默认接收器保持原样。
空口依据为 §6.2.3、§6.3、§6.9；原标准版本与 SHA 见[标准来源](standard-sources.md)。
本页的字格式、误差和资源上限均为实现研究预算，不是标准合格限值。

## 接口与处理顺序

`CoherentWordService` 只接受实际 `FineSelection` 和本 profile 编译的同步相位码。
借用原 128×44 bit 选择缓存，不复制 IQ、不读取后续载荷：

1. 对既有 signed53 差分相关归一化，运行已有 32 次 CORDIC，生成 turn40 角度。
2. 将角度 RNE 到 modulo20 NCO 步进；把实际同步模板的 4 bit 相位折入同一 NCO。
3. 单端口读取 signed22 I/Q，使用已有四沿系数 ROM，累计复相关与输入能量。
4. 比较 `20*|C|² >= 9*N*E*2**32`。零能量或上游差分相关为零时拒绝。
5. 实际回执就绪后，才开放原帧消费者和原始历史读取；选择坐标不变。

`WordConfirmedCapturedFrameReplay(..., coherent_threshold=0.45, clocked=True)`
是显式实验入口。`clocked=False` 仍执行相同有限字算术，但在功能调用中完成，
只用于分离量化和正延迟影响，不能计作零周期硬件。
原 `CapturedFrameReplay` 仅抽取初始化辅助方法，冻结输入上的默认输出及搬运统计精确保持。

每包独立初始化；结果反压时保持回执和借用窗，不把等待沿算入计算工作。
源 epoch 故障在下一个注册沿取消实际在途运算并释放所有权，不继续消费旧回执。
EOF 必须先排空此节点，随后由严格帧解析区分合法帧尾与截断。
原历史 4096、三个拥有窗、源端口上限 2 不变；没有新增整包尾部副本。

## 数值格式与独立参考

| 节点 | 表示与规则 |
|---|---|
| 选中 IQ / 共同指数 | signed22×2；原指数借用，归一化统计中抵消 |
| CFO 初始化 | signed53→peak30 RNE，33 bit CORDIC 坐标、42 bit 内部角度、turn40 输出 |
| NCO / 模板 | modulo20 步进，12 bit RNE 地址；signed18/Q16 系数 |
| 累计复相关 / 能量 | signed48×2 / unsigned52，完整增长，不饱和掩盖溢出 |
| 分子 / 分母 / 比较 | unsigned97 / unsigned91 / 110 bit；常数乘以移位加法执行 |
| 宽平方 | 每个 48×48 平方分为六个 unsigned24×17 原生乘积；两路共 12 个 |
| 接受判定 | 整数平方量比较，无除法、开方或运行时三角函数；Q 的除法仅用于报告 |

独立 Python/Fraction/三角函数参考验证 ROM 定义、宽整数和临界值，
不共享被测节点的 NCO 取系数函数。预先冻结 Q 绝对误差 0.005、角度环形误差
1e-6 rad、20 bit 步进误差 3.1e-6 rad；原成功功能结果和对应轨迹要求精确保持。
恰好 9/20、两侧邻点、零输入、轴向、分支切口、signed22/53 极值、指数抵消、
在途取消和超过计算上限的已完成输出等待均有独立反例。

这些局部门不能覆盖原 RRC 2.34835%>2%、插值 0.000150245>0.0001 或旧 16 KiB
失败；尚未建立完整载波、LLR、载荷译码的有限字接收机。

## 结构、端口和周期成本

| 项目 | 估算或可执行假设 |
|---|---|
| 原生算术 | 专用 1 DSP25×18、1 ALU32、单在途上下文，不抵扣其它模块 |
| 每请求乘法 | `8*N+12` 个原生 24×17 tile：四复旋转实乘、四能量 tile/符号及最终宽平方 |
| 节点寄存状态上界 | 4967 bit，含 fabric 1736 bit、NCO 的 94 bit 地址/ROM 流水和全部统计 |
| 节点及新增交接控制 | 5161 bit，研究上限 8192 bit；连同原帧所有者共 6648 bit |
| 系数存储 | 17408 bit，1 RAMB18、保守预留 1 BRAM36 站，两个 ROM 读端口 |
| 模板 / CORDIC 常数 | 512 / 1280 bit；分别 8 / 40 LUT6 ROM 上界，模板另有 4 MUXF7 |
| 缓存与端口 | 借用一个原选择缓存读口；无新增 IQ RAM 或源采样端口 |
| 额外组合设施 | 两个 53 bit RNE 移位器、LZC/绝对值/比较；两个 33 bit CORDIC 移位加法和 42 bit 角加法 |
| 硬上限 | 每请求运行最多 32768 沿；已完成回执的有界所有权等待另记 |
| 时钟假设 | 一次 CORDIC 迭代/沿，LZC/RNE 一阶段、ROM 四沿；没有综合或 Fmax 证据 |

微程序逐沿执行实际有限值，记录 ALU carry 步数、乘法发出次数、读口和等待；
宽乘法不是一个 DSP，回执主机一致性检查也不是第二套免费硬件。
旧原型漏记 94 bit、常数 ROM，以及等待混入计算沿的失败均留证，未修改预算。

在 100/160/200 MHz 下，编译工作上限分别为 327.68/204.8/163.84 µs。
这不是最坏合法包到 MAC 延迟；原头服务虽计了正延迟，bootstrap、包内载波、
解映射和载荷译码仍有 off-clock 工作，完整周期数为未知。
串行确认会推迟历史读取，也会改变后续细搜与槽位竞争，必须在实际输入日历中评价。

该节点须与 RRC、粗细核、头及上一包译码、TX 准备、实时 MAC 和 DMA 并发记账，
见[整机资源](system-feasibility.md)。没有证明可与 TX/其它 CORDIC 共享；不因 TDD 抵扣。
数据通路 LUT/FF 映射、布线、端口复制和时序仍需综合，ROM LUT 数不是全节点 LUT 数。

实际请求为 2443–9816 个计算沿，200 MHz 下约 12.215–49.08 µs，
不能以这段局部延迟替代完整包延迟。FT2/3/4 的实乘请求数分别为 268/508/1020。

## 验证与采用规则

三臂均使用同一有限 RRC/粗细缓存：原浮点确认、有限字功能隔离、实际正沿有限字确认。
它们不是全浮点接收机与全定点接收机。各臂分别比较整段、固定块和随机块，
同步确认、头 CRC、长度、MCS、数据 CRC 和完整载荷分别记录；不同判定人口的 BER 不直接比较。

新的开发/保留各 12 个合法未编码包，变化载荷族、FT2/3/4、MCS8/12、导频、包长、
幅度、CFO/SRO、分数偏移、起点和干扰组合，不只更换随机种子。
每集合另有纯噪声、单音、错误同步字、突发负例各 8192 采样。
开发通过局部数值门后才创建独立保留集；真实调度损失单列，不能据此放宽误差或缓存。
有限字数值通过不允许升级默认，正延迟集成还要求原成功零丢失、资源退出不增加。

开发/保留分别观察 86981/93002 个输入采样。各含 32768 个独立负例采样
（16 MS/s 下每集 2.048 ms），三臂均无负例确认/误交付；不宣称全环境零误检。
正延迟路径丢失开发 2、保留 3 个原成功包，不能因 BER 分母变小而宣布收益。
两集功能量化均无恢复/退化；21 个相同缓存配对的 Q 最大差分别为
2.28602e-5/3.22561e-5，满足原局部门。数据 CRC 失败和无完整载荷继续保留。
头 CRC、合法长度、合法 MCS 的逐事件统计在报告中分别输出。

真值起点最大误差开发为 0.2738 采样、保留为 0.08 采样；最大轨迹 RMS 分别为
0.154346/0.053874 采样。这是实际捕获的观测量，与网格间隔及新旧实现差值预算不同，
不把相同轨迹或小定点差值冒充真实定时精度。正延迟失去部分轨迹后不直接比较总体 RMS。
节点角度误差相对同一差分相关的浮点角度，不是真实 CFO 误差；真实已注入 CFO 的初值误差
另列报告，载波环收敛/滑移没有在本阶段独立验收。

结论：局部有限字实现可供继续研究，当前单 DSP 串行结构**未通过采用/调度规则**，
默认不变。开发与保留命令均实际返回 1，原因是正延迟资源/原成功损失，不隐藏为全通过。
下一步是用新的开发组合比较有限并行服务与窗口期限，保持本阶段相同有限字结果；
已经查看的两集只作固定回归，不围绕保留集修改参数。

真实 Python/Rust 依赖环境重放同一 SHA 的 20 流，265 个 NPY 成员逐字节相同；
80 份 JSON 中 53 处严格差异均为实际 `integer_screen_backend` 标签，其余值精确。
有限字微程序在两环境中均为 Python 模型，不冒充 Rust 实现或 FPGA 性能。
本地全量身份 5771/5782，原测试全部保留，新增 57 项；38/5 项依赖跳过明确记录。
两环境覆盖率均 93.9%，最大分片 95.125/92.708 秒，小于原 120 秒门限。

实际结果、全部剩余失败和一条复现命令随冻结证据保存于
`finite-coherent-capture/`。压力集正式 61/96 本阶段未重测；未知厂测编码前缀保持未知，
FT1/GFSK 完整未知起点流式路径仍缺失。四项整机验收分别开放，未宣称完整 16 MS/s 或 FPGA 验收。

SHA，运行针对性测试并重放两集原 IQ；不会创建或重新挑选保留样本。
