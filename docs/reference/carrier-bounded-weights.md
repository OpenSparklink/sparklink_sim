# 载波细化的因果有界权重（RX-CARRIER1A）

这是显式实验接口；默认权重仍为符号幅度平方。
本阶段只改变M次方统计的权重，保留原去交替旋转、FFT长度/频带/网格、三步有界Newton、
圆周相位处理、解映射和译码，不以CRC重试结果。
Gardner/PI、同步评分、候选、门限、RRC和单音回退不改变。

## 接口和因果规则

```python
rx = MacStreamReceiver(profile, quiet,
                       carrier_weight_kappa=2,
                       carrier_weight_fixed=False)
```

`refine_psk_carrier`、严格帧解析和流式MAC路径透传相同选项；
κ仅允许开发前定义的2/4/8，定点模式必须显式给κ，旧相位回归不能混入本实验。
原调用无需新增参数。头CRC/长度/MCS校验与交付规则不变，短头/短包也不能接受非法实验配置。

设同步复增益归一化后的符号功率为p，启动P=1；每包新建状态，包内跨任意调用分块保留：

```
w[k] = min(p[k], κ P[k-1])
P[k] = clamp(P[k-1] + (min(p[k], 2P[k-1]) - P[k-1])/64, 2^-16, 2^16)
```

当持续大功率输入时，估计每符号最多乘65/64；零输入时乘63/64直到下限。
不是将突发直接灌入普通EMA，也不假设同步增益归一化能改善信干比。
启动功率基于单位星座/同步增益，若同步本身受干扰，该假设也有边界，不能用期待数据修正。
没有等待未来功率或按CRC选择κ。`BoundedCarrierWeights`每次只接1..32个功率字，
完整权重输出及实验轨迹由调用者持有，不冒充内部硬件状态。

## 独立定点节点和成本

有限字入口是无符号41位Q16功率（范围约0..33554432），不是已完成的ADC/符号归一化通路。
状态功率33位Q16，权重36位Q16，更新差分有符号34位；最近偶数舍入，更新后显式上下限。
输入功率超范围饱和、正功率舍为零、权重/更新限幅、状态上下限和监测计数饱和分别记录。
整数入口拒绝浮点/负数/超字宽，不隐式改答案。

独立Fraction最近偶数参考验证正/负更新及边界；定点与浮点不是逐位相同要求。
Q16零输入反馈会停在32个LSB，而浮点到1个LSB下限，保留该量化死区；
局部节点数值通过不能扩展为任意低功率/强弱切换均无损。
原RRC2.348%>2%、旧local4起点误差和所有既有输入范围事件不因本节点改变。

`CarrierWeightFlow`分配一个42位比较/加减ALU、一个64位饱和计数ALU及guard/sticky/选择逻辑。
κ和2倍更新上限用移位，1/64用算术移位/RNE；相对既有功率计算不新增乘法、除法或开方。
**归一化/功率输入转换、原FFT/Newton/圆周相位仍有原成本，不在此免费消失。**

八相位分别做权重比较、更新比较、差分、移位/RNE、状态加法、下/上限及提交。
七个监测计数分配到不同相位，持续工作不跳静默。
两端FIFO各4项、一个活动字，功率/临时值、标签、7×64计数、配置和指针共1581bit。
FIFO各1读/1写，状态功率1读/1写，计数银行1更新/周期；逻辑/扇出/布线尚无综合计数。

在单周期ALU/进位饱和/选择的假设下，孤立II=8、延迟8周期。
1024个4Msymbol/s连续字在100/200MHz均无丢弃；对应孤立延迟80/40ns。
200MHz下消费阻塞0..3000周期丢52字；一字/周期RAM突发输入丢892/1024字。
这些情景中队列有界、丢弃带源标签，任一丢字使整个包无效；不继续把跳过功率状态的帧算正确。
这只是权重节点日历，尚未把丢弃反馈到实际接收器；整包RAM批处理可反压的调度也未证明。
不能用4Msymbol/s节点条件替代16MS/s整链或响应期限验收。

## 冻结实验和当前证据

实现前冻结`carrier-bounded/predevelopment.json`，SHA
`7065fc14cc4a63ff6af35752e9d911cbb079ab72c739c0c4199a23eb7783a4a0`。
先保存种子530117的旧算法源码/支持脚本及88流/64包基线：51捕获、37完整正确。
新开发集有867825输入采样；48负例共462647采样（约28.92ms），零新增候选/误交付只对这些观测成立。
原始IQ不改，发送使用独立角度/脉冲及重采样，仍共享比特编码器，不作为唯一标准互通证据。

κ2/4/8均51捕获/37完整正确，原成功零丢失，头部/同步/采样轨迹与旧算法逐值一致。
κ2仅将单音未编码信息位错误1033→1031，未恢复整包；κ4/8无此信息位收益。
可计算的突发数据包含未编码7/1216线比特错误、编码72/5568线比特错误，
均位于已知突发经RRC/插值扩散的受损区；突发后64符号区域均0错，三权重未减少这些错误。
未捕获/坏头/截断不补入BER分母，编码线比特与译码后信息比特分别记录。
这不支持把当前样本的局部损伤说成整包载波全部被拉偏，也没有突发整包增益结论。

独立“强M次方相干异常”单元反例验证有界权重能限制整体拟合偏移，但不冒充真实包通过率。
最初该合成异常漏加规定交替旋转、未产生预期带内峰，修正试验构造并保留失败日志，
没有放宽断言或修改冻结包输入。

κ2浮点/定点开发节点最大权重归一化差0.000105876，残余频率差9.28005e-10周/符号，
相位差2.55283e-6rad；满足预先冻结0.002/1e-5/0.005预算，输入范围事件0。
完整正确数仍37，无量化整包损失；不能据此宣称全接收机定点通过。
已按开发结果冻结κ2，仅作新保留探索性复核，不推广默认配置。
新保留540117、旧原哈希回归、真实MAC、分块/后端及全部失败由后续验证阶段归档。

后续先闭合本次冻结回归，再依证据进入有限候选/固定局部搜索和独立相干确认。

## 编码对照的参数转发修复

验证工具新增权重选项后，`Replay.coded()`的独立硬/软译码曾重新调用默认载波函数，
没有转发权重参数。三项独立参数转发测试中默认路径通过、浮点/定点新选项两项失败；
保存首次908行回放和驱动哈希，编码分支不能计为已测新权重。
修复只转发本次明确配置并记录实际载波/软信息元数据，不改变期待载荷、CRC或算法参数。
两编码臂独立运行，不按CRC挑解码结果；补充编码分支单独重放并关联原输入哈希。
新开发/保留的实际MAC流式对照原本直接使用所选配置，不受这个诊断工具问题影响。

## 诊断重放必须保持实际处理路径

BER重放读取实际帧中的载波方法及权重信息，不能默认用coherent替代phase_regression。
少于32个载荷线符号时，真实解析器只用同步区估计，诊断同样跳过盲载波细化。
缺失、未知的方法或与符号数矛盾的元数据明确报错，不能将另一条处理路径的结果计入BER。
CRC只用于核对重放与实际接收是否一致，不用于重试或选择算法。

原短包CRC通过但诊断抛异常的IQ、SHA及错误模式转发记录保存在冻结证据根
`carrier-prefix/diagnostic-baseline.*`；新反例包含短包正确/坏数据CRC、两种长包方法和未知元数据。
这修复的是验收工具，不是新的接收增益。
