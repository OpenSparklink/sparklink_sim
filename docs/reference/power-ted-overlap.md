# 功率与 TED 的有限重叠

本页记录 §6.2.1.2 接收实现的结构候选；它不改变调制标准。显式选择
`PowerTEDFrameReplay` 才使用该时序。普通接收、已有定时类和默认回放保持原行为。
目标仍是4 Msym/s、SPS4；本节点不构成完整未知起点接收机、FT1支持或16 MS/s验收。

## 依赖与时序

原四个 DSP25×18 银行先计算当前符号能量，再计算 Gardner TED。
TED 操作数准备不依赖新的功率，功率更新也不需要 TED 乘积，因而允许重叠：

| 相对注册边沿 | DSP 银行 | 独立逻辑 | 结果约束 |
|---|---|---|---|
| 0–4 | 当前符号能量乘积及归并 | 0–2准备 TED 操作数 | 同一输入 credit |
| 5–9 | TED乘积及归并 | 5–10执行原六级功率更新 | 不提前提交包状态 |
| 11起 | 原后续 PI 所需乘法 | 比值准备等待功率及TED均完成 | 原RNE、限幅和系数 |

旧比值准备从第19个相对边沿开始。新结构保持功率、TED、除法、PI和NCO的整数算术，
只把无依赖工作重叠；没有降低同步门限、改变相位网格或依据CRC重试。

| power30/error32路径 | 原串行 | 重叠候选 |
|---|---:|---:|
| tracked、bounded-prefix非旁路 | 75 | 67 |
| tracked、radix4-prefix非旁路 | 59 | 51 |
| tracked、零TED | 29 | 21 |
| 无midpoint的初始节点 | 18 | 18 |

这些是可执行模型边沿。DSP延迟3、宽加法/RNE/归一化和比值准备宏仍沿用已有假设，
没有综合或布局布线证据。radix4的51位比较/选择/减法一拍假设继续独立记录。

## 有限状态与端口

一个输入 credit 和一个 held 输出；没有投机的下一次NCO查询或更多源样本历史。
TED准备结果可用94bit编码：两个signed25差值与两个signed22中点分量。
展开的四组DSP项是这些寄存器的扇出、位选及常量移位，不是四个独立寄存端口。
可达节点状态均检查该编码的范围及可逆关系；若实现选择保存展开副本，必须另行计费。

另外10bit用于TED准备年龄/有效、功率年龄/有效、完成与操作数有效标志和控制余量。
新增逻辑状态上界104bit；新`wait_power`状态使原15个状态变16个，仍可用4bit编码。
这不是实际综合FF上界，物理扇出复制、控制LUT和时序仍未知。

| 项目 | 候选要求或增量 |
|---|---|
| DSP | 原4个，单边沿最多4个原生乘法启动；无新增DSP |
| 状态 | 94bit操作数＋10bit控制；不改旧4096bit结论 |
| 源RAM/源端口/缓存 | 无新增，原512word历史保留 |
| 并发乘积树 | 两个80bit成对加法与一个80bit最终加法 |
| 功率逻辑 | 45bit加/减、两个44bit归一化与对齐路径 |
| 宽逻辑共享 | 功率加法与TED乘积树可同拍工作，不能免费共用 |
| RX/TX/MAC/译码共享 | 未计收益；并发和截止时间需整机证明 |

总容量、RAM银行/复制、环路、载荷译码及TX/MAC预留继续在
[整机账本](system-feasibility.md)单列；旧16KiB和其他数值超预算失败不被新增量预算覆盖。

## 两个结果所有者

复用既有 `DataJointFrameReplay` 的原子join。新零TED路径21周期，早于24周期归一化；
一般路径67周期，晚于归一化。两种顺序都必须等待双方结果、校验同一输入字和绝对索引，
随后只提交一次符号、头字和下一查询。每符号联合节省可能为5或8周期，不能概括为恒定8。

同一包持续保存功率、Gardner/PI、NCO、归一化和源索引；跨包使用新上下文。
头部真实CRC、合法长度/MCS与帧尾回执保持原逻辑。EOF、非法头或资源耗尽不得浮点重译头，
未执行的数据CRC仍为null，不能交付MAC。载荷载波/LLR/译码仍是显式off-clock服务。

## 冻结验证与复核

外部原型在4200个开发节点后冻结，再检验4608个不同指数/符号/幅度阶梯组合。
本次移植类AST与该原型一致；这些节点已经查看，当前只作固定回归，不宣称新的保留集。
独立功能状态、串行服务与候选均比较整数状态，并检查输出保持、每拍DSP上限和中止。
冻结源、参数及采用规则后才执行validation命令，变化即拒绝，不使用CRC挑结果。

```sh
PYTHONPATH=src:scripts uv run --frozen python -m scripts.model_timing_overlap --output /tmp/ted-dev
PYTHONPATH=src:scripts uv run --frozen python -m scripts.model_timing_overlap --freeze /tmp/ted-dev/freeze.json --output /tmp/ted-val
```

须使用新目录；预期退出1必须核对`model.json`和诊断记录，异常不等同于预期资源失败。
协议保存源码/策略SHA和实际后端标志；相同字模型本身没有Rust版本。
普通与标准B1固定帧、两RAM布局和三种分组比较完整内容、CRC、MCS、长度和采样轨迹；
负例、EOF和两个自然完成顺序有独立测试。所有已看RF样本只作固定回归，不计新的捕获收益。

此前两原输入的24个连续前缀仍全部history_overflow。只从首个数据符号后连续供样的
短前缀中，两个除法选择的周期从124/108至116/100（各观察8个相邻周期）。这不是
ADC/RRC/捕获或最坏整链证明；100周期仍超过200MHz下每符号50周期的目标。
四项接收机验收继续分别开放，不把精确整数结果或局部节省当成完成。
