# 低幅度与低SNR未知起点捕获

本轮基线 `c3e2cbb`，沿用 `codex/psk-timing-tracking`；只改离线模型、测试、文档和CI。
下文96包编码原始IQ是独立发送参考生成的仿真IQ，不是硬件采集；真实硬件数据及派生试验另列。
先捕获正确性及误检/预算闭环，再优化16MS/s；FT1流式及未知厂测编码前缀独立处理。

## 冻结预算与阶段

用户确认先按保守基线推进：原成功包零退化，原144真实静默及220独立静默零新增候选/交付，
增加独立噪声与干扰验证；历史与合法最大帧缓存上限不增加。
没有声称0次观测误检是普遍误检率。每百万采样报告能量触发检查、搜索调用、相位/位置假设、
同步候选、误交付；新工作区与搜索上限在实现前固定，不通过CRC/期待载荷选择同步答案。

阶段：可观测性与基线归因 → 新开发集比较门控/同步方案 → 参数冻结后复核保留与全部原成功/静默
→ FIR融合/搜索复用及向量化 → 必要热点Rust化与16MS/s实际测量 → 捕获后重评软信息。

## 阶段2：更早触发，先筛除不相关窗口

新默认 `PSKCaptureConfig(energy_multiplier=2, integer_screen=.6)`。静默参考仍显式传入，
仍用8符号能量窗和`.999`分位数，降低倍率而非无条件逐窗搜索。每个能量触发窗先做4个整数采样相位
的归一化差分相关，最大值不足`.6`直接返回；否则运行原32相位分数搜索、`.85`门限及最大峰准备条件。
预筛不会挑选较弱的就绪峰，完整搜索仍独立选择一个最大值；CRC/期待载荷/真值不进入捕获。
预筛可能漏掉极端离网格信号，不将开发/保留集通过解释为一般等价证明。
`PSKCaptureConfig.legacy()` 显式重现4倍门限、不预筛的旧路径；原整段理想API保持不变。
这些门限是接收模型开发参数，不是标准门限；对应波形/同步/CRC条款沿用上节。

参数仅依据新开发48输入选择，再冻结后运行新保留96输入，未依据保留集重调。

## 阶段6：有界延后静默滤波与硬解映射批处理

默认允许`defer_quiet_fir=True`：4096采样能量证明静默后，暂存480原始采样，替换原滤波历史和
延迟数组；下一次实际处理或访问滤波历史前，按原32采样卷积顺序重建一次。
连续静默不重复重建。保留原输入dtype，保证complex64/float32的能量运算不被隐式升精度改变。
原滤波历史仍384采样；原历史/延迟合计495采样预算内替换，存在未满量子的pending时两路径均另有至多31采样。
能量滤波器超过一量子或原缓存预算不够时使用原即时路径；显式False可作对照。
原私有历史读取也会就地重建，没有延后包事件、不等待采集结束，未来样本需求仍相同。

仅延后静默滤波的配对实测：Rust8.05/8.50→9.82/10.59MS/s，轨迹完全相同。
随后profile确认硬解映射占剩余约0.039/0.174秒；改为128符号有界批处理，保持真实星座标签、
绝对交替旋转和导频位置。距离临时矩阵独立于包长，上限128×8，不构造整包的大矩阵。

## 阶段7：原生整数预筛及精确边界回退

新增`integer_screen_backend='auto'|'python'|'rust'`。原生函数只计算整数网格的归一化差分相关最大分数，
完整分数搜索仍由同一组件选择答案。支持的同步长度至128符号时，若分数距既有门限不足1e-12，
用原NumPy运算做精确判定；这不是降低门限。安装加速扩展的CI必须核验新函数实际存在。
事件、性能基准和后端JSON分别标明定时环与整数预筛的实际后端。

NumPy复核的整数相关数组供后续分数网格复用，正确排除最后原始样本对应的非法细搜索窗。
新增反例证明不会把整数边缘完美峰当成可用细搜索最大值；原最大峰准备条件保持。

## 使用：让MAC调用改进后的接收路径

改进入口是`MacStreamReceiver`（内部`PSKStreamReceiver`）。原`iq_to_mac_capture`/
`receive_capture`整段分段入口保留既有行为；已知对齐的`iq_to_mac`/`rx_chain`仍供理想仿真。
普通A2及厂测A3必须显式选择profile；不将厂测同步字、CRC或未知编码前缀当通用默认值。

```python
from nearlink_sdr.phy.mac_interface import MacStreamReceiver
from nearlink_sdr.phy.strict_rx import PSKReceiveProfile
from nearlink_sdr.phy.tx_pipeline import TxConfig

profile = PSKReceiveProfile.ordinary(TxConfig(mcs_index=8, symbol_rate_mhz=4))
rx = MacStreamReceiver(profile, quiet_iq)  # 独立静默参考，禁止包含期待载荷
for iq_block in input_blocks:
    for result in rx.iter_feed(iq_block):
        consume_verified_packets(result.packets)
        retain_diagnostics(result.diagnostics)
result = rx.finish()  # 截断候选仅留诊断，不交付MAC
consume_verified_packets(result.packets)
retain_diagnostics(result.diagnostics)
stats = rx.phy.capture_stats
```

同步不使用期待长度/内容或CRC择优；只有真实头CRC正确后读取合法长度/MCS。
新增低幅度编码IQ到MAC回归：旧门控漏包、新路径交付完整载荷，坏头CRC仍不交付。
