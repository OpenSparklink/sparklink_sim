# 数据期定时与归一化联合调度（RX-DATA-JOINT-SERVICE）

本实验仅改变 PSK 数据期的执行先后，目标是验证有限资源下的计算重叠。
沿用 §6.2.1.2、§6.3/6.9 的既有波形与帧算法，不新增标准功能宣称。
已实现的同步期缓存广播、Gardner/PI、归一化微程序、真实头 CRC 和合法帧尾完全复用。
默认接收机不变，新类 `DataJointFrameReplay` 为显式结构实验。

此处数据期指固定已知同步保持段之后，包含头部、载荷及实际导频，并非仅MAC载荷。

## 依赖与唯一所有者

旧数据期先执行定时服务，结果完成后才启动 24 边沿归一化。
两者已经有独立 4 DSP 银行；归一化只读取当前 52 bit 字、初始拟合得到的
增益/频率和自己的前字相位，不读取定时功率、TED、积分器或 NCO 速率。
因此可在同一个真实边沿把同一当前字送到两套现有银行；Gardner 同时取得中点字。
没有改变样本选择、环路反馈方程或反馈所对应的符号索引。

每次只有一个输入对，不能在未配对结果旁继续推入其他符号。
输入前先检查两个信用、实际未来样本、字宽、包索引和有限计数。
输出前检查实际当前字、绝对索引、相位、持有输出和计数，才执行唯一交接。
归一化即使先完成，也保持原有结果寄存器，不能先存符号或启动下一查询。
定时服务原本在注册完成边沿更新状态；该状态尚未交付时，仍不得查询下一符号。
两状态/两服务的提交差异在中止和资源事件中分别记录，不冒充原子物理寄存器写入。

头部只在符号真正交接后取得字，实际头所有者继续执行解扰、SSC、CRC 与合法长度。
EOF、非法头和资源退出不重新运行浮点头译码，未实际校验的 CRC 为 null。
CRC 不用于选择另一组同步、定时或载波答案，载荷仍只消费唯一可信头回执。

## 成本和延迟

| 项目 | 本次增量/规则 |
|---|---|
| 控制状态 | 128 bit：两个 64 bit 计数，已计入公共控制总量，不再相加 |
| DSP | 新增 0；既有定时 4 与归一化 4 同时工作，不计共享收益 |
| 原始历史、源/缓存端口 | 新增 0；512 字源历史不扩大 |
| 输入对信用/结果 | 1；复用原两个服务的结果寄存器，无新 FIFO |
| 字广播 | 52 bit 送两个既有输入寄存器，扇出/选择逻辑需映射 |
| 模式 | 复用 `timing_issue/timing_run`，不增加 FSM 编码 |
| 身份比较上界 | 两组 52 bit 源字、64/18/18 bit 包序号；既有未来样本/计数保护复用 |
| LUT/FF/Fmax | 未知；控制预检与交接的单边沿组合假设未综合/布局布线 |

原同步期的四上下文归一化寄存器仍全部计费，不能因数据期只用一个上下文便减掉它们。
没有新增可暂停 ADC 的接口，也没有给 TX、译码或实时 MAC 共享这些银行的收益。
更新的替代节点见 [整机账本](system-feasibility.md) 和 `system-target-ledger.json`，
本次不修改原 16 KiB、4096 bit、2048 bit 或浮点数值失败结论。

主对照保持 `bounded-prefix`，不自动采用两位商候选。
75 周期定时与 24 周期归一化可以重叠，但仍有约 45 周期运输，
当前非旁路串行反馈子图下界约 120 周期/符号，超过 200 MHz 下 50 周期预算。
当前数据期最短定时旁路为29边沿，仍晚于线性归一化24边沿；已知同步期的较短保持
服务不走本次数据配对。现有正常编译时序只观察到归一化先完成，不能称为验证了两种顺序。
另以明确的注册DSP返回延迟注入反例验证定时先完成时的保持与唯一交接；
该反例不改变正常延迟假设，不当作新硬件配置、资源期限或接收能力证据。
完整载波细化、LLR、译码和调度周期仍未知，不以局部周期数代替整包延迟。

  --output /tmp/data-joint-development

  --freeze /tmp/data-joint-development/freeze.json --output /tmp/data-joint-validation

两条命令预期退出 1，并且必须核对生成的 `model.json`；异常不能当作已保留的资源失败。
目录须不存在，源码、政策、采用规则和预算在节点验证前冻结，错误源向量直接拒绝。
新节点集合改变帧型/MCS/导频组合，以及零输入、极端符号位、稳态和强弱指数切换。
它们是明确的 52 bit 当前/中点端口注入，用真实运输维持因果索引，
只评价调度/所有者/数值等价性，不是可解码 RF 包或新的接收保留集。
既有独立定时/归一化算术依据继续有效，不因调度相同宣布原量化超预算通过。

所有已查看波形仅作固定回归；9 输入、两银行、三分组的 54 次对照分别核对
头 CRC、数据 CRC、长度、MCS、完整载荷、四轨迹、两环路状态和所有保留源字。
期望载荷仅在最终输出后用于计分。新的 RF 误检观察量为 0，不能据此宣称新增零误检验收。

两个原输入各以两银行、三时钟对比新旧连续后缀，共 24 日历。
连续只从头等待开始，之前源可暂停；输入是已滤波 46 bit 字端口，不包括连续 ADC/RRC/捕获。
每个首拒绝索引、保留源字、头校验状态、未完成载荷和未处理后缀都需保留。
完整流式、全链定点、整机资源、连续 16 MS/s 仍分别开放，无新综合证据。
