# 实验：实际PI状态提供保守合法尾界

本试验对应现有§6.3/6.9严格帧所有权的复制调度，普通FT2/3/4、4Msym/s、SPS4，
MCS8/12；不是标准规定的新同步算法。仅显式`MovingTailCaptureReplay`使用，默认不变。
前一静态预取在新开发中恢复1包、退化1包，已拒绝；原失败不回写。

## 资格反例与单一变化

旧输入SHA对应的实际第132041沿，私有FIFO尚空2字、源字6984仍在[6463,10559)，
但静态尾界6080令复制停止。真实已校验头给出1515符号、实际PI已经提交1239次，
下一位置Q32为21731731511482。用这两个收到的状态可得到6148的必要前缀。
这证明复制资格存在缺口，尚不证明端口仲裁能及时返回或包能够恢复。

只改变复制尾界。同步评分、候选数、相位网格、门限、等待规则、PI参数、载波、
CRC、原1024字私有FIFO、4096字源历史、3个拥有窗和读端口均沿用。
真实头CRC、合法长度/MCS仅决定本包范围；不在多个接收答案间使用CRC重试。

设实际提交PI状态为`q[m]`，合法帧符号数为`N`：

```text
position_floor = q[m] + (N-1-m) * MINIMUM_STEP_Q32
copy_floor = min(sample_limit,ceil(position_floor/2**32)+3)
```

只接受`0<=m<N`，不能用最后一个符号后的外推`q[N]`扩大本包范围。
现有有限PI的实际步进不小于MINIMUM_STEP_Q32，因此每次结果不大于实际最后
符号的插值需求，且随提交的m单调不减。这是必要前缀，不能替代实际NCO末尾查询。

17沿移位累加、1沿取整/截断、1沿注册输出，共19真实沿；计算忙时保持上次已发布
尾界。一个请求在途、不设队列；有新PI状态时才重发，忙时的中间状态无需排队。
延迟结果可能失去调度收益，不能提前变成未来答案。EOF、取消和包间释放沿用
实际拥有者，不产生补零；原未消费后缀仍单独记账。头不合法不启动尾界服务。

## 有限数据通路与成本

|项目|旧静态界|移动界|
|---|---:|---:|
|控制状态bit（含63bit时钟、192bit统计）|406|444|
|新增已发布尾界/上次PI计数|0|21+17|
|单请求真实沿|19|19|
|请求数|每包至多1|随实际PI更新重复，II19，上限1在途|
|53bit移位加法|每请求最多17|每请求最多17|
|余量计算|N-1|17bit N+ones-complement(m)|
|新增IQ RAM/DSP/样本端口|0|0|

移动控制器使用53bit局部位置/累加器、52bit移位常数、17bit剩余数、5bit步数、
21bit工作及发布界、3bit模式；RNE不参与本节点，余数OR32实现向上取整，再加3、
与既有sample_limit取小。收到的96bitNCO/64bit计数借用既有拥有者输出，窄化必须
检查高43/47位为零，位置及计数范围/方向比较也计费。位置上界为编译的
`(2**20+8)<<32`，确保53bit累加不溢出；不是新增任意配置接口。

除原53bit加法器外，新增17bit余量加法、计数比较、53bit输入选择、21bit发布
比较/寄存器，以及范围零检测。原ceil/clamp21bit加法/比较、OR32、源复制21bit
比较/选择、3个64bit统计更新、5bit步数减一和控制复位/使能继续计费。
常量35bit步进与53bit范围界是编译线路，不假定任意宽计算等于一个DSP。
外层实际PI计数仍为64bit：每个合格沿的合法末尾/计数变化两个比较另计64bit，
不能用节点内部17bit比较清单冒充全部代价；未证明比较器共享，不先抵扣。

持续忙时控制器上界为每19时钟一请求，而非一次/包。100/160/200MHz、16MS/s时，
最多0.329/0.526/0.658请求每输入采样，分别5.59/8.95/11.18次53bit加法每采样；
实际PI更新稀疏时低于该上界。持续检测、RRC、相关、窗口复制等仍另外计费，
不能把这个节点的II当成整链吞吐。系数/控制映射、LUT/FF/Fmax及故障导出未综合。

512bit是本新节点开发前冻结的实验上限，旧406bit/1024bit及16KiB失败结论仍保留。
整机还须为Polar、必要TX、实时MAC、射频接口/DMA和队列留资源；本节点的38bit
增量不等于新的整机预算已批准。四项总验收分别仍开放。

## 复核与采用规则

```sh
PYTHONPATH=.:src:scripts uv run python scripts/model_moving_tail.py --output /tmp/moving-tail-new
```

先新变化开发集，再按原SHA重放两个已查看固定集合；源、参数、预算、采用规则
冻结后，只有全部通过才生成独立新保留集。开发载荷、FT/MCS/导频/包长/间隔和
干扰组合变化，非仅换噪声种子。旁路真值不进接收；本例PI状态来自真实接收计算。

分别记录捕获、真实头/数据CRC、长度/MCS、完整内容、BER、数值误差与不完整对照，
恢复、退化、算法漏检、资源丢弃和有限负例采样量。低于既有预算的数值或资源
失败不由整包相同覆盖。必须无原成功丢失、无新增误交付/负例确认、资源退出
不增加，且确有整包恢复或相同召回下的调度收益；否则保留并拒绝，不改默认。
这仍不是FT1/GFSK、全链定点、完整16MS/s或实际FPGA/SLE验收。

## 冻结结果：拒绝采用

|集合（各12合法包）|原参考完整|静态界完整|移动界完整|恢复/退化（相对静态）|
|---|---:|---:|---:|---:|
|新变化开发|8|3|3|0/0|
|已查看M38B固定回归|8|4|4|0/0|
|已查看M37固定回归|8|4|4|0/0|

捕获、头部/数据CRC、完整内容及细搜索工作均无收益，仍分别丢失原参考的5/4/4个
成功包，不能以“不比已拒绝静态界更差”推广。原25个剩余失败全部保留；不生成
独立新保留集，不据这些已查看集合调参。三个算法CLI均以1退出，属于结构化拒绝。

私有复制分别19457→19550、19964→20040、14924→14972字；尾界请求均由每集合6次
增至2867/2672/1852次。状态小幅增加不等于计算免费，此处没有换得接收或调度收益。
各集合负例仅32768个独立采样，即16MS/s下2.048ms，未见新增相干确认或误交付；
不同分块/后端的重复回放不增加独立观察量，不宣称一般环境绝对零误检。

只读诊断保留实际第一候选及原滤波字，放宽全局源过期限制后，两个固定集合的
stream3分别211/193字节完整恢复，真实头CRC/长度/MCS、数据CRC及内容均正确。
实际1024字私有FIFO、PI/载波/解码规则不变，没有真值起点或CRC择优。
这说明同一个有限路径在这两个输入上有恢复依据，优先研究样本保存/调度；正式
有限全局历史接收仍失败。不得把暂停式源可用性诊断计入未知起点流式通过率。

新开发89509采样，两个固定分别86492/84653；输入SHA清单及全部候选、漏检、
CRC和资源退出见冻结证据`moving-tail-horizon`。原61/96及更早预算失败不改写。
64项针对性、全量Python6095/Rust6106身份通过，旧身份全保留，覆盖率均93.93%；
本地分片最大76.508/73.432秒，原120秒/90.1%门不变。只将新增两个测试文件分到
既有group6，没有迁移或移除旧测试；实际CI需按发布提交另行核验。

两实际后端240个结果文件、309个NPY成员的数值/判定相同，54处明确的后端标签
python→rust单独核对，整体JSON字节身份不声称相同。完整同服务数值对照4/6/5组
均在旧预算内，另3/2/2组不完整不记通过；共用引导/插值，这不是独立Lagrange
资格证明，旧独立插值拒绝不变。RMS最大9.607e-6、中心差最大1.933e-6采样。

继承的汇总原型曾断言尾界不大于实际消费/退休界，在完整包失败；该原型和错误
保留。原控制器规定的接纳界是ceil(q)+3，四点实际读取可以在floor(q)+3结束。
14个完整服务的尾界均精确等于原接纳界，实际退休小1字，最后Q32与轨迹精确
对应；这一保护字仍属于未消费后缀。汇总改按原接纳界核对，没有增加数值容差、
改变控制器/读取或把保护字冒充消费。输入、策略和源码冻结校验均保持。
