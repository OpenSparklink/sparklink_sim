# 已知同步残差的定点增益准备

本实验补充[定点软解映射](psk-word-demap.md)的增益输入。已知同步
模板与经归一化的观测符号组成 Q14 复数对，准备按已知同步残差
估计的复方差。增益随后供 QPSK/8PSK 标准 FT3/4 B1 的
已验证头到有限译码、双 CRC 和 MAC 服务使用。模板选择、采样跟踪
和载波归一化仍由上游供给。

## 算术和周期

- I/Q 每字有符号 18 位、14 位小数。差值有符号 19 位，平方的
  18 位绝对值按低 17 位和高位拆分。17×17 乘法与两个移位加法
  精确恢复平方；一只乘法器在 I/Q 间复用。最多累积 256 个
  复符号，45 位余量按全幅差值证明。
- 记累加值为 `E`，样本数为 `N`，待传递给软解映射的比例为
  `(N << 29) / E`，对应 `2 / variance`。当且仅当累加值为零，
  使用 1e-12 方差下限。在本输入字宽及 N 范围，最小非零方差大于
  该下限。比例对齐成 [0.5, 1) 的商及二进制指数，除法最多使用
  45 位分母和 46 位双倍余数。17 位商计算完后执行最近偶数舍入，
  末位进位超过量程则重归一化。不把浮点倒数用于该状态机。
- 输入到残差提交为 4 沿，组件保留一个在途复符号，最短启动间隔
  为 4 沿。末符号之后，1 沿规格化、17 沿恢复商、1 沿舍入，
  连同最后一次残差提交共 **23 沿**。逐沿记录实际状态、余量和结果。
- 准备好的增益明确携带可用沿。首个有效载荷符号检查增益已可用，
  对晚接入报错，避免从后续观测反推早期数据。若恰在首符号沿出有效，
  首符号可进入投影，稍后的增益乘法读取有效结果。浮点方差入口保留，
  两种增益源不能同时指定。

该组件估算新增 1 个 DSP、398 位主状态，无新增数据 RAM，
模板读取端口仍由上游负担。规格化移位、前导位检测和比较的单沿
为建模假设，完整 LUT、布线及物理时钟尚待确认。未给未知上游延迟
或 DSP 共享计入零成本。

## 复核

| 输入和实验 | 有限结果 |
| --- | --- |
| 开发和独立保留整数参考 | 160 + 240 个精确残差/比值例，含全幅、零、单码残差 |
| 开发软位 | 117632 位，16 位改变，最大 1 个量化码 |
| 独立保留软位 | 94080 位，8 位改变，最大 1 个量化码 |
| 独立帧结果 | 48 帧结果，33 交付、9 CRC 失败、6 译码缺字 |
| 已冻结的标准 IQ | 2 份输入、整段/随机分块及两种字宽共 8 臂，9728 个软位一致 |

独立保留在 100/160/200 MHz 组件节拍下测量。浮点和整数增益
在失败、MAC 内容和末沿上全部一致，无新增整包退化或恢复。
100 MHz 最短连续符号例只余 2 沿。冻结 IQ 在已有归一化序列标定
的名义时刻上，最小余量为 8027 沿；真实 ADC 起始到同步模板准备、
头上下文和归一化输出的调度还需联合核验。超期输入、相邻过早输入、
截断模板、极端零残差和溢出上界分别有测试。旧软解映射极端非额定
误差、Polar 缺字与既有资源/量化失败结论维持。

阶段证据和单命令重放保存在冻结根 `psk-sync-gain`。
完整流式、全链定点、整机资源及连续 16 MS/s 仍待联合验收。
原 IQ 接收保持现有默认路径。
