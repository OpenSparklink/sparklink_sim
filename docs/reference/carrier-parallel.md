# 并行原始角度载波实验（B3A，拒绝采用）

本阶段对应标准§6.2.1.2的接收实现选择，延续[整数载波节点](carrier-fixed.md)。
目标是缩短反馈依赖链，而非优化Python/Rust墙钟时间。原B2与默认接收路径均保留。

## 唯一算法变化及冻结

原B2先旋转/RNE/饱和，再取CORDIC角度。候选在原始量化IQ上先取角度，与NCO旋转并行，
随后减去同一符号开始时的32bit相位字，再做原交替旋转、扇区选择、限幅及PI。
旋转输出仍执行原RNE/饱和；该算法变化只使检测器绕过旋转舍入及饱和。
浮点中两个坐标在圆周意义下等价，有限精度下不保证等价，尤其在星座扇区边界。

保持18bit Q10、18次CORDIC、24bit向量/34bit角度、原系数ROM、medium增益、功率保护、
实际头部预热、同步/定时及解码规则不变。没有同时减少CORDIC迭代、改变环路增益或按CRC重试。
独立的节点测试检查真值载波、Fraction PI、字段切换、1..32任意分块、极值/零向量、
饱和、EOF和实际FT2/3/4 IQ→MAC；BER重放只调用元数据声明的同一方法。

`tests/data/carrier_parallel_study.json`在生成新开发集之前定义方案、预算与两组配方；
`carrier_parallel_selection.json`在开发通过后、生成新保留之前冻结源码SHA及采用规则。
开发改变载荷多项式/重复模式、FT/MCS/导频/长度组合、近邻双音、错误同步背景、突发与幅度变化，
并非只换随机种子。先前集合均为固定回归，本保留集现已查看，不可用于选择另一迭代次数。

## 实际接收结果及拒绝原因

| 集合/方案 | 捕获 | 完整正确 | 载荷错误bit/可算bit |
|---|---:|---:|---:|
| 开发：浮点PI / B2 Q10 / 原始角度 | 均7/8 | 均6/8 | 均6/20872 |
| 新保留：浮点PI | 8/8 | 7/8 | 1742/30768 |
| 新保留：B2 Q10 | 8/8 | 7/8 | 1709/30768 |
| 新保留：原始角度 | 8/8 | 7/8 | 1737/30768 |

开发数值门通过后，仅评价冻结方案。新保留原成功零丢失，但相对B2多28个错误bit；
`validation-3`相对浮点的相位峰差0.035262rad、输出归一化峰差0.023222，均超原0.02门。
相对B2的相位峰差0.165062rad、RMS差0.050439rad也超预算。因此**拒绝推广**，
不以整包相同覆盖数值失败，不放宽预算、不在该保留集挑选14步或其他增益。

这也新增了B2自身的固定数值反例：该输入上B2相对浮点相位峰差0.165131rad、
输出归一化RMS差0.053315。B2先前通过的有限验证并不代表对所有输入逐点接近浮点。
三方案输入符号/采样轨迹一致，记录了最近扇区路径分歧；没有中间饱和/溢出。
该包为错误同步背景下的未编码8PSK，三方案都未完整恢复；不能据此断言理论不可恢复。

新开发4负例29069采样、新保留4负例28823采样（16MS/s合计约3.618ms）均零候选/误交付，
这只是有限观察。开发的1漏检及1CRC失败、保留的1CRC失败、全部数值失败和原输入SHA均保存。
因新保留已否决，没有将候选推广到默认，也没有把旧96包的61正确写成该新方案的验证结果。

## 携带实际值的32周期日历

| 周期 | CORDIC/环路 | 并行工作 |
|---|---|---|
| 1..3 | 原始字领先零/公共移位/象限 | NCO地址/ROM，功率乘积3 |
| 4..21 | 18次向量迭代 | NCO4，功率RNE5/保护6/状态13，旋转7..9 |
| 22..25 | 减当前相位、交替旋转、扇区及限幅 | 输出旋转已完成 |
| 26..28 | 并行两种PI RNE、积分相加/限幅 | 需计两RNE设施/选通 |
| 29..32 | 两次相位相加、回绕/提交、计数完成 | 假设同周期状态转发 |

逐周期模型携带实际整数，逐字/逐状态对照节点；有限队列/背压/整包作废规则复用B2共同模型，
B2公共API与41周期日历保留。零/低功率/异常字仍按最坏32周期收费。

估算仍6个18×18实乘DSP25x18片、额外1个双读RAMB18；逻辑内容20552bit（输入深4）或
20776bit（深8），复用已有原始拥有字、相位快照、CORDIC及PI暂存。另计34bit相位减法
（在日历22复用先前的角度ALU）、68bit组合选通及两PI RNE设施；选通/RNE的LUT/FF未知，未填零。
ROM/atan表、移位器、宽加法、计数器与队列沿用B2分项，不把任意位宽乘法算成一个DSP。
每字最坏6次实乘、54次CORDIC加法、36次移位、18次方向比较和新增相位减法；
功率宏及旋转/PI/饱和成本一并保留，没有运行时除法/开方。模型原语延迟和布线仍是假设。

512字、4000401符号/s场景：

| 条件 | 发出/资源作废字 | 最大字延迟 |
|---|---:|---:|
| 100MHz持续 | 14/498 | 125周期 |
| 160/200MHz持续 | 512/0 | 33周期 |
| 160MHz四字突发、输入深4 | 512/0 | 126周期 |
| 160MHz八字突发、输入深4 | 0/512 | 整包作废 |
| 160MHz八字突发、输入深8 | 512/0 | 250周期 |

服务41→32周期（减少约22%）使160MHz孤立节点容量条件改善，但候选没有通过数值/BER采用门。
100MHz仍不够，新增深度只延缓持续超载。额外状态/选通未综合，不能声称已满足完整资源预算。
捕获积压、头历史重放/译码就绪、归一化、插值、Polar/TX/实时MAC/DMA并发仍需统一模型；
不能将该节点写成整链接收16MS/s或实时FPGA。原2%RRC/16KiB失败继续保留。
