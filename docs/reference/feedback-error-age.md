# 定时误差年龄：功能参考与待验架构

§6.2.1.2规定波形，本接收环路和固定误差年龄属于实现选择。
默认接收机及原周期服务不改变。显式`FeedbackAgeTimingState`只是有限字功能参考，
不是完整流式接收、周期服务或已采用的算法。原word-full12-c18、插值和资源失败仍保留。

## 改变什么

原Gardner误差、功率更新、RNE、限幅、PI系数、速率范围和插值器不变。
测量误差为当前符号；PI应用其前0/1/2/3个符号的误差。同步期间维持原功率更新和NCO推进，
不推动误差队列；跟踪启动用固定零填充。结束或EOF丢弃未应用误差，不继续修改NCO。
同一包跨块保留状态，下一包使用新实例。

这是算法变化，不能把变化后的轨迹当作原算法的浮点舍入差异。
选择年龄不能使用CRC、期待载荷、真值或逐包重试；固定年龄必须先由调度要求决定，
再通过独立新保留集验收。目前尚未采用任何年龄。

## 有限字语义

复用原power30/error24、30/32、38/32格式和64+32坐标。
误差FIFO的每字宽为error_bits+3，恒定长度不超过3，移位寄存结构无动态队列增长。
一个原WordTimingState保存功率、上一个样本、NCO及原统计；新增FIFO、最后应用误差和关闭标志。
原提交先检查所有范围和计数，再原子提交；成功后才移动FIFO。
FIFO损坏、计数/NCO耗尽时，原状态和FIFO都不改变。

`FeedbackAgeTimingState`使用组合而不是继承原周期状态类。
原`TimingWordService`明确拒绝它，防止把功能计算当成零周期或错误地复用原单所有者服务。

| 项目 | 功能参考的增量或状态 |
|---|---|
| FIFO | age×(error_bits+3) bit，零初始化 |
| 最后应用误差 | error_bits+3 bit，诊断持久状态也计费 |
| 关闭标志 | 1 bit |
| error32、age1/2/3 | 71/106/141 bit新增持久状态 |
| age0 | 仍计最后误差和关闭标志；不修改默认原状态 |
| FIFO逻辑操作 | 每跟踪符号一次pop/push；不等同单RAM端口实现 |
| FIFO物理寄存器活动 | 每跟踪符号读、写age个字，另有(age−1)×字宽移位线；已计所有寄存位 |
| 流水上下文、标签、仲裁、额外DSP及RAM端口 | 尚未建模，不能填零 |
| II、完整延迟、LUT/FF、Fmax | 未验证，无综合或布局布线证据 |

160bit是本功能状态增量的事前实验上限，不是放宽原4096/2048/16KiB或整机预算。
功能实现中的整数乘除不是硬件一拍。原精度预算在相同算法的浮点/有限字之间仍适用；
独立FIFO顺序/PI舍入精确不等于闭环采样误差、全链定点或硬件调度通过。

48项针对性测试覆盖36组格式/年龄/同步长度、逐步Fraction舍入、零填充、边界及失败原子性。
冻结后另有9252个不同符号/指数边界节点，两环境压缩转录逐字节一致。
检测器仍复用原规范函数，该验证只独立核对FIFO顺序及PI舍入，不是独立端到端定点依据。
全量两环境4833/4844项，原身份全部保留，覆盖率均93.54%；四片和90.1%/120秒门不变。

## 新开发对照

新输入变化普通标准A2/B1、FT2/3/4、QPSK/8PSK、37–1021字节、导频0/4/8/16、
CRC24/32、载荷、CFO/SRO、非网格起点、幅度和干扰组合。解析保留实际profile语义，
没有厂测未知编码前缀。各臂保持同一已有因果单音抑制器及捕获配置。
独立解析脉冲发送参考和信道生成IQ，接收端不读取发送真值。

36流包括30个正流（其中6个密集双包，合计36合法包）和6个负流。
浮点零延迟逐字段和轨迹精确复现原接收；独立1024步/年龄验证FIFO应用顺序与功率/PI行为。
完整接收结果如下，仅属于开发集，不是独立新保留集：

| 误差年龄 | 捕获/头CRC | 数据CRC/完整载荷 | BER错误/可计算比特 | 最大原轨迹差异 |
|---|---|---|---|---|
| 0 | 29/36 | 22/36 | 2093/64736 | 0 |
| 1 | 29/36 | 22/36 | 2094/64736 | 0.06688采样 |
| 2 | 29/36 | 22/36 | 2095/64736 | 0.10977采样 |
| 3 | 29/36 | 22/36 | 2094/64736 | 0.16365采样 |

各臂均16/30正流全部正确，零原成功丢失；7漏检、7数据CRC失败保留。
BER略增，不是接收收益。0.25采样算法轨迹预算沿用旧结构实验的预定比较界，
不覆盖相同算法有限字的0.001采样增量门或旧插值失败。
每臂负例仅44663个采样，约2.79ms，未观察到误交付；不能声称全环境零误检。

初次主机统计接口和后处理坐标使用错误均留证：修正统计读取后使用原SHA输入重放；
流式接口已补偿FIR延迟，后处理不再重复加40采样。后者只重读保存的事件和轨迹，
没有重新选择同步、载波或CRC答案。真值误差未擅自扣除单音滤波器的频率相关群延迟。
正式61/96压力计数不改变。

同一36流的固定257采样及混合分块另作288次/环境回放：两环境的所有同年龄包判定、
完整载荷、字段与采样轨迹和整段结果精确，发出时刻差异为0。候选定时与整数搜索
均显式使用Python；Rust环境仅验证可用的CRC/Polar等加速，不存在Rust延迟定时或新字模型。
分块重放不增加独立RF观察样本。

## 为什么仍需新的周期模型

现有选定符号串行路径为98边沿，包含51定时、43查询/插值运输及4交接。
100/160/200MHz下每符号预算分别25/40/50，原单所有者结构不满足连续吞吐。
延后误差有可能让检测、PI及未来查询重叠；它需要独立功率/样本和NCO状态所有权、
有限上下文、真实DSP冲突及源窗口验证。简单把98除以并行数或增加FIFO都不是证明。
本页没有为尚未执行的采样、载波、头、载荷和译码赋零周期，也没有宣布整链16MS/s。

新开发结果仅支持继续研究这个方向。必须先闭合有限字闭环误差和可执行调度，
冻结算法、参数、预算和采用规则，再评价新的独立保留集；失败后不围绕该集合调参。
整机仍需给译码、TX、实时MAC及接口预留并发资源，四项接收机验收全部开放。
