# B1 译码的输入槽提前释放与缺字处理

本阶段接在[有限 B1 译码](payload-polar-flow.md)和[压缩几何](payload-polar-geometry.md)
之后，使用已验证头几何形成标准 B1 字序（第 6.9.1.3 节、附录 A）。
入口为连续的已解扰 LLR。资源选择只用到达、RAM 所有权和必需物理字是否齐全。

## 数据、端口和失败处理

- 保留两个输入槽，每槽三块单口 RAM。字内地址按模三分银行，
  一拍允许连续的 2 或 3 个 QPSK/8PSK LLR。实际回放逐拍写入有限的两组
  RAM，各有 342/341/341 字。一个 8PSK 符号横跨物理字时，两组槽
  同沿各接收自己的部分。超过端口或占用额度的事件留证。
- 译码直接读取正在持有的三块输入 RAM，读数进入已有 LOAD 寄存路径。
  在该路径最后一次写回 alpha 后释放输入槽。后续节点遍历只用内部
  alpha/beta/U。允许新字在释放沿占用原槽，包括旧字仍在译码时。
  例如两路 N1024/K512 的最后输入读是启动偏移 512 沿，LOAD 结束 516 沿，
  完整译码 13817 沿。输出 U 的保留和下游两位每沿的交接规则维持。
- 首次资源丢字发出帧不完整事件。可选抑制只作用于该帧之后尚未接纳的字，
  区分 `resource_drop` 和 `incomplete_suffix`，在下一帧开始复位。
  已入队或在解码的字都完成退休。输入仍按实际符号时序推进。
  截断输入记录异常事件，输出仍是未校验信息位，需要由后续帧级
  合并、长度和 CRC 服务决定交付。
- 比较保留原槽、提前释放、只抑制与组合四种紧凑策略，同时重放原 indexed。
  端口模型排除读后退休及同槽同银行的同沿读写。30 次带值回放
  共 55040 个实际读、24551 次带写输入拍、102 个接纳字，
  其中 24 次复用发生在原字完成前。已接纳的字与相同定点输入下的 SSC
  参考逐位相同，两后端的结果和端口日志哈希一致。

数据银行、并行度和占用上界沿用紧凑实现的 18/22 个 RAMB18 等效估算，
提前释放与缺字抑制不增加数据 RAM 或 DSP。原控制估算包含两个槽的状态；
新增需接入 LOAD 退休握手、帧缺字记忆位、一次首次缺字通知和后缀接纳门，
控制综合、路径延迟与下游错误描述符资源待联合测量。模型中的绝对沿与
口日志用于校验，实际逻辑需为所有权和跨帧错误路由分配有限编码。

## 候选局部截断

已选多帧可用各自独立的输入源。码字日历在某个必需输入拍缺失时，
撤销该未收全码字的输入槽及该字预订的 LOAD 和输出期限。
帧事件仍在首次遗漏拍发生，先前已收全的码字保持原时钟并完成退出。
后续候选可以在原可信几何预计的尾部之前进入同一译码器，
缺失 LLR 不以零补齐。原单源的全局 EOF 和双 CRC 交付保持。
[多帧调度与前端约束](psk-selected-carrier.md)。

## 末码字暂存实验

`short_tail_slot=True` 可用于入口日历和实际字节交付回放。
真实头给出标准 B1 码块几何。两常规槽忙时，第三槽只可接纳
尚无资源缺字帧的最后一个物理码字，容量为 N64/N128。
常规槽空闲时优先用常规槽。后缀已经失效、末码字过长或短槽
仍在使用时走原资源丢失规则。短槽不为其他字复制 LLR，也不
改变头 CRC、码块/数据 CRC、解映射位序和译码算法。

短槽用三个取模分银行，深度 43、43、42，每银行每沿一访问。
实际写入后等原译码器 LOAD，读取注册完成后释放。提交仍按照
到达码字顺序。MAC 边界最多有四个帧描述符，含 LOAD 已释放
但结果仍在输出的帧。EOF 中止未写全的所有权。保留此前完整结果，
额外槽的好坏 CRC、未完成写入和多帧状态分别验证。

| 项目 | 额外预算 |
| --- | ---: |
| 8 位整数 / 9 位含小数 LLR | 1024 / 1152 数据位 |
| 始发与 MAC 所有权，以及控制/注册读 | 最坏 443 位 |
| RAM 银行与端口 | 3 个各一端口，注册读按一沿 |
| 7 系列分布式存储估算 | 24 / 27 个 RAM64X1S，加注册读与地址选择 |
| 独立 BRAM 映射保守上界 | 3 个 RAMB18 |

分布式 RAM 占用 SLICEM，物理放置、控制 LUT、寄存、Fmax 与
端口仲裁尚无实测。分布式与硬 BRAM 是两种映射，整机总账不能
把两者相加，也不能据此认定剩余半片或 DSP 已共享。
[AMD RAM64X1S](https://docs.amd.com/r/2025.1-English/ug953-vivado-7series-libraries/RAM64X1S)

16 个独立已选输入在 160 MHz 从 7→11，200 MHz 从 9→11。
两个时钟分别有 384/192 个短槽 LLR 实际写入且被读取。
旧固定的三个已知失败均在 160 MHz 恢复，200 MHz 恢复一臂。
在独立连续日历的 MAC 阻塞压力下，恢复更早帧会占住单帧输出
RAM，原成功的后一帧在 160/200 MHz 各退化一臂。**拒绝一般
推广**。以前成功的孤立帧时序和交付保持相同，短槽继续显式实验。
原始 ADC、未知起点捕获及整链 16 MS/s 不由这些结果覆盖。
证据目录为冻结根的 `b1-tail-slot`。

## 短译码结果保留

`short_result_slot=True` 在译码完成边沿检查实际输出信用。
当输出阻塞、短槽空闲且结果为 N64 时，原双银行结果按每沿两位
读取和注册复制。合法 N64 的 K 为 12、20、28、36、44 或 52。
末对复制后下一沿释放译码器，保留原结果顺序。下游在复制中
恢复可用时，首读等待复制完成。N64 最大可能额外等待 26 沿。
同沿先处理输入，再送输出对。该配置使用原模型的初始停顿日历，
接入运行时 ready/valid 及任意停顿仍需核对。

取消未收齐的码字时，输入、译码与输出信用及短槽期限一起回退。
已完整复制的结果保持拥有权并继续排在新结果前，真实块/帧 CRC
和 MAC 交付由后级判定。原 MAC 仍最多三个预留，字节上限 2044，
因此解除译码停顿也可能把压力移到交付端。

预算增加 52 位数据、128 位码字标记、64 位时标、7 位游标与
有效位及 256 位最坏额外在途帧状态，共 507 位。复用现有双银行
的两个单读口，保留同一两位交付口，无新增 BRAM 或 DSP。
阵列与算子有值时序已验证，物理布局、Fmax 及跨接口阻塞尚未验证。

独立保留的原候选与前端 Q14 及绝对沿逐项相同。

| 每时钟 35 个候选 | 单帧 MAC，旧→短槽 | 环形 MAC，旧→短槽 | 环形恢复/退化 | 短结果复制 |
| --- | ---: | ---: | ---: | ---: |
| 100 MHz | 0→0 | 0→0 | 0 / 0 | 0 |
| 160 MHz | 15→15 | 18→20 | 2 / 0 | 4 |
| 200 MHz | 15→15 | 19→20 | 2 / 1 | 4 |

200 MHz 原成功的后一帧在 170883 沿用尽 MAC 预留描述符。
因此联合方案继续显式，通用采用门未通过。逐帧真实 CRC、
完整字节对照与旧版冻结回归在 `b1-polar-short-result`。

## 固定和独立业务

固定 324 组含上阶段两个原始集合。父版 indexed 和紧凑原调度的逐字
字段先精确重放。新保留生成 24 组独立业务，混合尾字、长短帧、速率变化
与输出阻塞，逐套在 100/160/200 MHz 与一、两路测试，共 144 组。
4 Msym/s，FT3/4、CRC24/32、九个编码 QPSK/8PSK MCS。表中丢帧是
已知头几何下的译码调度结果。

| 两路业务 | 时钟 MHz | 总帧 | indexed 丢帧 | 紧凑组合丢帧 | 恢复 | 新丢 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 固定 | 100 | 459 | 310 | 195 | 118 | 3 |
| 固定 | 160 | 459 | 255 | 108 | 149 | 2 |
| 固定 | 200 | 459 | 212 | 74 | 138 | 0 |
| 新保留 | 100 | 288 | 265 | 175 | 92 | 2 |
| 新保留 | 160 | 288 | 210 | 90 | 122 | 2 |
| 新保留 | 200 | 288 | 168 | 55 | 114 | 1 |

200 MHz 两路的新保留中，只提前释放丢 57 帧，只抑制后缀丢 151 帧，
组合丢 55 帧并抑制 127 个后缀字。原固定最大帧由丢 18 个字、涉及
15/27 帧收敛到丢 3 个字、涉及 3/27 帧。固定短帧组由 12/144
丢帧降到零。在独立业务的退化例中，第 9 帧末尾两个物理字
占满两槽，第 10 帧首字到达即被拒绝。两个尾字分别要到
538688/541909 沿退休，新首字在 535850 沿到达。
冻结采用门要求零新丢，因此各候选仍为实验，默认路径保持。

原 SHA 的 B1 IQ 重放继续维持 CRC、载荷及符号中心。独立固定的
228 流仍捕获 87/96、整包正确 61/96、观察到零误候选与误交付。
本阶段无需调整量化，历史数值反例和 16 KiB 模块失败保留。
16 MS/s 整链、完整流式接收、全链定点、整机资源和硬件实现能力分别验收。

后续的[有界 B1 帧服务](b1-payload-service.md)已消费实际结果节拍，
检查完整长度、两层 CRC、缺字和 RAM 持有。

冻结证据根下 `payload-polar-ownership` 的 `REPRODUCE.md` 可重放
逐拍 RAM、完整日历及 IQ。输入、判定、源码和 CI 回执均保留。
