# 分离定时所有者与实际采样交接

这是§6.2.1.2接收实现实验，复用§6.3/6.9帧和CRC规则。
`SplitSamplingFrameReplay`把既有独立检测、PI/NCO和查询服务接入实际源历史、
插值、有限归一化和真实头所有者。它消费一次上游已选答案，尚不是未知起点的整链接收机，
不改变默认算法，也没有完成四项接收验收。

## 配置、接口与状态

当前显式实验限制为4Msym/s、SPS4、power30/error32、固定误差年龄0/1/2/3。
普通FT2/3/4 PSK profile沿用各自同步、CRC上下文、合法长度/MCS、导频和编码配置。
限制不能仅通过删除检查扩展；FT1/GFSK和未知厂测编码变体不在这个实验的验证范围。
本阶段归一化格式验证为`linear`；既有`nearest`接口的可构造性不构成本阶段新增验收。

输入仍是已匹配滤波的有限字和已准备的同步缓存。借用同一个512字源、单读/单写端口、
同步缓存和6DSP插值器，不新建整段尾部副本。查询和运输只有一个信用；
检测、PI及归一化各有独立实际时钟服务。除归一化原有四槽外，四种有序消息队列
容量均为`age+2`：检测回执、PI回执、带可见边沿的误差、采样坐标/未来样本需求。

```{mermaid}
flowchart LR
    P[PI/NCO快照 n] --> Q[三边沿查询]
    Q --> S[源历史与实际插值]
    S --> D[功率/TED/除法]
    S --> N[有限归一化]
    D --> E[注册误差 n]
    E --> P
    D --> J[按符号合并回执]
    P --> J
    N --> J
    J --> H[真实头CRC与合法几何]
    H -->|通过后开放实际帧尾| Q
    J --> F[载荷显式功能服务]
```

查询n先捕获PI的稳定坐标，再允许PI应用n-age的注册误差。
同步及FIFO启动阶段用预先规定的零误差，检测从不提前观察未来符号。
PI可以先于已交付符号，因此接收器使用按符号匹配的检测/PI回执；
不能用活跃NCO的最新坐标替换先前符号的采样轨迹，也不在交接时重复运行环路公式。
回执离开队列后仍占有一个已计费的最后交付槽。

头部尚未通过时，查询索引严格小于实际头结束符号；
真实头CRC、合法长度和MCS检查通过后，才开放到该回执给出的实际帧尾。
坏头、非法字段、EOF或资源退出都不重选同步、相位或载波答案。
CRC仅决定可信字段、交付及资源释放。有限头处理保持真实边沿，
载荷残余载波、LLR和译码仍为显式功能停点，完整延迟是`None`。

EOF先排空已经准入的完整符号和已开始的真实头服务；没有所需未来样本的查询不伪造输入。
终止时丢弃未应用误差及前瞻回执，取消插值和头所有者；不继续冲洗PI。
源仅按实际插值依赖退休，再归还未消费后缀。新包创建新上下文。

载荷功能停点没有硬件周期，因此这些数字不是完整包延迟或持续吞吐。

与原串行实现逐值一致。各年龄的实际查询、检测及PI回执与同年龄功能参考逐字比较；
归一化对照同一实际有限格式。这里没有扩大捕获范围，不将三个帧计作未知起点捕获增益。
非零年龄是已单列的算法选择，尚无新RF保留集的默认采用结论。

原36个已查看开发流中29个实际候选再做四年龄回归，两真实依赖环境各116组。

每年龄的22个正确包、7个CRC失败及前级7个漏检保持，正式61/96统计未重跑。

峰值9.751e-5，均在原预算内。这不覆盖原RRC/插值数值反例或新保留集。
两环境128份轨迹的512个NPY数组精确；固定事件中的116个后端可用性标签不同，
其余JSON、状态及帧精确。新模块没有执行新的Rust搜索；标签差异不能冒充数值损失。

继续沿用已有同年龄浮点预算：中心0.001采样、速率0.1ppm、归一化RMS0.0001、峰值0.001。
固定已查看集合用于回归，不能用来重新选择年龄或系数。
原RRC 2.348%大于2%及插值数值反例继续保留，不能由本模块字一致覆盖。

45项针对性测试覆盖三帧型/四年龄、实际字与查询、坏CRC/非法字段、错误上下文、
EOF排空、分块、重复交付、源后缀、有限溢出和异常查询原子准入。
两个真实依赖环境的全量测试条目为4982/4993，其中可选依赖跳过38/5项，

## 计算、存储、端口与失败

| 项目 | 模型成本 | 证据限制 |
|---|---|---|
| 活跃采样乘法银行 | 插值6、检测4、PI4、归一化4，共18DSP | 既有有限位宽分解；不含整个前端、TX、译码及MAC |
| 检测/PI节点寄存器上界 | 2446+2169=4615bit | 已超过原4096bit；宽加法/比较未综合 |
| 查询节点 | 1689bit，实际三边沿，单信用 | 96/97bit坐标与宽比较仍有时序假设 |
| 归一化流水节点 | 默认linear上界7825bit | 四显式槽、一个4DSP银行、两读ROM；非双口RAM证明 |
| 新队列/最后回执/前沿控制 | 年龄0/1/2/3为3914/5165/6412/7663bit | 含槽、tag、指针/计数、可见边沿、峰值及坐标 |
| 含公共运输计数的控制上界 | 6064/7315/8562/9813bit | 全部超过原2048bit；不把逻辑位数当综合FF |
| 原样本历史 | 512字、1R/1W，借用原银行 | 无新增原始RAM或端口；窗口过期仍明确失败 |

每跟踪符号仍执行两次已有插值、一次功率/TED/规范化除法、一次KI/KP和一次归一化，
查询/环路实际微程序的乘加、比较、移位、ROM访问及边沿保存在节点成本和服务记录中。
未减少算法算术量；收益来自有限调度重叠。队列按寄存器/有序多路选择上界计费，
没有共享RAM端口或DSP仲裁收益。初始拟合、持续捕获、RRC及整机预留继续由整机账本单独计费。

持续16MS/s后缀的测试仍出现`history_overflow`，有明确资源丢弃计数和有界占用；
不能记成数据CRC失败或悄悄丢请求。头处理和载荷服务的等待都可能耗尽历史。
局部重叠不证明100/160/200MHz整链承接能力，旧16KiB失败也不改写。
下一步应将源到达、候选窗口、头/载荷期限和下游阻塞纳入同一有限调度，
再决定共享方式或前瞻深度；不能靠增大无限队列解决。

已执行三输入×100/160/200MHz×年龄0/1的18个有限到达对照，
另加三个200MHz/年龄1载荷服务持续阻塞对照。源从选定准备交接后开始持续到达，
不包括此前ADC/RRC/捕获期间；独立派生零背景尾部有单独SHA，原输入未修改。
18个正常对照中，仅FT2年龄1在160/200MHz到达尚未建模的载荷服务，
峰值历史分别359/191字；其余16个在512字上限明确溢出。
三个阻塞对照也均溢出，共19项资源失败保留，不记为算法或CRC失败。
200MHz下FT3/FT4年龄1分别交付221/445个头前缀符号时仍未取得有效头回执，
源已经溢出。下一瓶颈有直接证据指向头处理等待和原始样本保存期限，
不是把局部定时节点II继续缩短便能宣称整链通过。

初版原型的查询计数耗尽和非法地址会先消费查询/退休历史再报错，
三项原输入反例已保存，改成准入预检后再消费，断言和预算未放宽。
初始夹具也保留：FT2 A2不携带B1的MCS字段，B1固定CRC种子不能构造为任意种子；
反例分别使用实际B1字段及合法A2种子/错误LLID上下文。

## 可选的两处注册交接

`compact_query=True`把查询的退休位置与相位取整并行计算。
退休只读整数 cell，当前和中点的分数取整、未来边界和索引保持。
该几何节点由三拍到两拍，仍只有一个查询信用，回执可保持。
`start_stencil_on_reply=True`允许有可用样本时从已注册回执发起
首个既有源 RAM 读。结果仍在下一拍返回。保持单读/单写、同址
延迟、实际未来样本及头部所有权。两个选项默认关闭。
连续源在缓存耗尽时仍明确报告拒绝位置。

| 固定 608 字节例 | 常见间隔/周期 | 两符号合计 | 200 MHz 理想 FIFO 下界/字 |
| --- | --- | ---: | ---: |
| 基线 | 49、53 | 102 | 139 |
| 仅并行几何退休 | 48、53 | 101 | 115 |
| 仅回执同拍发读 | 48、53 | 101 | 115 |
| 两者合用 | 47、53 | 100 | 93 |

三个既有合成帧的 200 MHz FIFO 下界分别从 107/122/139 到 91/93/93，
每字 55 位。所有归一化字一致。该下界允许使用完整轨迹选择启动拍、
同拍数据直通，且不含端口和控制。后级实际 36 位后缀 RAM 另有所有权。
头回执处仍有约 4583 拍的符号间隙，短周期与长周期间隔仍交替。
100/160 MHz 保留真实历史溢出。

新对照使用六个合成帧，另有一个独立 EOF 派生。固定两臂在可暂停与
100/160/200 MHz 的已滤波源边沿下比较，共 26 组源条件。
共享前缀逐字相同，CRC、截断和下游结果一致。在 200 MHz，
三个合法完整帧到达载荷屏障。将其字按固定节拍另行交付后级，
三帧都通过头/数据 CRC 并完整交付。坏头、坏数据 CRC 和实际截断
仍失败。原计划裁掉 400 个采集尾样本只缩短了静默，其交付结果
保留，独立生成真正少 100 个符号的 EOF 反例。100/160 MHz
共 12 个历史溢出保持。结果来自选定已匹配滤波的字、源准备后
的连续写入及单独的 B1 重放。

沿用 512 字、1R1W 和既有 18 DSP 估算。两处组合路径不新增字 RAM、
DSP、端口或寄存预算，未计中间回执寄存节省。整数 cell 的比较/
减一与相位取整同拍，以及已注册几何到 overlap、地址、范围、同址
仲裁与 RAM 命令同拍，均为未综合的时序假设。
运行本阶段 `tests/test_timing_query_flow.py` 与
`tests/test_split_sampling_replay.py`。转录和复现位于冻结目录
`b1-sampling-edges`。跨候选的实时交接、输出缓冲与完整 16 MS/s
仍待验收。
