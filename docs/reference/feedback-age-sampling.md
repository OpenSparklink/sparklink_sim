# 固定误差年龄与真实采样闭环

这是§6.2.1.2波形的接收实现实验，帧与CRC复用§6.3/6.9路径，
不是标准规定的环路或默认接收机。此前的[误差年龄功能参考](feedback-error-age.md)
现在接入实际源历史、插值和严格帧消费；四项接收验收仍分别开放。

## 接口和状态

`FeedbackAgeFrameReplay(profile, prepared, error_age=..., finite=..., ...)`
只消费上游已经选定的一次同步答案。必须显式指定固定年龄0/1/2/3，
有限字臂还须指定`TimingWordFormat`；浮点臂拒绝被忽略的有限字格式。
非法年龄、格式或所有权在消费准备结果前退出。没有真值、期待载荷或CRC择优接口。

复用同一512字源、同步缓存和6DSP插值器，真实头CRC通过后才读取合法帧长/MCS，
载荷沿用同一解析回执。包结束、坏头、非法长度或EOF均释放误差队列，
不在包后继续应用残余误差；新包创建新实例。有限字接收器只创建一个规范定时状态，
明确拒绝将带FIFO所有者交给旧的单状态周期服务。

`step()`依然在PI、归一化、头或载荷计算处等待显式功能服务。
功能服务一旦执行，完整周期证据即无效；完整延迟为`None`。输入是已匹配滤波的字，
不是连续ADC；可暂停回放也不是持续16MS/s证明。

## 冻结对照

保持原固定FIFO、Gardner/PI、插值、载波、门限和解析参数，只接通功能采样路径。
先冻结原预算，再用此前36个开发流的原SHA输入：通过只读观察器记录真实候选的
起点、粗CFO、同步符号及raw/tone路径，不从解析后的CFO反推粗估计，也不按CRC重选。
观察器逐字段和轨迹复现原零年龄接收。

前端顺序为因果RRC后已有单音抑制。记录实际42个EOF冲洗采样，不增加尾部。
流接口的起点已补偿40采样FIR延迟；源字坐标明确加回该延迟。
两臂共同使用既有19+19+8主机归一化表示和同一有限初始拟合；这不验证ADC/RRC定点链。

29个真实候选（含7个数据CRC失败）×4年龄，116组同年龄浮点/有限字对照。
有限字为power30/error32，严格检查头CRC、数据CRC、长度、MCS及完整载荷；
全部字段一致、零原成功丢失。七个没有候选的原包仍是漏检，不因这个模块只接收候选而消失。
每年龄仍29/36捕获、22/36完整，接收率增益为0。原正式61/96压力计数未重跑或改写。

| 年龄 | 最大中心差/采样 | 最大速率差/ppm | 归一化RMS | 归一化峰值 |
|---|---|---|---|---|
| 0 | 3.059e-6 | 0.002344 | 9.278e-7 | 9.903e-6 |
| 1 | 2.958e-6 | 0.002157 | 1.426e-6 | 1.145e-5 |
| 2 | 4.457e-6 | 0.003507 | 1.889e-6 | 4.566e-5 |
| 3 | 3.498e-6 | 0.002727 | 9.640e-7 | 1.190e-5 |
| 原预定义预算 | 0.001 | 0.1 | 0.0001 | 0.001 |

这是同年龄、同插值器的有限字增量，不是绝对定时真值误差，
也不覆盖不同年龄间的算法轨迹变化或旧RRC/插值数值失败。
两种真实依赖环境各116组、232份轨迹与冻结原型精确一致。
新定时/FIFO模型均为Python；Rust环境仅使用已有可用加速，不宣称新增Rust实现。
年龄0还与原选定浮点/字回放逐值一致。

上游六个负流合计44663采样（约2.79ms）没有候选或交付；后级未扩大搜索。
重复年龄及后端不增加独立观察量，也不能据此推断所有环境零误检。
这是已查看开发集，不是新保留集；尚未决定采用任何年龄。

## 成本和边界

| 项目 | 已有或新增成本 | 证据范围 |
|---|---|---|
| 源/同步缓存/插值 | 借用已有512字历史及6DSP服务 | 实际有限运输；没有另建原始尾部副本 |
| 功能定时状态 | 一个规范状态，FIFO等新增36/71/106/141bit | 年龄0/1/2/3；逻辑位数，不是已综合FF数 |
| FIFO活动 | 每跟踪符号读写age个误差字、固定移位线 | 不把逻辑pop/push当成单RAM端口 |
| 分离检测/PI的上下文、仲裁、DSP和端口 | 未建模 | 不填零、不据此宣称流水共享收益 |
| 完整II、延迟、FIFO积压、Fmax | 未验证 | 不是98边沿除以并行度 |

原单所有者短前缀仍98边沿，超过200MHz下4Msym/s的50边沿预算。
当前证据只关闭这个组件的同年龄采样数值对照，下一步需实现值随边沿传递的
检测与PI/NCO独立所有者，实际验证反馈延迟、有限查询前瞻、DSP冲突和源历史期限。
之前24个连续输入历史溢出及旧16KiB/4096/2048预算失败继续保留。

残余载波、软解映射/LLR、载荷译码和连续捕获交接仍有浮点或调度缺口。
FT1/GFSK、全链定点、整机资源及完整16MS/s均未验收；无新增综合或布局布线证据。

## 复核与失败

30项针对性测试覆盖实际严格帧、坏头/坏数据/非法字段、EOF、分块、所有权和独立FIFO/PI顺序。
两依赖环境全量4863/4874项全部通过，原身份全部保留，覆盖率均93.56%；
四片均低于原120秒门，90.1%覆盖率门不变。

工程内运行`PYTHONPATH=src uv run pytest tests/test_feedback_timing_replay.py -q`。
外部冻结目录`feedback-age-closed-loop`保存输入SHA关联、实际候选、全部轨迹、
同年龄字段/数值对照及失败。`ALL-FAILURE-ASSOCIATIONS.json`关联原7漏检和各臂7CRC失败；
相同失败在多个对照重复出现，不算多个独立RF样本。
没有新增真值重放依据时，这些失败仍归为证据不足，不能断言理论不可恢复。

针对性测试保留初版夹具失败：B1没有A2的empty标志，改用真实A2非法长度反例；
EOF检查改比有限状态快照，而不是深拷贝对象身份。算法、期待载荷及数值预算未改变。
