# 实验：细搜索完成后的已消费候选释放

本实验用普通 FT2/3/4、4 Msym/s、16 MS/s、MCS8/12。帧、导频和 CRC 合同见
[标准来源](standard-sources.md)。在[细搜索与回放重叠](fine-frame-overlap.md)
的一个帧所有者和一个细搜索之间，已就绪结果可以继续等待交接。若上一沿的消费
前沿已覆盖整个候选窗，已完成的细搜索结果到下一沿释放自身选中缓存与候选窗。

检查只读取上一沿实际消费的源坐标。预细搜比较优先，偶数沿可给已完成的细搜
结果，剩余比较机会给待处理 FIFO 的队首。待完成的细搜索不会取消，计算周期
仍计入。帧所有者继续处理原帧。当前输入纪元中止会清掉比较结果及借用；
没有从头/数据 CRC、期待载荷或恢复结论反推调度。

使用现有 63 位注册比较器和两个源访问端口。增加一位被比较所有者标志及至多
64 位操作数选择逻辑。没有另建队列或硬件遥测计数器。原有 4096 字历史、三个
候选窗、1024 字私有历史和一份选中缓存均计入。测试中的逐候选可观察记录
属于主机诊断。本模块既有 17 块 BRAM36 子集估算不覆盖其他整机存储。

采用门在新开发前冻结。比较未触及的原参考、合法尾界和注册排队串行方案，以及
已经查看的重叠实验。保持原数值预算、误检和峰值资源限制。新保留集仅在开发和
全部固定回归通过后生成。

```sh
PYTHONPATH=.:src:scripts uv run --frozen python scripts/model_completed_fine_retirement.py \
  --role fixed-regression --inputs /path/to/inputs.json --baseline /path/to/results.json \
  --output /tmp/completed-fine-retirement
```

冻结复查使用原 IQ 和串行基线。退出码 1 是采用门拒绝。

计算量和已确认的载荷语义问题。
