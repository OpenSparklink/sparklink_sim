# 实际归一化字到有限头部判决

## 接口与采用边界

本组件补齐[整数头服务](head-word-gate.md)之前的硬解映射和收集状态。
输入来自既有 `SymbolNormalizationService` 的实际输出，格式为
22 位有符号实部、22 位有符号虚部和 11 位共同二进制指数，合计 **55 位**。
不把浮点符号重新量化后称为实际字流，不重新选择同步、定时、载波或星座相位。
标准依据为 TXS-10002-2025 §6.2.1.2 的星座与交替旋转、§6.4 的控制字段；
CRC、B1 线上长度和零数据语义沿用已核对的原文与头服务。

`hard_psk_word(word, modulation, symbol_index)` 支持 BPSK/QPSK 头，
`symbol_index` 从本帧同步首符号开始，包含所有导频，不在字段边界重置。
共同正比例因子不改变硬判决的星座排序，所以不需要指数对齐、乘法、开方或除法。
这不适用于软 LLR 幅度，也没有实现 8PSK 载荷硬化。

| 调制与线上索引 | 精确判决投影 |
|---|---|
| BPSK 偶数 / 奇数 | `imag` / `real`，负数为比特 1 |
| QPSK 偶数 | 实、虚符号位分别决定 Gray 标签的低、高位 |
| QPSK 奇数 | `real-imag`、`real+imag` 的符号位决定标签低、高位 |

22 位实、虚相加的范围为 [-4194304, 4194302]，相减为 [-4194303, 4194303]，
都使用 23 位有符号寄存器，无舍入或饱和。输入格式越界、非规范零字、非法索引明确拒绝。
零能量和数学平局按最大精确投影中的最小数值 Gray 标签判决，另有标志；
它们没有被当作可靠信息或 CRC 成功。原浮点距离计算在数学平局上可能因 ulp 选择不同标签，
这是明确的算法边界变化，不能藏在数值容差中。

## 注册状态与端口

`HardPSKWordService` 一次拥有一个输入，先注册 23 位投影，再注册判决。
结果两边沿后可见，保持至 `take()`；转移边沿不复用为新请求，连续无阻塞 II=3。
有界输入信用、输出等待、取消、复位及 64 位计数溢出都有显式行为。

`HeaderFromWordsService` 一次拥有一个头。它只接收同步尾到控制尾的连续线上索引，
检查重复、缺失或错字段输入；导频仍参与旋转索引，然后按实际控制字段位置丢弃。
64/256 位收集缓冲采用 FF 位/双位写使能与并行读总线，选择网络不视为免费 RAM 端口。
全部位写完后才把该唯一头交给原有限解扰、SSC、真实 CRC、字段许可与几何服务。
坏头不读取字段，不做 CRC 引导的重试；有效头回执只属于本帧。

没有输入 FIFO、原始样本历史或第二套接收路径。忙时返回 `False` 并计数，
调用者必须保留尚未接受的字；本接口没有授权 ADC 停顿。
EOF 会排空已接收但未提交的字，不足一头返回 `truncated_header`，CRC 为 null；
已齐备头仍完成真实校验。上下文完成前不能切到下一包，结果转移后保留一边沿交接。
包内跟踪、候选、CRC 上下文和载荷处理参数均未改动。

| 组合逻辑容量估算 | A2 dense / depth-parity | B1 dense / depth-parity |
|---|---:|---:|
| 原有限头/SSC/几何加本组件 | 20247 / 20255 bit | 44129 / 44133 bit |
| 本次新增状态 | 1863 / 1863 bit | 2055 / 2055 bit |
| RAMB18 等价 | 3 / 5 | 6 / 6 |
| 保守 BRAM36 站点上界 | 3 / 5 | 4 / 5 |
| 新增 DSP、原始样本 RAM | 0 / 0 | 0 / 0 |

新增硬判决本身为 895 bit，其中包括 640 bit 统计和 64 bit 周期计数；
其余为收集缓冲、索引、导频/上下文、保持/交接状态和额外统计。
QPSK 奇数符号最多需要两个并行 23 位加/减法与两个符号测试。
头服务原有 SSC RAM、几何和 CRC 已包含在组合容量，整机账本不能重复相加。
前瞻组件门为新增不超过 3072 逻辑 bit、零新增 DSP/BRAM；
这是组件选型约束，未批准新的整机预算，旧 16 KiB 和数值失败仍失败。
完整 LUT、FF、布线及 Fmax 没有综合证据，不以逻辑 bit 或估算 DSP 替代它们。

## 验证与复现

  --output /tmp/hard-head-development --split development

  --output /tmp/hard-head-validation --split validation \

输出目录必须不存在。新开发/保留组合事先声明于 `tests/data/hard_header_policy.json`，
改变载荷、帧型、MCS、包长、CRC、加扰、导频和信道组合，不只换随机种子。
源码、参数、预算和采用规则在打开保留输入前核对，之后该集合只作固定回归。

期待载荷、真值和 CRC 不参与任何前端选择或两种布局间的结果选择。

独立整数参考枚举所有标签的点积，覆盖全尾数范围、极端指数、零字及平局。
浮点比较单独使用良好尺度域；非平局要求零位误差，数学平局差异单列。
本次发送脉冲/角度参考独立，编码比特仍共享既有实现，不能作为唯一互通证据。
两种头布局分别从同一字流运行；参考载荷续解只消费该头的真实 CRC 回执，
仍属未计周期的功能边界。字分组与可用边沿分别记录，不把主机批量输入变成无限硬件队列。

## 尚未关闭的验收

本日历是实际注册头字的因果重放；上游仍是整段差分最大值测试夹具，
不是持续输入捕获控制器。归一化输出的可用边沿来自原有限串行服务，
原每符号 144 周期组合瓶颈并未被 II=3 的头判决解决。
100/160/200 MHz 下 4 Msym/s 分别只有 25/40/50 周期每符号，
硬判决组件的 II 小于它们，但这不是整链吞吐证明。

头后译码等待期间仍需保存实际后续输入、处理历史到期并交接回放；
这些存储、端口、调度和解码工作不能填零周期。本组件没有新增隐藏尾部缓存。
完整流式、全链定点、整机资源、连续 16 MS/s 四项验收继续分别开放，
FT1/GFSK、A3 字头、载荷软 LLR/译码与整链实时调度仍是独立缺口。
