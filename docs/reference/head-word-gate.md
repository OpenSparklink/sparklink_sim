# 真实头CRC后的有限字段与帧消费

## 接口与范围

`PSKReceiveProfile.head_backend`默认`reference`保持不变。
显式`word-dense`或`word-depth-parity`把同一已选头的硬位送入有限头服务：
解扰→整数SSC→真实CRC→字段许可检查→[有限帧几何](head-length-words.md)。
普通FT2 A2+LQI使用N64/K40、CRC12及实际同步上下文；普通FT3/4 B1使用
N256/K51、CRC24B及LLID。字段与浮点解析器共享不可变的位布局表。
标准B1原始线上长度包括数据CRC，不能换成旧原型的信息长度输入。

A3、WS63厂测、A2无LQI明确拒绝word配置；它们继续使用既有参考路径。
本项没有实现头部软解映射，也没有把当前4Msym/s、SPS4实验扩成任意配置支持。
前端捕获、同步、样条及Gardner/PI仍复用已有选择；厂测常量不成为普通默认值。
原始IQ不修改，未知厂测编码前缀仍未知。

头CRC失败时不读取字段，不启动几何或载荷译码。CRC通过后先检查MCS：
MCS15缺少重传上下文即拒绝，不把CBG位图解释为长度。非法长度同样停止。
合法头回执只属于当前已选帧，载荷阶段复用它，不再译头或尝试另一同步/载波答案。
头CRC、数据CRC、长度、MCS与完整载荷分别报告；数据CRC失败不会产生MAC交付。

真实CRC正确的零长度B1只产生`valid_empty_control`，数据CRC为null且无MAC载荷。
帧尾一经可信头确定，流式接收器先锁存已消费范围，再发立即完成事件。
这修复了实验无数据导频配置中零控制帧只抑制同步尾、未抑制已消费控制尾的缺陷。
原FT3/4两个反例保留；导频8的原对照继续通过。该修复不是捕获增益或新增标准模式。

## 有限状态、端口与数值

服务输入是一次并行64/256位硬判决字，**不是ADC逐采样接口**。
一次只拥有一个头，无请求FIFO；忙时显式拒绝并计数，结果保持至`take()`。
`abort/reset`、输出等待及64位统计溢出均有明确行为。
子服务只消费上一注册边沿已就绪的结果，不借用同边沿新结果。

解扰每边沿处理一位，保留7位LFSR。SSC复用已验证的10位精确min-sum及零值语义，
输入可靠度固定为硬位±1；这不代表模拟LLR已经定点化。CRC按真实上下文逐位递推，
再逐位比较接收校验位。CRC成功后每边沿读取一个字段位。
profile预编译合法长度上下限；数据运行时使用三个11位比较器和一个4位MCS许可选择器，
16槽中13槽表示普通MCS、3槽为常量零。导出长度由有限几何的实际24位ALU计算。

整数头/字段/几何无舍入或饱和，合法范围内与参考要求整数零差异；越界抛模型错误。
浮点硬判决、载波、数据LLR/译码接口及整链反馈仍有未闭合节点，不能称全链定点完成。

| 组件容量 | A2 dense / depth-parity | B1 dense / depth-parity |
|---|---:|---:|
| 总逻辑状态与常量 | 18384 / 18392 bit | 42074 / 42078 bit |
| SSC物理RAMB18等价 | 3 / 5 | 6 / 6 |
| SSC保守BRAM36站点上界 | 3 / 5 | 4 / 5 |
| 新独立DSP | 0 / 0 | 0 / 0 |

BRAM列计实际宽深与银行碎片，不能按逻辑字节向上取整代替。
几何使用分布式LUT/FF，完整LUT、FF、布线/Fmax仍未知；上述DSP为该组件估算。
头服务包含原SSC和几何，整机求和时不能再把两个子节点重复加入。

源码中冻结的组件候选容量门为98304逻辑bit、8个RAMB18等价及7个BRAM36站点上界。
这是实验组件的候选约束，不是已批准整机预算或综合资源通过；原捕获16KiB失败不改写。

额外状态包括并行输入、译后字、字段、保持回执、CRC、LFSR、索引、控制和统计。
256位profile预留中明确分配237位，其中80位字段描述ROM已经包含，不能重复计费；
仍有19位预留。保持回执另计11位信息长度和1位数据CRC存在标志。
该预留只属于头/几何节点；载荷CRC种子、载波/LLR配置和包调度上下文另计，尚未闭合。
1位数据读取多路器、输入位写选择器、CRC门及三个长度比较器另列操作上界，
不能把它们当成免费控制。参数、指令ROM和FF双读单写端口见几何账本。

在本次正例实际服务中，dense为1837–5920边沿，depth-parity为1579–4450边沿。
这是已执行样本范围，不是所有配置的全局最坏证明。100/160/200MHz只是换算假设：
例如5920边沿为59.2/37/29.6us，4450边沿为44.5/27.8125/22.25us。
还不包含上游解映射、候选保存、载波、载荷及译码服务，相关周期保留null。
主机按有界10000步排空头节点是功能对照，不是连续输入时的真实调度。

## 冻结实验与能力边界

在现有已查看集合之外，预先声明两组各6个组合，改变载荷、FT2/3/4、MCS、长度、
CRC24/32、加扰、导频0/4/8/16、幅度、CFO/SRO、分数起点和突发位置。
先冻结源码、参数、容差与采用规则，再打开独立新保留集；它现在只作固定回归。
独立连续脉冲发送参考使用40/48/64符号前导，发射比特编码仍共享，因此不作为唯一标准互通依据。
真值只用于信道构造和事后误差统计，不进入实际接收选择。

| 集合 | 参考 / dense / depth-parity完整正确 | 原成功损失 | 接收增益 |
|---|---:|---:|---:|
| 新开发6包 | 5 / 5 / 5 | 0 | 0 |
| 冻结新保留6包 | 5 / 5 / 5 | 0 | 0 |

同一实际Python或Rust环境内，整段、固定1/32/257轮换和随机1–513分块的帧判定、
完整字节及轨迹按冻结容差比较：符号1e-12、中心1e-10采样、速率1e-8ppm。
Rust环境是实际加载的既有载波/定时/CRC/Polar后端；**没有Rust版头部word模型**。

两个失败全部保留：开发FT2未编码突发包117/232比特错误；保留FT2编码突发包128/328比特错误。
这是实际已选载波方法的事后误码重放，错误位没有用于重试或选择答案。
不能据此断言理论不可恢复；头CRC通过也不能代替数据CRC或完整载荷。
原61/96压力集没有重新计数，不把新集合正确率接到该统计上。

每组负例包含噪声、持续单音、错误同步字和突发各16384采样，共65536采样，
相当于16MS/s的4.096ms。三条路径均零MAC交付；相同IQ在不同路径/后端重复播放
不增加独立观察样本量。这不证明全环境零误检。
六个原SHA标准长度向量、动态B1 MCS、坏CRC/错误种子/非法长度/EOF及零控制另作固定回归。
按原始冻结元数据与SHA读取6份WS63 A3原始采集及8份SRO派生，整段/固定4096/随机1–8192
分别在父版本和当前版本、实际Python/Rust环境重放。6原始采集64候选中63数据CRC通过、
1个EOF载荷截断；8派生84候选均数据CRC通过。帧结果、可用时刻及四条采样轨迹逐元素相同。
原始6×1048576采样约0.393216s，派生和重复后端不增加独立RF观察时长。
真实IQ没有精确定时/原始SRO真值，不把判决残差当真实误差；该对照只验证参考A3未退化。

## 复现与验收归属

```sh
PYTHONPATH=src uv run --frozen python -m scripts.model_header_words --split development --output /tmp/head-dev-new
PYTHONPATH=src uv run --frozen python -m scripts.model_header_words --split validation --freeze /tmp/head-dev-new/freeze.json --output /tmp/head-fixed-regression-new
```

输出目录必须不存在，源码/冻结不匹配时在创建保留输入前报错。两命令构成一次完整复现；
已经查看的原保留样本不会因为重新执行命令而成为新保留集。
每个正/负输入、候选、头与数据CRC、轨迹、失败及输入SHA均保存。额外误码/真值诊断
与完整JSON保存在冻结证据根的`head-word-integration-standard`，不改变接收选择。

本项增加“已选头硬位→真实CRC→合法几何→同一帧消费”的功能/整数/组件周期证据。
完整流式结构、全链定点、整机资源、连续16MS/s四项验收仍各自未通过。
word-full12-c18原2.348%＞2%、插值误差、旧16KiB和定时节点预算失败继续保留。
FT1/GFSK、全配置合法性、真实细搜索生产者、载荷/译码调度与实际综合/时序仍是独立缺口。
