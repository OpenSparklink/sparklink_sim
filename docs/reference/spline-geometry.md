# 准备后的有限几何等待（SYS-C2B）

本阶段在[完整增长功率复用](spline-power.md)之后加入显式`defer_all_future=True`研究配置。
默认仍为False，不改变接收器默认同步、载波或CRC选择；对应标准§6.2.3的同步接收实现。

## 证明条件与有限控制

对每个整数粗峰`p`，原网格为`8p-4..8p+4`，位置单位为1/8采样。
同步符号数为`L`，窗口长度为`N`，符号间隔4采样，最低起点为`m`，未来需求为`h`。
合法位置满足`start>=m`和`start+32(L-1)<8(N-1)`。
因此该粗峰的合法位置是闭区间：

```text
lo = max(8p-4, m)
hi = min(8p+4, 8(N-1)-32(L-1)-1)
ready_upper = 8(N-1)-32(L-1)-h
```

区间非空时，存在就绪位置等价于`lo<=ready_upper`。
只有至少一个合法位置且所有粗峰均没有就绪位置，才返回`geometry_wait`。
任何一个位置就绪都会执行原全部评分；即使评分最大值最终仍需未来样本，也不改挑其他候选。
此规则没有改动位置、候选数、相位网格、门限或原最大值等待条件。

控制器至多检查两个粗峰，按17位有符号加减/比较和5位计数逐操作执行，
移位是固定布线，不使用除法、开方或数据相关搜索。单峰18周期、两个有效峰30周期，研究上限32。
独立枚举核对空集、严格末端、就绪等号、极值、部分就绪和全部等待；
不能把1/8网格或区间证明当成真实定时精度。

## 必须先完成准备与拒绝

全部样条准备、指数对齐及饱和检查先执行。准备饱和仍按原结果拒绝，不能因已知将等待而隐藏数值失败。
几何等待不计算分数，不生成最佳相位或起点，返回`best=None`、`numerical_pass=None`、
`scores_evaluated=0`。没有合法位置另记无候选，不把空集当作等待。
保留基线完整评分供诊断：等待路径的分数误差是未评价，不能写成零或数值通过。
只对实际完成评分的窗口比较所有候选分数、采样、排序与选择。

`FineService`新增`geometry_wait`且必须`start_tick=None`；原`needs_future`仍表示评分后已知最大值需要未来。
七个状态仍容纳于3位状态码，描述符448bit不变，不能使用无效起点推断定时或交付包。
搬运层新增一个64bit等待计数器，测量模式统计预留10→11项；这一成本也显式反映在默认成本报告中。

## 状态与端口

| 新增项 | bit |
|---|---:|
| 三个17位范围寄存器 | 51 |
| 三个17位区间工作寄存器 | 51 |
| 合法位置/标志/峰索引 | 10 |
| 结果计数与状态预留 | 6 |
| 节点增量 | 118（上限128） |
| 搬运等待统计增量 | 64 |

77个活动位宽监视器仍放入原80×8bit预留，不免费增设银行。
无新增DSP、样本缓存、队列或RAM端口；复用既有ALU32，几何与评分串行执行。
控制LUT/FF、前导位监视更新及200MHz时序未综合，状态位数不是总资源。
默认节点微轨迹保持原SHA，成本报告新增结构标志及64bit运输统计，不能说所有元数据/成本不变。

## 固定回归与边界

冻结规则和预算后，开发与独立验证各8个新节点例，变化窗口、模板、粗峰、起点限制、
未来需求、幅度构造及指数；不是只换随机种子，也不是新的RF保留集。
另保留原饱和反例。实际30窗来源与原功率节点微轨迹SHA冻结，原输入不变。

| 固定30窗 | 功率复用 | 再加几何等待 |
|---|---:|---:|
| 总周期 | 3872765 | 2805974 |
| 实际评分窗口 | 30 | 19 |
| 未评分、明确等待 | 0 | 11 |
| 已完成评分的差异 | — | 全部分数/采样/选择相同 |
| 100/160/200MHz完成请求 | 28 | 28 |
| 各时钟队列丢弃 | 2 | 2 |
| 各时钟待确认结果历史缺口 | 17 | 17 |

周期减少27.55%，相对最初串行节点约32.87%；没有新增正式捕获或整包恢复。
200MHz下固定请求的最大必要历史34272→17440点，直接双路TDP投影136→72BRAM。
仍需基础工程73BRAM、拥有槽、译码/TX/MAC等，不能将该投影视为整机通过。
就绪窗口本身仍需原长服务；双峰和密集请求的最坏工作量未因等待捷径消失。

本阶段重放原开放环请求，早返回可能改变真实异步链的后续请求到达率；
尚未证明闭环捕获、相干确认、包内回放/译码或完整连续16MS/s。
旧2%/16KiB、载荷CRC/截断和其它数值失败沿父索引保留；不以等待替代原数值验收。

## 复现

先按[捕获窗口命令](capture-fine-integration.md)生成输入，预期退出1；随后运行：

```sh
PYTHONPATH=src uv run --frozen --no-sync python scripts/model_spline_geometry.py \
  --capture-root /tmp/capture-fine-repro --output /tmp/spline-geometry-repro
```

输出目录必须不存在，预期退出1表示整链未验收。保存逐区间/操作、未评分原因、完整基线、
全部已评分候选、饱和拒绝、源SHA、有限日历和资源丢弃；两个实际后端环境均验证。
新增节点本身是Python整数结构/周期模型，不是新的Rust/RTL实现或墙钟加速声明。
