# 跨符号原始四字暂存

本结构对应§6.2.1.2接收实现，调制/帧/CRC标准语义不变。显式
`RetainedStencilFrameReplay`继承`PowerTEDFrameReplay`，限普通FT2/3/4、
4Msym/s SPS4及父类已验证配置。默认接收、厂测新字路径和FT1不因此扩大支持。

## 样本所有权与准入

一个符号最后的当前中心查询发出后，保留原4×46bit原始字寄存器和64bit起址。
下一注册NCO查询先计算中点窗口地址。只有前向连续交集构成新窗口前缀时复用：
差值d在0至3时复用4−d字；倒退或间隔不相交时正常读取。新相位仍执行原插值，
不能复用上一相位的插值结果，更不依据CRC、期待载荷或真值选择路径。

独立字典地址参考验证64bit地址、窗口独占末端和46bit不透明数据。
四字末端、统计计数和查询身份在消费查询/退休源索引之前检查；溢出明确抛错，
查询和所有控制/整数状态保持，可显式中止。原型曾先消费查询再检查计数，
该失败及修复前后快照保留在外部证据，不能用异常已抛出掩盖部分提交。

跨块沿用同一寄存器/源索引；跨包新实例，不保存上一包缓存。
坏头/非法长度不消费未知载荷；真实头CRC通过后由原几何决定合法帧尾。
EOF或资源退出排空/清除暂存、核和源请求，未做数据CRC为null，不交付MAC。
载荷off-clock服务仍是显式停点；此时源所有权尚不能无条件交给下一捕获。

## 成本与周期假设

| 项目 | 增量或上界 |
|---|---|
| 寄存状态 | 新64bit统计，已计入公共控制；复用原184bit原始字及64bit起址 |
| DSP、源RAM、源端口 | 均无新增；沿用1R1W和一个注册查询信用 |
| 地址与窗口保护 | 最多两次投影、4个65bit末端加法/进位保护、2个65bit首址减法 |
| 范围与计数 | 2个65bit差值、4个65bit比较、2个65bit计数加法和1个64bit身份比较 |
| 压紧选择 | 最多368个mux2；不计组合逻辑共享收益 |
| 原始读取通用上界 | 仍8字/符号；6→4只是已有连续前缀观测 |
| 额外流水边沿 | 当前模型假设0，置于已有NCO边沿；尚无组合时序证据 |

同一暂存不能免费借给细搜索、其他包或TX。新增地址检查和mux有实际逻辑成本；
没有LUT/FF或Fmax综合结论。若需增加流水，可能抵消所观测2边沿收益。
[整机账本](system-feasibility.md)保留译码/TX/实时MAC/接口与旧预算失败，不批准整机扩容。

固定已选输入的外部原型：短连续后缀每符号源读6→4，两个除法模式周期
116/100→114/98（100/160/200MHz各观察8个相邻周期）；此前初始化源可暂停，
不含ADC、RRC、捕获或完整载荷，不能作为最坏整链吞吐。98仍大于200MHz下50周期。

## 复核方法与采用规则

先执行96个新地址开发组合及9个已查看帧、两布局和三种分组，冻结源码/政策，
再执行112个独立地址验证组合。地址验证不是新RF保留集；所有波形仅作固定回归。
字、环路状态、帧判定、MAC内容和采样轨迹预算均为零差异；新控制≤128bit、
DSP/源RAM/端口零新增，历史512字不变。算法、参数、预算和采用规则变化会拒绝验证。

```sh
PYTHONPATH=src:scripts uv run --frozen python -m scripts.model_retained_stencil --output /tmp/stencil-dev
PYTHONPATH=src:scripts uv run --frozen python -m scripts.model_retained_stencil --freeze /tmp/stencil-dev/freeze.json --output /tmp/stencil-val
```

使用新目录。预期退出1须同时核对完整model.json、组件断言及24项连续源失败；
导入异常、空结果、缺制品不能计为预期资源失败。CI保存输出和日志。
真实Python/Rust环境分别验证；字模型本身只有Python实现，不能宣称Rust版字通路。
原RRC2.34835%＞2%、插值超预算、4096/2048/16KiB和连续历史溢出均保留；
四项总门、正式61/96压力计数及接收率增益不因结构复用改写。

## 当前集成观测

纯Python/Rust环境全量4785/4796项，原身份均保留；覆盖率93.51%/93.53%。
四互斥片分别耗时63.369/60.501/45.766/61.101秒与52.749/53.496/41.367/58.653秒，
120秒和90.1%门不变。实际shell选择器与覆盖率参数集合一致，七个实际模块入口help通过。
严格文档检查与远端CI状态分开记录，局部通过不意味着实际硬件通过。

两环境96/112地址节点精确，验证集8个越界组合明确拒绝；开发54次固定帧逐字段、
整数状态、采样轨迹、源后缀和MAC内容一致，零新增接收收益/退化。
129份开发NPZ的所有NPY成员逐字节相同，33份短前缀JSON也逐字节相同；
仅98个开发后端标签及2个验证后端标签不同，字模型本身没有Rust实现。
资源24次仍全部有界history_overflow，不能以组件精确覆盖这些失败。
独立地址验证不是独立RF保留集，未据此重新计正式61/96或宣称全环境零误检。
