# 同步区载波初始化的有界相干实验（RX-INIT4）

目标是分离同步载波初始化问题，不更换同步统计/网格、插值、Gardner/PI或载荷译码。
本阶段只提供显式模型和实验工具，主接收器及MAC默认路径保持原实现。
依据§6.2.1.2、§6.2.3.2的实际已知同步模板；优化器和下述预算都是实现选择，
不是标准强制算法或合格限值。标准版本/SHA见[来源记录](standard-sources.md)。

## 实际基线与候选

当前主接收器在差分CFO和Q确认后，重新用局部四点插值取得同步符号，
对补偿后的相位解缠并线性拟合，得到包内初始频率/相位。
不能把最终初始载波估计误认为直接等于差分相关相角。
旧`wrong-sync-1-2`诊断中，实际定时加真值CFO使头CRC通过，但轨迹只有65符号，
不能由该部分对照宣称整包恢复；详见[失败对照](rx-failure-controls.md)。

候选在**原Q0.45确认通过后**才运行，种子仍为原差分CFO。
令`r[k]=y[k]conj(s[k])`、`t=k−(N−1)/2`，每轮计算：

```
z[k] = r[k] exp(-jωk)
A=Σz, B=Σtz, C=Σt²z
g=2 Im(B conj(A)), h=2(|B|²−Re(C conj(A)))
Δω=clip(-g/h, -π/N, π/N)
```

只在`h < −1e−12 Ey Es (N−1)²`时更新，其他情况保持当前频率。
固定一次或两次更新，最后以`angle(Σr exp(-jωk))`初始化相位，原平均幅度增益不变。
频率按符号率周期回绕，零输入/零相干和明确不初始化。
没有CRC重试、期待载荷、真值起点、另一相位或单音路径选择。

输入以最大实/虚分量归一化，控制浮点矩动态范围；实部和虚部分别除法，
避免NumPy复数倒数先溢出而把极小输入标为“初始化成功但NaN”。
首次原型的该失败及修复前源码/日志保留。这是实验模型缺陷，不是已修复的生产接收缺陷。
单位模板验证、矩能量和零判定改为显式平方量，不隐藏复数绝对值开方成本。

新开发152流含64个合法包、5061578采样；112负例4657308采样，
在16MS/s对应约291.1ms。各臂均无负例候选/交付，仅为有限观察。

| 初始化 | 捕获/64 | 完整正确/64 | 坏头 | 坏数据CRC | 原成功丢失 |

| 原相位解缠/直线拟合 | 59 | 41 | 1 | 17 | — |

已匹配原采样中心/定时误差/速率轨迹完全一致，载波旋转后的符号变化是算法变化，不藏进数值容差。

## 系数量化与硬件成本

复用既有20位增量、12位地址、18位Q16系数NCO，其他数据、矩、除法和相位仍浮点。
量化前冻结预算：频率差1e−5周/符号、相位差0.01rad、Q差0.005。
相位预算为新工程实验值：0.01+2π×65×1e−5小于0.025rad头部附加相位，
不是长载荷误差界，更不是标准限值。
开发一步59节点最大差分别7.55008e−6周/符号、0.000742998rad、0.000152638，节点门通过；
实际一步浮点/有限字NCO均59/41，不能将其写成完整定点接收机通过。

N=32时，一/两步的直接实乘积等价量为647/909，另有64次分量归一化除法、1/2次Newton除法、
1次相角，以及2/3遍NCO。原初始化约32次相角，但不能仅由32→1宣称整体节省。
常系数矩乘法的移位/加法、共同指数或倒数替代、系数复用均需独立实现与计费，当前不算免费。
原幅度增益等未建模包内工作也不能从新节点图推导为零。

保守情景为初始化另设NCO，已知逻辑容量下界164480bit（约20.08KiB）超过原16KiB；
符号缓存、矩累加器和端口位宽仍未知，不填零。共享原NCO需证明并发和期限，目前无共享收益。
周期报告串联范围扫描、逐分量除法、模板、每轮旋转/矩/除法及最终相位，
以每符号`ceil(8/乘法槽)`的有限II建日历，不以总乘法数平均代替反馈依赖。
200MHz/7乘法槽情景中，一/两步总细处理服务2773/2874周期；
每32采样均请求且初始化的抽象过载中，8185请求丢7002/7043。
除法/相角32周期、宽加法单周期只是公开假设；不是浮点或定点单元的综合证据。
该日历和有限FCFS不反馈到算法，不能把资源丢弃当算法漏检，也不证明合法业务整链16MS/s。

**当前拒绝默认集成**：新开发整包收益0，一步有新增坏头，部分NCO字通过但整体格式和资源未通过。
保留能恢复旧一包的证据，后续优先研究有限结构与明确恢复线索，不反复围绕旧包调参。
