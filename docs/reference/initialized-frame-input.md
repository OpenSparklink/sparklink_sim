# 已捕获窗口的连续初始化与帧交接

本阶段将[头部存储候选](packed-head-retention.md)之前的实际初始化也接入同一时钟，
对应已核对的§6.2.1.2、§6.3、§6.9及附录C范围，见[标准来源](standard-sources.md)。
`InitializedFrameReplay`是显式实验模型，默认接收接口及512字模式不变。

## 输入和状态合同

调用者提供一次已选答案、实际捕获历史及交接时钟，不提供期待载荷或包长。
历史必须保留同步区过去样本和全部未来插值样本；不足、过期、已有读回执、
非1024字或重复所有者都在消费前拒绝。样本索引连续，一沿至多写一字。
参考接口仍将`sample_limit`和所选坐标限制在2²⁰采样窗口内；
无限时间轴的捕获窗口坐标重定位尚未在本组件中完成。
已有相干确认配置继续验证同一个答案，不能借CRC更换同步、CFO或相位。
上游确认和细搜索计算时间不在此组件内，交接时钟必须包含它们，不能当零周期。

```{mermaid}
flowchart LR
  A[已捕获的1024字源] --> B[原始四字插值与同步缓存]
  B --> C[实际有限初始化拟合]
  C --> D[3边沿定时状态安装]
  D --> E[原查询/检测/PI/归一化]
  E --> F[真实头CRC及合法长度/MCS]
  F --> G[合法帧尾停止采样]
  G --> H[载荷服务：周期仍未知]
```

初始化、状态安装和采样复用同一源、缓存及6DSP插值核。安装期间输入继续写入，
就绪的拟合结果仍由上游持有，时钟同步推进，不复制原始尾部或重新拟合。
安装依次执行54→30位功率RNE归一化、有限尺度下的功率下限比较、检测/PI初值注册。
输出只转移一次；所有旧功率/Gardner/PI参数和采样数值保持。
54位移位/加法及宽比较各占所列注册级是周期模型假设，尚无200MHz时序证据。
超出有符号10位指数明确溢出，不偷偷饱和。

真实头未通过前不允许载荷查询；头通过后从合法几何确定帧尾。
EOF排空已接纳的工作，输出截断头/载荷的真实状态，不补造样本。
同步尚未完整的窗口在本接口前拒绝，其EOF事件仍由上游捕获器处理。
初始资源退出明确统计被丢弃的未验证窗口；已进入帧路径则沿用依赖退休和未消费后缀归还。
终止后才归还所有者令牌。两包间调用者仍需持续执行捕获历史的有界保留；
不能将此单窗口模型等同于已经接通下一捕获生产者、译码或MAC调度。

## 预算选择与仍未通过的资源门

隔离诊断先比较512/1024/2048字及100/160/200MHz，保留只改变容量守卫的差异，
没有直接将它当成实现支持。200MHz原三例在1024和2048字下同为到达未知载荷服务，
故本阶段仅研究1024字。此前512字和16KiB失败记录不改写。

| 已建模部分 | 本候选占用 | 限制 |
|---|---:|---|
| 单已选路径源 | 47104逻辑bit，2 BRAM36 | 全局1R1W，两72×512 SDP银行 |
| 同步缓存 | 1 BRAM36 | 填充/回放串行，共享同一缓存 |
| 控制头 | A2 2/B1 3 BRAM36 | 同一头在初始化期间也预留 |
| 上述RAM合计 | A2 5/B1 6站，即22.5/27KiB原生 | 不含其他前端、载荷、TX、MAC、DMA |
| 专用DSP | 19 | 插值6共享于两阶段，拟合1，检测/PI/归一化12 |
| 新安装器/已知包装控制 | 373/392bit上界 | 原服务寄存、队列及未映射描述符另外计费 |

源相比512字增加2944逻辑字节、4608原生字节和一个BRAM36。
新增银行译码与46位返回选择的LUT/FF/Fmax未知；不是免费端口。
19DSP是纳入初始化后的静态成本，**原18DSP预算失败**；未证明拟合乘法器可以与后级共用。
同一源在两阶段的复用有对象和事件证据；不同包/不同profile的插值器、头银行、
TX或译码共享尚无成本扣减。整机预算仍为规划，未知项保持未知。

## 冻结验证结果

新开发/保留分别为12个原始IQ流、15个合法包，其中每集3流包含两包。
变化载荷、包长、PID、CRC/加扰上下文、导频、幅度、分数偏移、CFO/SRO及干扰组合。
MCS8/12无编码，MCS10有编码；两臂保持原编码和现有译码，不将编码收益计入无编码。
使用独立解析发送脉冲真值；两臂复用同一次未知起点捕获，不按载荷/CRC选择答案。

| 数据集 | 捕获/合法包 | 原/新完整正确 | 原成功丢失 | 数值/字段不一致 | 到未知载荷服务 |
|---|---:|---:|---:|---:|---:|
| 新开发 | 12/15 | 10/10 | 0 | 0 | 12/12 |
| 冻结后新保留 | 12/15 | 11/11 | 0 | 0 | 12/12 |

接收率增益为0。初始化也持续输入，最高已见源占用956/1024字，余68字。
新测试使用捕获器实际数据水位，包含数据依赖的前瞻；
尚未接入细搜索的真实硬件服务时间，也没有给载荷FFT/LLR/译码填零周期。
`resolve_functional()`只完成数值参考，明确使完整周期证据失效。

固定三输入的新组合周期模型中，200MHz三例到未知载荷服务，峰值316/651/924字；
160MHz只有FT2到达，FT3/4溢出；100MHz三例均溢出。
200MHz三例下游故意阻塞均在1024字有界溢出，没有MAC交付。
这些是已选窗口的组件结果，不能证明完整16MS/s接收机。

每个新负例集15流、614400采样（38.4ms），覆盖静默、噪声、变频单音、错误同步及突发，
均0候选/误MAC。观察有限，不代表所有环境绝对零误检。
开发3漏检/2数据CRC失败，保留3漏检/1数据CRC失败均保留。
未编码BER分别9/39680、109/17440；编码BER为0/19840、0/8720，均与原数值路径一致。
只统计实际候选可计算的载荷，漏检不伪记BER为0；CRC失败继续为失败。
真值最大定时误差约0.217/0.222采样，单音抑制相位/群延迟未扣除；
收敛、相位失锁及滑移本阶段未分类，不用判决残差代替真值。

47项新测试覆盖三沿安装及独立整数舍入、真实CRC/非法长度、任意调用批次、
跨包所有权、EOF及有界阻塞。两环境全量5057/5068身份，含38/5可选跳过，
覆盖率93.66%/93.67%，原身份不减少，四分片均低于120秒。
新服务是Python模型；新数据捕获/定时显式选择Python，Rust环境的既有加速另行核对。

## 支持和未完成事项

| 配置/层次 | 状态 |
|---|---|
| 普通A2+LQI/B1、4Msym/SPS4，MCS8/10/12 | 新数值与选定窗口结构验证 |
| 其余MCS、包长/导频组合 | 不由上述有限集合推断完成 |
| 原始IQ未知起点→MAC | 继续使用原严格浮点流接口；新窗口组件尚未整链调度 |
| WS63 A3、未知编码前缀 | 不进入本候选，保持独立/未知 |
| FT1/GFSK | 严格完整流式、定点和周期仍有独立缺口 |
| 全链定点/整机/连续16MS/s | 均未通过，无新综合或布局布线证据 |

原word-full12-c18的2.34835%＞2%、插值、16KiB及4096/2048控制预算失败保留。
接收能力边界、下一捕获、载荷处理及实际源/RRC/细搜索生产者继续逐项闭合。
资源账本保留必要TX、译码、实时MAC及接口预留，不因本模块通过测试而借用。

## 本包配置拥有权

实际捕获路径可通过可选`confirmed_receipt`传入本候选已完成的有限相干回执，
详见[捕获桥](initialized-capture-bridge.md)。模板、样本、位置/CFO/分数及可用时刻
必须全部匹配；拒绝固定成功标志或第二次确认门。未提供回执时原接口行为不变。
该扩展修复了原型中差分0.84020446已被实际相干门接受后又被≥0.85守卫拒绝的问题，
不普遍降低同步门限，也不使用头/数据CRC选择答案。完整调度仍按各自资源门评价。

`InitializedFrameReplay`入场时锁存接收profile及其中可变的`TxConfig`，
随后初始化、实际头CRC/字段处理和载荷CRC使用本包配置。调用者可以为下一包
更新自己的CRC种子等协商上下文，不能改变当前拥有者。新建下一拥有者时
重新锁存当前配置，不复用全局或上一包快照。

修复前，头部模块已经持有快照，外层却保留调用者别名；在初始拟合或三沿安装
期间更新CRC种子，会在交接时触发配置不匹配异常。FT2/3/4共6个异常反例及
交接后三个对照保留在冻结证据根的`packet-config-ownership`。新增9项测试
分别覆盖初始拟合、安装、交接后更新：字段、完整载荷和全部定时轨迹与原配置
参考精确相同，同时检查下一拥有者取得新配置。已有错误CRC种子负例仍按失败处理。

这是既有本包配置寄存器语义的修复，不新增物理IQ副本、候选、样本端口或
数据路径运算，也没有新RF接收率收益。Python对象复制不是一个新硬件FIFO；
完整配置/描述符的位宽与切换成本仍须在整链资源和调度模型中核实，不能填零。
标准依据仍为§6.3帧结构、§6.9真实CRC上下文，不引入新profile或字段定义。
