# 精确符号评分流水（M24，实验）

对应普通PSK同步§6.2.3的硬件结构选择，不改变发送波形。保留浮点参考、完整增长整数参考、
共享样条银行、插值、全相位网格、候选、归一化排序、平局、门限、等待及选中相位回放。
仅将既有三实乘差分及相邻符号功率积累计从通用逐字指令改为专用流水。
未使用CRC、载荷、真值或相干确认选择答案，没有新Rust/RTL实现。

## 有限数据通路

显式`SplineScoreFlow(...,symbol_pipeline=True)`需要既有功率复用、Gauss及逐字设施，
`CaptureFineWorker`提供同名研究参数。默认False，原默认成本及结果结构保持。
九相位当前字及进入/工作状态使用原已计费寄存器；流水中每份源票据和中间量另计。
每符号先完成既有插值，最多九票据逐沿进入流水，收到全部回复后处理下一符号。
第二粗峰按原顺序复用这些槽，不保存18×128整段符号向量。

`FineSymbolRequest`携带token16、phase4、当前/前一complex22、有效位、功率44、
相关53×2、能量98和模板符号2×2，共361bit。首符号必须为零累计和无差分模板符号。
输入及输出身份逐一核验，16bit令牌耗尽须清空后重启；取消一沿清除全部在途票据。
外部同相位状态由调用者拥有，节点不根据主机预计算完整乘积或未来指令轨迹。

16级分别为：源票据、预加/分解、原生输入、原生乘法、结果寄存、五组部分积重组、
差分/符号功率、模板贡献/能量输入、能量原生输入、能量乘法、结果寄存、三组重组、
两组重组、单组重组、C/E累计、注册输出。无阻塞从准入到输出16沿，II=1；
输出阻塞通过时钟使能冻结所有槽，不能覆盖/无限排队。上游须保持并重试，
这不是ADC背压或完整输入缓存证明。每批至多九个票据，全部回收后才能复用相位状态。

只在原生signed25×18处执行乘法。signed22×23拆为两片，三组差分共6DSP；
两个signed22平方各两片，共4DSP；unsigned44功率先零扩展signed45，
45×45为六片（移位0/17/34/24/41/58），共6DSP。
所有部分积/重组、signed23预加、signed45差分、signed46贡献、signed53相关及unsigned98能量
保持完整有效位；无舍入、截断或饱和，越界显式中止，不回退浮点冒充成功。
首符号同样付完整计算成本，不按静默或零值跳过最坏工作。

## 操作、状态及整机影响

每票据16个原生乘法、三个23bit预加减、18个重组/差分/贡献/累计加法、四个符号选择/取负。
模板符号是固定-1/0/1，不是通用乘法；无新除法或开方。最大加法98bit，
每级宽加法一沿是待验证假设，未证明200MHz。下游原分子平方、归一化交叉排序及比较仍逐字执行。

16槽源票据5776bit，各级额外数据总和按实际格式逐项列在`estimate()`；
加有效位、令牌/耗尽、时钟及八个64bit计数器，节点外部寄存上界11617bit。
批次控制再计34bit，合计11651bit，低于实现前12288bit增量研究界。
DSP内部管线容量2144bit另列，未凭推测扣除外部保守预留。
旧7219bit查询状态和22799bit通用设施/相位上下文继续保留，总计41669bit。
旧24576bit设施/上下文界仍单独成立，旧16KiB失败不改写。

新增16个专用DSP，旧排名/插值逐字DSP继续保留，评分总17；准备阶段2个另计，合计19。
不计未经证明的跨阶段、RX/TX、粗筛/细搜或译码共享收益。
无新增IQ/Y/M RAM、采样端口、ROM或相位数；票据及回复分别一端口。
控制LUT、寄存器布局、时钟使能扇出、宽选择和Fmax尚无综合证据，不填零资源。

这将占用原整机RX/TX/译码/MAC/接口余量：单路径粗入口20DSP与细搜19DSP可能并发，
双路径按78DSP保守相加，基础29另计；不能按TDD直接复用。
寄存预留单个细搜已41669bit，加双路粗核及基础工程会与未批准25%余量建议冲突。
完整RAM映射、译码/TX预留及端口期限仍未闭合，局部结构通过不等于资源通过。

## 验证与采用规则

实现前冻结：全部整数语义精确；开发至少6个评分窗覆盖FT2/3/4；
相对既有Gauss/功率复用/两ALU基线总服务周期至少减少25%；
增量不超过16DSP、12288外部bit，无新采样RAM/端口。只允许显式研究配置。
新节点开发和独立节点验收变化整数输入族、幅度/指数、模板PID、FT、相位边界和几何规则，
源/参数冻结后评价新组合，不能据其失败重选。它不是RF捕获率保留集。
旧真实捕获窗只作按SHA读取的固定回归；整包率、BER和环路真值指标未测，保持未知。

独立整数直接复乘/平方与Fraction样条参考覆盖最小负值、极值、零功率、符号、临界值、
少相位、两个粗峰、阻塞、取消、令牌耗尽和实际捕获所有者。保留新原型报告截断的三条失败，
修复变量遮蔽后继续原等值断言，没有修改期待答案或放宽预算。

PYTHONPATH=.:src:scripts uv run --frozen --no-sync python -m scripts.model_fine_symbols \

目录必须不存在；预期退出1且有完整`model.json`正向回执。任意异常不能算预期通过。
当前完整流式、全链定点、整机资源、连续16MS/s四项验收保持开放。

## 冻结结果及采用边界

| 节点集合 | 窗 / 实际评分 | 原 / 新服务周期 | 减少 | 额外整数数值损失 |
|---|---|---|---|---|
| 新开发组合 | 6 / 6 | 577320 / 216932 | 62.424% | 0 |
| 冻结后独立节点组合 | 6 / 6 | 614096 / 226958 | 63.042% | 0 |
| 原输入SHA固定回归 | 16 / 13 | 804861 / 332790 | 58.652% | 0 |

三个固定回归窗仍没有评分，数值状态未知；原M23全部结果及周期也精确复现。
不是仅比较最终最佳项：所有相位符号、相关/能量、归一化排序、选择及Y/M均精确。
两组节点输入各六个独立整数窗口，不是射频包正确率实验，不能据此改写正式61/96。

实际原生依赖环境直接复制两组原输入SHA，各12JSON/6NPY成员及全部语义/成本精确。
新节点仍是Python结构模型；依赖存在不表示本节点调用了Rust CRC/Polar或已有Rust实现。
两环境全量5490/5501项、原身份保留，覆盖率均93.85%，新节点97.76%，
最长分片90.202/76.614秒；80项针对性测试通过。全部原型/入口失败和输入关联保存在外部证据。

结论为显式结构候选，不升默认。实现前25%周期收益、16DSP/12288bit增量研究规则满足；
完整资源账本及四项接收验收仍不满足。宽加法、控制和布线频率尚无综合证据。
观测最长服务70040沿，100/160/200MHz分别700.4/437.75/350.2微秒；
期间连续16MS/s新增11206/7004/5603点（向下取整），仍超过4096点历史。
这是排除等待/复制/其他请求的下界投影，不是最坏服务上界、实际队列结果或16MS/s通过。
下一步应在真实RRC释放时钟上统一粗筛、细搜、拥有窗及帧消费，并优化寄存存活范围和端口；
不能用本次局部加快掩盖尚未计时的载波/解码或FT1完整路径缺口。
