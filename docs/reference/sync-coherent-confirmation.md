# 已知同步CFO补偿后的相干确认（RX-CFO3）

本阶段只改变同步确认门，保留原能量/整数门、一峰九相位、差分定时选择、
16采样峰值等待、单音回退、Gardner/PI和载荷载波细化。默认确认仍为差分分数0.85。
原始规范依据为§6.2.1.2（PSK及交替旋转）、§6.2.3.2（同步信号2），
来源/版本/SHA见[标准来源](standard-sources.md)。门限是算法实验值，不是标准合格限值。

## 显式接口与选择边界

```python
rx = MacStreamReceiver(profile, quiet, quiet_batching=False,
                       correlation_backend="scaled", normalized_coarse=True,
                       sync_search_method="bounded-grid", sync_candidate_count=1,
                       sync_coherent_threshold=.45,
                       sync_coherent_fixed_nco=False)
```

阈值必须显式为正数，只允许已冻结的一峰Q12路径；有限字NCO必须另行显式启用。
目前实验覆盖4Msymbol/s、SPS4、FT2，不能由节点允许128符号推断FT3/4整链已验收。
普通链路和厂测profile仍由显式配置提供，未把WS63同步字、CRC或未知编码前缀变成默认。

1. 差分归一化分数仍决定整数峰和九个局部位置中唯一最大值。
2. 最大值未满足原未来样本规则时继续等待，不能用较弱就绪峰替代。
3. 就绪后复用该最大值的差分相关相角ω，不增加频率搜索、相位试探或CRC重试。
4. 使用实际`profile.sync_symbols()`（含规定旋转）计算：

```
ω = angle(Σ (y[k+1] conj(y[k])) conj(s[k+1] conj(s[k])))
C = Σ y[k] conj(s[k]) exp(-j ω k)
Q = |C|² / (Σ|y[k]|² Σ|s[k]|²)
```

运行门使用`denominator>0 and numerator>=threshold*denominator`，不需要除法或开方；
输出Q的除法仅供诊断。零能量拒绝，非有限输入和超有限四次方范围报错，不补固定成功标志。
确认Q不重排局部位置，不能恢复整数预筛已丢弃的峰。ω仍有符号率±π的相位增量歧义，
ω误差会损害积累；同窗参数拟合也会抬高噪声Q，必须在独立负例上校准和复核。

启用时以新Q门替代最后的差分0.85接受门，能量倍数2及整数0.6不变。
`sync_score`继续表示原差分分数；新结果放`sync_confirmation`，不偷换既有字段单位。
`correlation_qualifying_searches`也保留原0.85语义，新增`coherent_evaluations/rejections/
accepted/zero_energy`分开记录。Q拒绝不触发另一载波/相位/单音路径重试。
候选和头/数据CRC分别记录，只有正常严格解析通过的帧才可交付MAC。

## 有限字NCO节点与未完成部分

`SyncConfirmationNCO`只接收20位整数相位增量，每个候选相位从0开始，最多生成128字。
相位按2^20回绕；地址最近偶数舍入到12位，使用1024×17位无符号Q16四分之一余弦ROM。
端点旁路，象限/符号还原为18位有符号Q16的cos和−sin，不做运行时三角函数。
跨调用块保存相位，候选结束后复位；输出数组归调用者，不作为内部历史缓存。
独立Fraction字地址参考验证舍入、象限、回绕和跨块，解析复指数验证系数误差。

浮点ω到相位增量的转换、输入符号、相干乘加、能量及宽比较仍为浮点。
`sync_coherent_fixed_nco=True`的意思是**确认用NCO系数为有限字**，
不是已完成定点CFO估计器或定点接收机。头/载荷原载波估计仍未改变。

位宽在查看开发结果前按解析界冻结，未依保留集扩大：
频率步进误差≤0.5/2^20周/符号，128符号累计与地址误差加系数误差的保守界
导出理想算术下Q差≤0.002324，小于原0.005预算；浮点归一化误差仍另有范围限制。
节点格式及预算分别保存在`nco-format-predevelopment.json`和实现前预算，不事后放宽。

`SyncConfirmationNCOFlow`是四信用、II=1、四周期延迟的单块令牌日历：
下游停顿时停止输入字准入和相位前进，不丢字或悄悄插零。
128字正常/阻塞输出逐字相同；截止100周期且下游始终不接收时只准入4字、保持4字待发，
明确标记未完成。信号对齐、原ADC输入及整链期限未接入该日历。
孤立II/延迟依赖独立加法/地址级、双读同步ROM及单周期相位反馈，尚无综合/布线证明。

## 开发结果与冻结

实现前预算SHA为`35ce5fb3c9999a83b5948af0ef268a281a263c0b7e027546d1826d478b52630f`，
开发种子570117、额外负例570121。原路径实现前/后152流判定与220个轨迹数组精确相同。
这些流共有5062710采样，64个已知合法包；112负例共4657832采样（16MS/s约291.1ms）。
额外64条负例占4194304采样，覆盖能量门开启/关闭的纯噪声、单音、错误同步背景和突发。
有限样本无误检不代表任意环境绝对零误检。

| 原差分0.85 | 55 | 37 | — | 0/0 | 基线 |

两个拒绝方案都丢失`wrong-sync-1-2`旧成功包，输入SHA
`1716082e4bb0dbfb68a0d52681a2afa47f5d4b66c75a235704e9af02b4b08081`。
总正确数相同不能掩盖逐包退化。Q0.60首次回放在134/152流处以143中断，原因未知；
保留部分文件/哈希，原参数重跑完成后才计入结果，不把中断当算法拒绝。
开发Q0.45额外捕获5包、恢复1整包，原成功轨迹未变；CRC失败继续算失败。

Q0.45有限字NCO与浮点确认的开发结果同为60/38，63个就绪确认节点的最大Q差9.24439e−5、
频率步进差4.76145e−7周/符号，低于冻结0.005/1e−5预算，未见门判定变化或成功丢失。
相位系数误差最大0.000845474rad，只是NCO相对请求ω的误差，不是相对真实无线载波的误差。
π附近的频率差按符号率周期比较，不能把相同离散旋转误算成整周频偏。
节点数字门、功能门、资源门分开记录；同包标签、空节点评价或损坏哈希都不能数值通过。

冻结选择SHA为`21e1b5673ba3bffae1ba5bbb1bef30f6fa8cf0f55e72dff67fafcbbb3cf8e052`，
新保留种子580117及额外负例580121在冻结后生成，后续只评价，不反向改门限。
发送角度/脉冲及重采样独立于接收插值，仍共享比特编码器，不能作为唯一标准互通证据。
真值位置、载荷及CFO仅在接收结束后用于配对、BER和归因，不进入Q/相位/CFO选择。

新保留228流、7593739采样，96个合法包。原路径80捕获/59完整正确，
Q0.45及有限字NCO均87捕获/61完整正确，分别增加7.292和2.083个百分点。
原成功及原候选无丢失，已匹配旧轨迹完全相同；35个未完整正确包仍保留：
9漏检、4头CRC失败、22数据CRC失败。
168负例共6985435采样（16MS/s约436.6ms）中均无候选/交付，不作全环境零误检保证。

两个完整恢复均是**原本已编码的MCS6普通链路包**，编码配置和译码器未改，
收益来自新的同步确认；不能宣称未编码突发或未知厂测编码已修复。
`wrong-sync-1-6`/`wrong-sync-1-10`的输入SHA、CFO及定时误差在`held-outcome-links.json`。
其中前者真值同步初始定时误差约0.2447采样、包内RMS0.1171采样，
表明网格步长并不等于真实精度；原载荷载波细化将其最终CFO误差收敛到约1.375Hz。
这些是已知注入的仿真真值诊断，不是对真实IQ的精确定时声明。

新保留98个确认节点中，NCO最大Q差0.000102240、步进差4.70430e−7周/符号，
仍满足冻结预算，无门判定变化或整包量化丢失。
相干累加/频率估计器仍浮点；“有限字节点通过”不能替代整个接收机定点门。
旧908行回归、实际厂测MAC、任意分块和双后端的扩展复核仍需单独完成，不提前推广默认。

## 资源与系统边界

NCO包含四分之一ROM、相位/增量/计数、四级标签、地址、符号和系数寄存器，共17610bit。
ROM估算占一RAMB18的两个只读端口；不是资源或时序综合结果。
还计入四符号对齐184bit、四个64位监测计数256bit及同步相位码预留96bit，
相位码/相干输入和累加器格式尚未证明，不能把预留当定点验收。

在原一峰2949实乘积直接图上，新增通用模板/旋转/信号能量/分母/门限共324实乘积等价量，
合计3273，高于原18DSP/200MHz分配后乐观剩余2912。
具体任意位宽乘法尚未完成原语分解，样条准备、除法诊断/非线性、宽比较和端口仍未调度，
不把每个实乘积当成已映射一个DSP。这只是一个直接图，不是其它因式分解的不可实现证明。

原已知部分128724bit加新增预留后为146870bit（约17.93KiB），已超过原16KiB。
另一个可选载荷有界权重节点1581bit单列，不因本实验默认为免费或双重计入。
相干累加/能量/宽比较、完整插值准备、译码、TX和实时MAC等尚未全部计费。
保持原预算，不因全芯片仍有资源就自动放宽；共享ROM/NCO没有并发期限证明，未计共享收益。

200MHz/7路细乘法的乐观快照日历为每请求469周期，连续262144采样、8185请求丢1203；
100/160MHz分别丢6184/3386，较低时钟RRC自身也未验证16MS/s。
这是隔离FCFS情景，丢弃没有反馈到实际接收器，不能算同步算法漏检或宣称整链16MS/s。
原RRC2.348%>2%、旧local4起点失败、输入范围事件及全部CRC/截断继续保留。
**新确认/NCO仍为显式实验选项，完整接收机与整机验收未完成。**
