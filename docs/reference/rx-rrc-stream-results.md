# 有限字RRC到严格MAC的集成结果（RX-C2A5B）

本阶段验证显式`word-full12-c18`实验前端，默认浮点接收链不变。
功能、数值和资源分别判定：**功能回归满足既定预算，RRC数值门失败，整链接收资源/周期未验收**。
集成不增加接收能力，也不消除原始数值失败。接收机尚未完成，不转入大规模TX实现。

## 范围、配置与独立性

格式仍为输入12位/系数C18/输出19位，4Msym/s、SPS4、beta0.4、81抽头；
其他符号率和SPS是后续扩展任务，不是永久产品限制，也不能只删除守卫后宣布支持。
有限字覆盖主RRC输出及其跨块历史；检测、单音支路、分数细搜索、定时/载波、解映射和译码
仍使用原有浮点或独立有限指数相关模型，不能称为全定点接收机。

普通FT2/3/4、MCS0..12、导频0/8的78组合及QPSK/8PSK的1/2047字节边界已有严格IQ到MAC测试。
独立角度、脉冲及重采样发送参考仍共用比特编码器，不能作为唯一标准互通依据。
WS63显式使用冻结厂测同步字、CRC种子、编码/加扰和导频配置；未知编码前缀仍未知。
原型`finish()`保持80个零样本；整接收器统一补42个EOF样本后`seal()`，跨块/包保留历史，EOF后关闭。

开发前冻结`rrc-stream-predevelopment.json`（SHA
`79ac86fdbfe755cc058b40ecc3a4b5f772a0ece4aba4e834f644e32ae7964183`）。
种子510117开发44流/32合法包；冻结源码、2倍能量门限、0.6整数预筛、8分相位、
0.96875单音极点和原定时/载波配置后生成种子520117保留88流/64合法包。
覆盖静默、AWGN、单音、错误同步字、突发及四包密集流；背景与弱包叠加。
期望载荷、CRC和真值仅在接收完成后检查，不能挑选同步、定时或载波答案。

## 静默证据与数值限制

原364输入中的220非静默流实际运行全部有限字RRC（16,655,307采样）。
剩余144静默输入逐个按冻结SHA读取，以原始能量门始终关闭证明新流无同步候选/交付；
**没有执行这些流的内部RRC/单音状态数值验收**。证明不依赖浮点RRC幅度界，单音抑制器可激活。
停止逐样本长静默复核的部分运行、退出143及原因单独保留，未冒充完整数值回放。
硬件模型仍计入全部持续输入：共167,650,251实际样本，另计EOF，不能用证明跳跃稀释最坏成本。

此前种子500117的`blocks-1`局部64样本误差2.34835%仍超过2%预算；
输入仅量化2.01959%、系数仅量化0.19166%的诊断继续保留，不能按整包一致改预算或强行增加位宽。
比较器在功能全部满足时仍返回1（数值门失败），未将程序执行成功等同算法验收通过。
144静默内部数值门为“未验证”，不是通过。

## 存储、周期与后续

FIR持久NumPy数组1696字节，旧浮点1928字节；未包括临时数组、进程RSS或约3MB合法帧/译码缓存。
孤立RRC周期候选24900bit逻辑状态、8实乘/43宽/64小运算单元及专用端口假设仍单独成立；
不能与原15.61KiB捕获模块免费相加后宣称满足16KiB。
200MHz下孤立RRC及整数预筛的16MS/s条件不代表全链吞吐，尚无综合/时序证据。

本地全量Python 3353通过/32跳过、覆盖率91.457%；Rust及gmssl环境3396通过、覆盖率91.560%。
API提交`cc51789`远端9项CI成功，6份制品已核验官方哈希和ZIP；
纯Python测试125.74秒超过两分钟工程目标，该超时记录保留。
后续CI保留全部测试，将98个有限字集成用例与其余用例并行、分别保存报告和退出状态；
本地同样分组完整通过，合计墙钟43.75秒，远端耗时仍须实际CI确认。

下一阶段先统一RRC、检测、相关、细搜索及包内处理的计算/存储/端口预算，再比较有界候选/有限相位。
已拒绝的四次局部细搜索0.155438起点偏差仍保留。错误同步背景与突发污染载波分别归因、
在新开发集选型并冻结后检查新保留，不普遍降低门限、不关闭载波细化、不用CRC挑答案。
